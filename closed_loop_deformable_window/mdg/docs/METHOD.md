# MDG 方法

## 连续动态窗口与移动圆盘

每个门在局部二维平面内用真实简单多边形表示。中心、RPY、整体尺度和局部形状
参数均由固定控制点的 PCHIP 查询。物理区域始终非空、无洞且无自交；安全区域
直接使用 `polygon.buffer(-safety_radius)`，空区域表示门暂时关闭，MultiPolygon
原样保留。

每个采样时刻在安全区包围盒上建立规则网格，以网格点到真实边界的距离作为候选
半径。候选经非极大值抑制后用 Shapely 验证整个圆盘被安全区覆盖。相邻时刻圆盘
使用 Hungarian 匹配，圆心和半径由 PCHIP 插值并以 `0.02 s` 密集复核；违规轨迹
按最大越界量和 `0.01 m` 余量收缩。

## 不可通行区间与开放时机

物理窗口非空不等于安全区非空。若某个采样时刻的真实内缩安全区为空，MDG 不生成
候选圆盘，也不在该时刻建立穿越节点。安全圆盘轨迹的活动区间因此直接表示窗口的
开放机会。

图搜索联合选择每扇窗口的圆盘、穿越位置和穿越时刻。候选时刻除了位于开放区间，
还必须能够从上一层按速度和点质量飞行时间下界到达。若某一层没有开放节点，或所有
逐层连接均违反顺序/可达性约束，求解器返回不可行；不得回退到物理区域、凸包或闭合
时刻。

## 粗细时空图

固定起点是第零层，每扇门是一层，闭环终点是离散回到起点的最后一层。边仅连接
相邻层，并满足速度乐观下界与 `0.8*T_pm` 点质量下界。Bellman 松弛按层执行，
主目标是最早闭环完成，次目标是点质量边时间总和。

粗图选中后，在每次穿越前后 `0.30 s` 保留选中圆盘轨迹和两个最近竞争轨迹，
以 `0.02 s` 重建细图。Dense Oracle 只在四窗口实验中使用 `0.01 s` 和八圆盘。

## 自由点、MINCO 与 Lazy Repair

图搜索只选择圆盘轨迹和初始时间。自由点方法优化

\[
s(\xi)=\frac{\tanh\|\xi\|}{\|\xi\|}\xi,\qquad
q(t,\xi)=a(t)+0.95r(t)s(\xi).
\]

零点使用解析级数保证值和雅可比连续。窗口位姿、圆心和半径导数均进入穿越时间
梯度。后端直接复用 SC-DynaTOGT 的 TOGT 正时间映射、degree-7 MINCO、四旋翼
平坦性和 L-BFGS-B。相同 PVAJ 与恒定 yaw 约束并验证完整闭环状态。

密集验证检查指定穿越、圆盘包含、平面误差、每门一次、PVAJ 连续性、速度、
body rate、单旋翼推力和动态门框碰撞。失败时封锁违规最大的细图边并重跑 DP 和
后端，最多五次；全部尝试写入日志。
