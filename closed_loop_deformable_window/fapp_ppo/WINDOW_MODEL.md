# 独立连续形变时变窗口模型

本文档定义 `FAPP-PPO` 仿真环境当前实际使用的窗口模型，重点说明窗口的位置、姿态、
尺寸、局部轮廓和可通行状态如何随时间变化。

该模型只描述仿真窗口，不描述无人机控制算法。窗口的完整未来在每个回合开始时一次性
生成并固定；无人机只能观察和适应窗口，不能触发或改变窗口。

## 1. 模型总览

第 \(i\) 扇窗口在时刻 \(t\) 的状态由四部分组成：

1. 三维中心位置 \(c_i(t)\)；
2. 窗口平面的空间姿态 \(R_i(t)\)；
3. 整体尺寸与开合尺度 \(r_{i,x}(t),r_{i,y}(t)\)；
4. 局部非刚性轮廓 \(q_i(\theta,t)\)。

窗口局部平面中的第 \(k\) 个边界点记为 \(b_{i,k}(t)\)。它在三维世界坐标中的位置为

\[
x_{i,k}^{\mathrm{world}}(t)
=
c_i(t)
+

R_i(t)
\begin{bmatrix}
b_{i,k}(t)\\
0
\end{bmatrix}.
\]

因此，一扇窗口可以同时发生平移、倾斜、长宽变化、整体开合和局部轮廓形变。

## 2. 每回合固定、各窗口相互独立

每个仿真回合在 `reset` 时生成完整的未来窗口轨迹。第 \(i\) 扇窗口使用三个独立随机流：

| 分量编号 | 随机内容 |
|---:|---|
| 0 | 开放日程、首次开放相位、开放宽度、重现间隔 |
| 1 | 三维中心平移、空间旋转 |
| 2 | 横纵尺寸变化、局部轮廓形变 |

随机流由

```text
(scenario_seed, window_index, component_id)
```

共同确定。不同窗口的 `window_index` 不同，因此四扇窗口的日程、位姿和形变不会共享
同一随机序列。

窗口生成器不读取以下信息：

- 无人机位置、速度、姿态或动作；
- 当前策略输出；
- 路线长度；
- 巡航速度；
- 预计到达窗口的时间。

所以“无人机快到时窗口才突然打开”在当前模型中不存在因果通路。

1000 个场景种子的独立性审计结果为：

```text
四窗首次开放相位的两两相关系数：-0.034..0.014
首次开放时刻范围：              0.321..4.118 s
每扇窗口的开放机会数量：        6..8
```

## 3. 时间关键帧与连续插值

时间关键场景约每 \(0.30\ \mathrm{s}\) 生成一个关键帧。关键帧包含：

\[
c_i^j,\qquad
\rho_i^j,\qquad
\{b_{i,k}^j\}_{k=1}^{64},
\]

其中 \(j\) 是关键帧编号，\(\rho_i^j\) 是旋转向量。

运行时分别对以下量使用自然三次样条插值：

\[
c_i(t)=\operatorname{Spline}(\{c_i^j\}),
\]

\[
\rho_i(t)=\operatorname{Spline}(\{\rho_i^j\}),
\qquad
R_i(t)=\operatorname{Exp}_{SO(3)}(\rho_i(t)),
\]

\[
b_{i,k}(t)=\operatorname{Spline}(\{b_{i,k}^j\}).
\]

因此，中心、姿态和每个边界点都随时间连续变化，不采用逐帧独立随机抖动。

## 4. 三维平移模型

每扇窗口围绕自己的基准中心做三维平滑随机游走：

\[
c_i(t)=\bar c_i+\Delta c_i(t).
\]

其中：

- \(\bar c_i\) 是沿闭环路线布置的基准中心；
- \(\Delta c_i(t)\) 是零均值平滑随机游走；
- 竖直方向的变化幅度乘以 \(0.55\)，避免高度变化远大于水平变化；
- 位移范数受课程阶段和 `motion_amplitude_multiplier` 限制。

当前完整难度使用运动幅度倍率 `1.8`。

## 5. 空间旋转模型

窗口的基准法向大致对准无人机的名义接近方向。基准旋转向量为
\(\bar\rho_i\)，动态旋转为

\[
\rho_i(t)=\bar\rho_i+\Delta\rho_i(t),
\]

其中 \(\Delta\rho_i(t)\) 是独立的三维平滑随机游走。旋转变化经过范数裁剪，防止窗口
在相邻关键帧之间发生不合理的大角度翻转。

旋转只改变窗口平面在三维空间中的朝向，不直接改变局部二维轮廓。最终世界边界由
\(R_i(t)\) 将局部边界整体旋转得到。

## 6. 局部轮廓形变模型

### 6.1 64 点正半径极图

训练场景生成器在每个关键帧使用 64 个等角度边界点：

\[
\theta_k=\frac{2\pi k}{64},
\qquad k=0,\ldots,63.
\]

局部轮廓由正半径极图构造：

\[
b_i(\theta,t)
=
\begin{bmatrix}
r_{i,x}(t)q_i(\theta,t)\cos\theta\\
r_{i,y}(t)q_i(\theta,t)\sin\theta
\end{bmatrix}.
\]

其中 \(q_i(\theta,t)\) 决定轮廓上的局部鼓起、凹陷和波浪：

\[
\begin{aligned}
q_i(\theta,t)=1
&+\alpha_{i,1}(t)\cos 2\theta
+\alpha_{i,2}(t)\sin 3\theta\\
&+\alpha_{i,3}(t)\cos 5\theta
+\alpha_{i,4}(t)\sin \theta
+\alpha_{i,5}(t)\sin 4\theta .
\end{aligned}
\]

### 6.2 五个形变系数的直观含义

| 系数 | 空间模式 | 主要形态作用 |
|---|---|---|
| \(\alpha_1\) | \(\cos 2\theta\) | 双侧鼓起或收缩，改变两瓣结构 |
| \(\alpha_2\) | \(\sin 3\theta\) | 形成三瓣变化和非对称凹陷 |
| \(\alpha_3\) | \(\cos 5\theta\) | 形成五瓣细节、较高频的局部弯曲 |
| \(\alpha_4\) | \(\sin\theta\) | 产生单侧偏置，使上下或左右不对称 |
| \(\alpha_5\) | \(\sin 4\theta\) | 形成四瓣波浪和多处局部曲率变化 |

五种模式叠加后，可以得到心形、波浪形、多瓣形和带凹陷的非凸轮廓。轮廓可能在凸形
与非凸形之间连续变化。

这些系数不是每一帧重新独立采样，而是在关键帧上做平滑随机游走：

\[
\alpha_{i,m}^{j+1}
=
\alpha_{i,m}^{j}
+
\varepsilon_{i,m}^{j},
\]

并裁剪到

\[
\alpha_{i,m}\in[-0.22,0.22].
\]

关键帧还要求

\[
\min_\theta q_i(\theta,t)>0.28.
\]

这保证生成器的物理轮廓保持正半径、连通、无洞，并避免极图在原点附近退化。

### 6.3 当前形态模型的边界

需要区分“通用窗口接口”和“当前程序化训练生成器”：

- `DeformableWindow` 接口可以接收任意具有一致点序的简单闭合边界关键帧；
- 当前训练生成器使用正半径极图，因此生成的是星形非凸区域这一子类；
- 当前不生成孔洞、分裂窗口、自相交窗口或拓扑突变；
- U 形等原点不可见的强非星形区域不属于当前程序化生成分布。

## 7. 横纵尺寸与长宽比变化

横向、纵向基准半径分别为 \(1.05\ \mathrm{m}\) 和 \(0.88\ \mathrm{m}\)：

\[
r_{i,x}(t)
=
1.05\,[1+\delta_{i,x}(t)]\,\sigma_i(t),
\]

\[
r_{i,y}(t)
=
0.88\,[1+\delta_{i,y}(t)]\,\sigma_i(t).
\]

\(\delta_{i,x}(t)\) 和 \(\delta_{i,y}(t)\) 是两个独立的平滑尺寸随机游走，并满足

\[
\delta_{i,x},\delta_{i,y}\in[-0.20,0.20].
\]

它们使窗口出现以下连续变化：

- 整体变大或变小；
- 横向拉长、纵向压扁；
- 纵向拉长、横向压扁；
- 长宽比随时间改变。

它们与五个局部形变系数同时作用，所以“整体尺度变化”和“轮廓局部变形”是两套不同
机制。

## 8. 独立开放日程

每扇窗口使用自己的非周期更新过程：

1. 独立采样第一次完全开放的相位；
2. 独立采样每次完全开放的持续时间；
3. 独立采样相邻开放机会的重现间隔；
4. 重复生成，直到回合结束。

当前同分布设置为：

| 参数 | 数值 |
|---|---:|
| 回合长度 | \(26.0\ \mathrm{s}\) |
| 平均完全开放宽度 | \(1.40\ \mathrm{s}\) |
| 平均重现间隔 | \(3.80\ \mathrm{s}\) |
| 日程抖动参数 | \(0.22\ \mathrm{s}\) |
| 开合过渡时间 | \(0.32\ \mathrm{s}\) |

日程不要求周期重复，也不要求四扇窗口依次开放。

## 9. 连续开合包络

开放日程不会直接把窗口设置为“存在”或“不存在”，而是控制连续尺度
\(\sigma_i(t)\)：

\[
\sigma_i(t)
=
\sigma_{\mathrm{closed}}
+
\left(
\sigma_{\mathrm{open}}-\sigma_{\mathrm{closed}}
\right)a_i(t),
\]

其中

\[
\sigma_{\mathrm{closed}}=0.16,
\qquad
\sigma_{\mathrm{open}}=1.05,
\qquad
a_i(t)\in[0,1].
\]

每次打开和关闭均使用

\[
\operatorname{smoothstep}(u)=3u^2-2u^3,
\qquad u\in[0,1],
\]

在 \(0.32\ \mathrm{s}\) 内连续完成。

这意味着：

- 关闭时物理窗口不会被删除；
- 边界不会瞬间跳变；
- 打开和关闭过程中存在一段逐渐变得可通行或不可通行的时间；
- 无人机需要根据未来预览决定等待、加速或抢占当前机会。

## 10. 物理开口与安全可通行区域

物理非凸开口记为

\[
\Omega_i(t).
\]

考虑安全裕度后的区域使用真实非凸多边形内缩：

\[
\Omega_i^{\mathrm{safe}}(t)
=
\Omega_i(t)
\ominus
B(0,d_{\mathrm{safe}}),
\]

当前

\[
d_{\mathrm{safe}}=0.16\ \mathrm{m}.
\]

窗口关闭到较小尺度时，可能出现

\[
\operatorname{area}(\Omega_i(t))>0,
\qquad
\Omega_i^{\mathrm{safe}}(t)=\varnothing.
\]

此时物理开口仍然存在、连通且面积非零，但无人机尺寸和安全余量使其无法安全穿越。
这是真实的“暂时不可通行”，不是把窗口对象从场景中删除。

除安全内缩外，穿越检测还使用物理边框与无人机半径构成的碰撞带：

```text
物理边框厚度：0.08 m
无人机半径：  0.10 m
边框碰撞带：  0.18 m
```

合法穿越必须同时满足：

1. 轨迹确实穿过窗口的实时移动平面；
2. 交点位于实时安全非凸区域内部；
3. 交点没有进入边框碰撞带；
4. 窗口安全面积不小于 \(10^{-4}\ \mathrm{m}^2\)；
5. 窗口顺序正确。

## 11. 几何有效性检查

生成窗口后，会在密集时间采样上检查：

- 物理多边形有效且非空；
- 边界无自相交；
- 区域保持连通；
- 区域不产生孔洞；
- 物理面积始终大于零；
- 每扇窗口至少存在一个安全可通行时刻；
- 不同窗口的安全包络保持最小间隔。

关键帧严格由五谐波极图生成。关键帧之间实际插值的是 64 个边界点，因此中间时刻的
轮廓不宣称仍能严格写成相同五谐波公式，而是依靠密集几何检查保证拓扑有效。

## 12. 当前几何审计结果

在未见种子 `53000..53009` 的同分布条件中：

```text
最小物理面积：        0.01138 m²
最小安全面积：        0
最大安全面积：        3.96892 m²
安全可通行时间比例：  45.86%..56.35%
完全不可通行时间比例：43.65%..54.14%
每窗开放机会数量：    6..7
```

这些结果说明模型同时具有：

- 非零、连续变化的物理开口；
- 会完全消失的安全可通行区域；
- 足够长的不可通行时间；
- 相互独立的多窗口开放机会。
