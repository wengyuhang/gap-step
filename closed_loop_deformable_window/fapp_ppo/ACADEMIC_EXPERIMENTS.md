# 时间关键形变窗口：完整学术实验方案

本方案研究一个比“窗口始终能穿过”更严格的问题：窗口的物理边界始终是有效、无洞、无自交的简单非凸多边形，但在收缩阶段，按无人机外形和安全裕度内缩后的区域可以完全消失。无人机必须利用已知的非周期未来动态，在短暂开放区间内按序穿越四个窗口并返回初始完整状态。

本文档同时作为实验预注册草案。正式运行前固定种子、预算、主要指标和排除规则，不能根据结果事后挑选场景。

## 1. 研究问题与假设

| 编号 | 研究问题 | 预注册假设 |
|---|---|---|
| RQ1 | 未来机会预览是否提高闭环成功率？ | FAPP-PPO 高于反应式和已知日程名义控制器 |
| RQ2 | 优势是否来自真正的抢窗行为？ | FAPP-PPO 的机会捕获率更高、错失次数更少 |
| RQ3 | 方法对开放时间有多敏感？ | 宽度从 1.80 s 缩到 0.80 s 时性能下降，但慢于基线 |
| RQ4 | 大幅平移、旋转与形变是否导致 OOD 退化？ | 高幅条件下仍优于基线，但低于 ID |
| RQ5 | 特权预览、课程和残差先验是否必要？ | 去掉任一核心部件都会降低成功率或时间裕度 |
| RQ6 | 性能是否以更高控制代价换取？ | 同时报告能耗与旋翼饱和率，不只报告飞行时间 |

RQ1 是唯一主假设，其余为次要假设。主结论只使用预先指定的 ID 条件。

## 2. 场景与可通行性

ID 场景固定为：

```text
4 个窗口；路线半径 5.2 m；episode 26 s；控制周期 0.04 s
运动幅度倍率 1.8；局部形变倍率 2.0
独立不规则重复机会；平均宽度 1.40 s；平均重现间隔 3.80 s
边缘连续过渡 0.32 s
闭合尺度 0.16；开放尺度 1.05；日程抖动 ±0.22 s
```

窗口物理区域为 \(\Omega_i(t)\)，真实安全穿越区为

\[
\Omega_i^{safe}(t)=\Omega_i(t)\ominus B(0,d_{safe}).
\]

当 \(\operatorname{area}(\Omega_i^{safe}(t))<10^{-4}\,m^2\) 时定义为不可通行。闭合期间物理多边形仍须有效且面积严格大于零；禁止用删除窗口、瞬时跳变或凸包近似制造“关闭”。开放/闭合尺度由 smoothstep 连续连接。

### 2.1 窗口独立性

场景 seed 通过 `SeedSequence` 分裂成互不共享状态的随机流。对每个窗口 \(i\)：

- stream 0 只生成开放相位、开放宽度和不规则重现间隔；
- stream 1 只生成中心平移和姿态变化；
- stream 2 只生成整体尺度与局部边界形变。

第一个开放起点从自身相位区间独立采样，之后按带随机扰动的 renewal process
产生开放机会。不同窗口不使用同一个相位，也不按窗口序号依次开放。生成器的输入中
没有无人机位置、速度、策略动作、路线长度或预计到达时间；日程在 reset 时一次生成，
随后整回合固定。无人机只能观察和适应窗口，不能触发窗口开放。

单次机会只作为额外压力测试：其开放起点在整个 episode 中独立均匀采样，不用于 ID
主结论。

每个生成实例在评估前执行几何审计：

- 所有密集采样时刻物理多边形有效、连通、无洞且面积大于零；
- 每个窗口至少存在一个可通行时刻和一个不可通行时刻；
- 窗口安全包络的两两间隔满足设定阈值；
- 记录最小/最大安全面积、可通行比例和机会数量。

审计失败表示生成器缺陷：停止整组实验、修复后从预注册种子重新运行，不能静默换种子。

## 3. 方法与公平对照

主要方法：

- **FAPP-PPO**：有限未来预览 actor、整条剩余路线特权 critic、机会特征、日程感知名义 CTBR 和 PPO 有界残差。

非学习基线：

- **Nominal-Reactive**：同一动力学、锚点和 CTBR 控制器，但不读取开放日程；
- **Nominal-Schedule**：读取开放日程，可在门前等待，但没有学习残差。

消融：

- `reactive_actor`：actor 只有当前帧，不含机会特征；
- `no_privileged_critic`：去掉 critic 的绝对时间和剩余路线；
- `no_schedule_nominal`：名义控制器不知道开放日程；
- `no_residual_prior`：去掉残差先验；
- `no_curriculum`：直接训练最难的独立不规则重复机会；
- `small_motion_training`：只在倍率 1.0 的小幅运动/形变上训练；
- `no_residual`：等同 Nominal-Schedule，已由非学习基线覆盖。

学习方法使用相同网络容量、总环境步数、优化器、动作界限、训练种子和评估场景。消融不能因输入减少而获得更多训练步。

## 4. 训练协议

正式配置为 `configs/train_opportunity_default.yaml`：

- 每种学习方法使用 5 个独立训练种子：`17,29,41,53,67`；
- 每个种子 `500 × 512 × 8 = 2,048,000` 个环境步；
- 课程为 `static 50 / moving 80 / deforming 120 / full 250` 次更新；
- 训练种子与评估种子完全分离；
- 只用最终 checkpoint 报告主结果，不挑选中间 checkpoint；
- 超参数只能在独立开发种子 `10000..10099` 上调整一次。

| Motion-low | 独立不规则重复 | 1.40 | 1.20 | 2.00 | 0.22 | 幅度曲线 |

## 6. 指标与失败分类

唯一主要指标：

- **闭环成功率**：按序合法穿过全部四窗，无碰撞/乱序，并在时限内同时满足位置、速度、姿态和角速度返回容差。

次要指标：

- 成功回合闭环时间，失败回合不能用 horizon 代替；
- 平均合法穿越数与机会捕获率；
- 每窗穿越的最小/平均时间裕度；
- 错失机会数、目标关闭时的累计等待时间；
- 窗口/地面碰撞率、乱序率和超时率；
- 成功回合旋翼推力平方积分能耗代理；
- 至少一个旋翼饱和的控制步比例；
- 最终四类闭环状态误差。

失败互斥分类为 `window_collision`、`floor_collision`、`workspace_exit`、`order_violation` 或 `timeout`。保存逐回合记录，并提供代表性失败视频。

## 7. 统计方案

- 成功率给 Wilson 95% 置信区间；
- 同一场景种子上与基线的成功/失败用双侧 exact McNemar 检验；
- 多条件比较用 Holm 校正，显著性水平 0.05；
- 闭环时间只在“两方法都成功”的配对子集比较，报告 10,000 次配对 bootstrap 的均值差和 95% CI；
- 五个训练种子报告均值、标准差和最差种子，并对“训练种子—场景种子”做分层 bootstrap；
- 同时报告效应量，不只给 p 值；
- 零成功方法的时间记为不可估计，不能写成 26 s。

主结论成立需同时满足：ID 成功率方向符合假设、Holm 校正后显著、五个训练种子至少四个方向一致。OOD 与消融只支持次要结论。

## 8. 可复现命令

小预算链路验证：

```bash
python -m closed_loop_deformable_window.fapp_ppo.train \
  --config closed_loop_deformable_window/fapp_ppo/configs/train_opportunity_smoke.yaml
```

正式训练与消融：

```bash
python -m closed_loop_deformable_window.fapp_ppo.train \
  --config closed_loop_deformable_window/fapp_ppo/configs/train_opportunity_default.yaml

python -m closed_loop_deformable_window.fapp_ppo.ablation \
  --variant all --seeds 17,29,41,53,67
```

九条件配对评估：

```bash
python -m closed_loop_deformable_window.fapp_ppo.academic_experiments \
  --checkpoint <CHECKPOINT> \
  --suite default --episodes 200 --seed-start 50000
```

可以追加多个 `--extra-checkpoint NAME=PATH`，在完全相同的场景上加入消融或其他训练种子。输出包括逐回合 CSV、汇总 CSV、几何审计、McNemar/配对 bootstrap、manifest 和论文图。
