## 2026-09-10：安全软积分进入新算法的前置 L-BFGS

- Dual-Constraint CEM SC-DynaTOGT 不再把原始 SC 的贴边时间最优解直接当作唯一 CEM 中心。新算法先在相同 `[K,D]` 和 MINCO 参数化上优化“原 TOGT 目标 + 固定权重安全软积分”，再启动双约束 CEM。
- 安全项使用规划半径 `r_body+15 mm`，像动力学项一样在全部 MINCO 段的 8–32 区间时间网格直接积分 `smoothedL1(rho_plan^2-z^2-d_soft^2)`；L-BFGS 与 CEM 使用同一积分，不先检测穿越区间。其梯度包含窗口自旋的绝对时间效应，并经 MINCO、SC Jacobian 与 K 时间映射反传。
- CEM 的严格双零准入和最终独立硬验收保持不变。原始 `sc_dynatogt/` 和 Fixed-WP 继续作为不含安全目标的老方法对照；多中心与停滞重启暂不加入。
- 无内缩正式重跑必须从原生 `d=0`/几何时长冷启动，不读取旧实验 baseline 或候选；已验证的 SC 几何预处理缓存允许直接加载并记录加载时间。CEM 以首次双零后 5 轮为正常停止，300 轮只作无解兜底。
