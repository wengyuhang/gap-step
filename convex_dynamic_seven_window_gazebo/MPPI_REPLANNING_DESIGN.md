# 时空可行裕度触发的 MPPI–TOGT 分层规划控制

> 状态：算法与实验设计，尚未实现或形成闭环实验结论  
> 日期：2026-09-12  
> 对象：七个异形凸动态窗口、指定穿越顺序、H=3 动态 TOGT 滚动轨迹

## 1. 方法摘要

本文考虑外生平移与旋转凸窗口下的序贯穿越问题。离线或上一次在线优化所得轨迹会因闭环状态偏差、窗口预测误差和计算延迟逐渐失去时空可行性，而仅提高重规划频率会引入不必要的计算开销。为此，拟提出 **Event-Triggered MPPI–TOGT（ET-MPPI-TOGT）**：一个由时空可行裕度驱动的双层随机规划控制框架。

上层 Dynamic-TOGT 在窗口域中联合优化穿越位置、穿越时刻和分段多项式，并输出具有 PVAJ 边界的有限窗口参考；下层 MPPI 在系统动力学上直接优化控制序列，并以有序窗口进度而非绝对时间状态误差作为主要任务变量。两层通过预测切换时刻的 PVAJ 状态和鲁棒安全窗口耦合。只有当当前参考的时空可行裕度、性能价值或有限时域可恢复性发生显著退化时，才触发新的上层优化。

方法由三个相互独立的机制组成：

1. **参考生成**：H=3 Dynamic-TOGT 从预测切换状态开始求解；原始开口按整机包络、闭环误差管和窗口预测误差做时变内缩。
2. **随机最优控制**：MPPI 以 100 Hz 优化窗口进度、穿越时序和控制代价，允许偏离已经老化的时间参数化参考；碰撞 rollout 被视为不可行样本，而非仅施加有限软惩罚。
3. **事件触发与安全监督**：统一事件函数监测鲁棒净空、价值退化、窗口预测创新量和样本可行性；当剩余安全时间不足以覆盖重规划延迟时，由独立安全策略接管。

过门事件触发的是离散任务模式切换，风险事件触发的是连续轨迹更新，两者在定义上分离。`0.20 s` 周期刷新仅作为最大允许驻留时间，用于覆盖未建模慢漂移，不是算法的主要重规划原则。

## 3. 总体架构

```text
状态估计 + 窗口状态估计
        │  100–200 Hz
        ▼
时间对齐 / 门索引管理 ───────────────┐
        │                            │
        ▼                            ▼
MPPI（100 Hz）                 安全监督（≥200 Hz）
跟踪 + 进度 + 局部避碰          净空/TTC/预测失配
        │                            │
        ▼                            ├── 紧急滤波或逃逸
飞控指令                         │
                                     └── 异步请求 H=3 TOGT
                                               │
                                       候选轨迹验证
                                               │
                                      未来时刻原子切换
```

线程之间只传带时间戳的不可变快照。重规划在后台运行，不能阻塞 100 Hz MPPI；新轨迹通过验证后才以原子方式切换。

## 4. MPPI 控制器

### 4.1 状态、输入与预测模型

建议状态采用

\[
x=[p,v,q,\omega],
\]

输入优先使用四桨推力；若第一版直接接 PX4 级联内环，则使用总推力与三轴体速率，并在论文中明确这不是同一个执行模型。窗口状态由时间参数化运动模型和在线估计共同给出：

\[
G_i(t)=\{c_i(t),R_i(t),\dot c_i(t),\omega_i^G(t),\Sigma_i(t)\}.
\]

`Σ_i(t)` 表示门位姿预测不确定性，不能只保存理想正弦参数。

首版建议参数如下，均为待标定初值而非实验结论：

| 参数 | 初值 |
|---|---:|
| 控制频率 | 100 Hz |
| 预测时域 | 1.0 s |
| rollout 步长 | 0.02 s |
| rollout 数量 | 4096（GPU） |
| 每周期更新轮数 | 2 |
| 控制序列初始化 | 上周期序列左移 + 末端保持 |
| 门框近邻几何检查步长 | ≤5 ms 或保守扫掠检测 |

20 ms 动力学节点不足以直接检测薄门框。rollout 接近门平面时必须细分几何检查，或对相邻节点间的无人机与运动门框做保守扫掠相交测试，避免穿透采样。

### 4.2 目标函数

对 rollout `k` 使用：

\[
J_k = w_g J_{gate-progress}+w_cJ_{contour}+w_tJ_{ETA}
    +w_uJ_{control}+w_{\Delta u}J_{smooth}+w_rJ_{reference}+J_{terminal}.
\]

- `J_gate-progress`：最大化按顺序穿越窗口的进度，而不是只最小化对旧时间轨迹的状态误差。
- `J_contour`：约束无人机靠近当前安全通道，但允许沿通道方向调整相位。
- `J_ETA`：使预测过门时刻落入当前窗口的安全时间区间。
- `J_reference`：只作弱正则，且参考越旧权重越低；不能让过时轨迹压过实时避碰。
- `J_control`、`J_smooth`：限制推力、体速率及输入变化。

下列条件是**硬拒绝**，不是有限权重软惩罚：

1. 姿态长方体与任意运动门框相交；
2. 推力、角速度或倾角超过冻结动力学上限；
3. 从门框外侧绕过当前门平面，却试图增加门索引；
4. 预测穿越点的整机投影不完全位于内缩后的开口中；
5. 到门时刻不属于安全时间区间，且时域内无法减速等待或转移到安全区。

如果硬拒绝后无有效样本，控制器不得从“代价最小但仍碰撞”的样本中选指令，而要报告 `NO_SAFE_ROLLOUT` 给安全监督。

### 4.3 门索引更新

门索引只在相邻两个真实控制周期之间满足以下全部条件时递增：

- 无人机中心对门平面的有符号距离发生规定方向的过零；
- 过零时刻插值得到的整机投影位于安全开口内；
- 门序号等于当前目标门；
- 该时间段没有门框碰撞。

不能用“离门中心最近”或“轨迹时间已到”切换门索引。这一时序一致的过门逻辑直接借鉴 ICRA 2026 reference-free racing MPPI 的稳定门索引切换思想。

## 5. 参考轨迹老化的数学定义

轨迹老化不定义为单纯的墙钟时间增长，而定义为当前参考相对于最新状态与环境预测的**时空可行性和闭环价值退化**。每个控制周期将状态投影到参考轨迹的未来部分，得到相位对齐时刻 `t_ref*`，并计算：

- 马氏状态偏差
  \(e_x^2=(x-x_r)^\top\Sigma_x^{-1}(x-x_r)\)；
- 下一窗口的穿越时序残差
  \(e_\tau=|\hat\tau_{cross}-\tau_{ref}|\)；
- 未来 `T_safe=1.0 s` 上的最小鲁棒净空 `m_pred`；
- 窗口运动模型的预测创新量 `e_G`；
- MPPI 当前最优值相对于参考生成时预测值的退化量
  \(\Delta V=V_{now}-V_{ref}\)；
- 满足动力学、几何和有序过门约束的 rollout 比例 `ρ_safe`；
- MPPI 末端状态到下一鲁棒安全开口或安全等待集的可恢复性 `\nu_T`。

净空采用跟踪管膨胀后的定义：

\[
m_{pred}=d(\mathcal B(x),\partial W(t))-m_{track}-m_{gate}-m_{num},
\]

其中 `m_track` 和 `m_gate` 分别由闭环误差与门预测误差的高分位统计得到。第一轮可用 P99 或 conformal calibration 得到经验界；在形成严格界前只能称为风险感知安全余量。`ν_T` 不宣称精确计算可生存核，第一版以“是否存在可到达下一安全开口/等待集的有效 rollout”作为有限样本代理。

## 6. 时空可行裕度事件触发器

定义归一化事件函数

\[
\mathcal E(t)=\max\left\{
\frac{\bar m-m_{pred}}{\bar m},
\frac{e_x-\bar e_x}{\bar e_x},
\frac{e_\tau-\bar e_\tau}{\bar e_\tau},
\frac{e_G-\bar e_G}{\bar e_G},
\frac{\Delta V-\overline{\Delta V}}{\overline{\Delta V}},
\frac{\bar\rho-\rho_{safe}}{\bar\rho},
\frac{\bar\nu-\nu_T}{\bar\nu}
\right\}.
\]

当 `𝓔(t)≥0` 持续给定消抖时间时，认为旧参考已经越过允许的可行/性能边界并触发 Dynamic-TOGT。这个写法把原本互不相关的经验阈值统一为一个可分析的混杂事件面；各分量仍应分别记录，以便识别触发原因。滞回边界 `𝓔_on=0`、`𝓔_off<0` 与最小驻留时间共同避免 Zeno 式重复触发。

### 6.1 强制触发

以下离散事件绕过连续事件函数，立即请求一次 H=3 重规划：

1. 合法穿过当前门；
2. `a_ref ≥ 0.20 s`，作为 5 Hz 周期保底；
3. 新候选轨迹被拒绝后，原参考仍继续执行了 `0.10 s`。

### 6.2 事件函数的初始标定

以下为第一版启动阈值，后续必须通过验证集标定：

| 条件 | 正常重规划阈值 | 紧急阈值 |
|---|---:|---:|
| 预测净空 `m_pred` | `<0.15 m` 连续 3 个周期 | `≤0.05 m` |
| 状态残差 `e_x` | 超过验证集 P99；初始以 `e_p>0.12 m` 或 `e_v>0.8 m/s` 近似 | `e_p>0.25 m` 或 `e_v>1.5 m/s` |
| 下一门 ETA 误差 `e_τ` | `>0.08 s` | `>0.18 s` |
| 窗口创新量 `e_G` | 超过验证集 P99；初始以平移 `>0.05 m` 或转角 `>3°` 近似 | 平移 `>0.12 m` 或转角 `>8°` |
| 相对价值退化 `ΔV/|V_ref|` | `>20%` | `>50%` |
| 安全 rollout 比例 `ρ_safe` | `<10%` 连续 2 个周期 | `=0` |
| 终端可恢复 rollout 比例 `ν_T` | `<5%` 连续 2 个周期 | `=0` |
| `TTC` | `<t_plan,P99+t_valid,P99+0.10 s` | `<0.30 s` |

表中阈值用于确定 `𝓔` 各归一化分量的初始尺度。正常事件带 `0.10 s` 最小驻留时间和滞回；过门、`NO_SAFE_ROLLOUT` 与紧急条件绕过驻留时间。

`0.12 m` 位置阈值比现有 C++ NMPC 的 `0.2075 m` RMS 小，这不是说当前系统已能满足它，而是把该误差明确判为必须重规划/改善控制的异常。阈值最终应根据无碰撞闭环数据重新标定。

### 6.3 是否等待重规划

令

\[
D_{need}=t_{plan,P99}+t_{validate,P99}+t_{switch}+0.10\;s.
\]

- 若 `TTC > D_need`：后台重规划，MPPI 暂时继续使用旧参考并保持硬避碰；
- 若 `0.30 s < TTC ≤ D_need`：同时重规划和启用安全滤波；
- 若 `TTC ≤ 0.30 s` 或 `ρ_safe=0`：不等待规划器，立即执行预验证的逃逸动作。

“悬停”不应作为唯一紧急策略，因为移动门框可能扫过悬停位置。每扇门前后应离线或在线维护一个门框不可扫入的安全等待区；紧急动作在制动、退回上一安全区和穿过当前安全开口之间选择预测风险最小且已验证的一项。

## 7. H=3 重规划器接口

### 7.1 起点状态与延迟补偿

重规划不能从请求时刻的旧状态开始。设预计切换时刻

\[
t_s=t_{now}+\hat t_{plan,P99}+\hat t_{validate,P99}+t_{guard}.
\]

用当前 MPPI 最优控制序列前向积分到 `t_s`，得到规划起点 `PVAJ_s`：

- `P,V` 来自预测状态；
- `A` 由姿态与总推力恢复；
- `J` 由预测输入变化和刚体模型解析恢复，不能直接对带噪位置做三阶差分；
- 第一版若 `J` 不稳定，可对参考 jerk 与模型恢复 jerk 做有界融合，并单独消融。

这样新旧轨迹在未来切换点满足 PVAJ 拼接，而非在求解完成后把实际状态硬接到一条过去起点的轨迹上。

### 7.2 局部问题

- 视界：从当前未穿门开始最多看 3 扇门；接近终点时补上返回终态。
- 左端：固定为延迟补偿后的 `PVAJ_s`。
- 中间门：穿越点和穿越时间共同优化。
- 视界末门：穿越点仍自由；当前“移动停止端”版本令右端 `V/A/J=0`，但只执行到第一扇门，下一次规划的左端仍来自真实执行状态。
- 窗口时间：用绝对仿真/系统时间求门位姿，不能在每次重规划时把窗口相位清零。

末端停止只是短视界正则，不代表飞到第三扇门后真的静止。实验中应把它和“自由右端 PVAJ”作为消融项，因为停止端可能扭曲第一段时间分配。

### 7.3 规划安全余量

对门 `i`、候选穿越时刻 `t_i`，先将开口按整机在门平面内的支撑函数内缩，再减去鲁棒跟踪管：

\[
W_i^{safe}(t_i)=W_i(t_i)\ominus
\left(\Pi_i\mathcal B\oplus E_{track}\oplus E_{gate}\oplus E_{latency}\right).
\]

若 `W_i^safe(t_i)` 为空，该时刻不可穿越；规划器应改变穿越时间，而不是降低碰撞惩罚。安全时间区间是满足 `W_i^safe(t)≠∅` 且存在动力学可达连接的时间集合。这一处理借鉴 ICRA 2025 SIMP 的 safe interval 思想，但这里的配置是“具有整机和误差膨胀的窗口穿越状态”。

仅约束过门点仍不足以保证两门之间不撞到其他运动门框。候选生成后至少要检查完整可执行前缀；正式安全方案应把连续段-运动门框约束并入规划或使用连续域认证器。

## 8. 新轨迹验收与切换

新轨迹必须同时满足：

1. 优化器返回数值有效解；
2. 从 `t_s` 开始与预测 PVAJ 连续；
3. 推力、角速度、倾角及其实现所需输入均通过冻结动力学口径；
4. 指定门顺序、方向和安全开口穿越成立；
5. 至少对下一扇门前的可执行前缀做 ≤1 ms 整机-动态门框稠密审计；
6. 新轨迹的最小鲁棒净空不低于旧轨迹，紧急情况下还必须为正；
7. 轨迹时间戳仍新鲜，验证完成时没有错过其切换点。

通过后在 `t_s` 原子切换。验证失败时保留旧轨迹只允许到其**已验证安全前缀**末端；若该前缀不足以覆盖下一次求解，则进入安全等待/逃逸，而不是无限继续追踪旧轨迹。

稠密审计只是数值证据，不是连续域安全认证。论文中必须分别报告优化成功、采样安全、Gazebo 零接触和连续域认证；没有认证时不得使用“guaranteed collision-free”。

## 9. 独立安全滤波

推荐在 MPPI 输出与飞控输入之间增加最小修改安全滤波器：

\[
u_{safe}=\arg\min_u\|u-u_{MPPI}\|_R^2
\quad \text{s.t. moving-frame safety constraints.}
\]

第一阶段可采用解析制动/逃逸库加高速几何监督；第二阶段再接 composite CBF 或可达集约束。ICRA 2025 的 Composite CBF 工作说明了把大量位置约束合成为可实时执行的多旋翼安全滤波器是可行方向；RSS 2025 的 NS-VIMPC 则说明 sampling-based MPC 需要额外处理预测时域之外的安全，而不能只依赖有限时域 cost。

在本项目中，安全滤波器还需显式处理运动门框速度。静态距离 CBF 直接套用到快速平移/旋转窗口并不成立，必须包含障碍时间导数或在相对动力学中定义安全函数。

## 10. 在线状态机

```text
TRACK
  ├─ 周期/过门/风险事件 ─> REPLAN_PENDING ─> VALIDATE ─> SWITCH ─> TRACK
  │                              │               │
  │                              └─超时──────────┘拒绝
  │
  ├─ TTC不足或无安全rollout ─> SHIELDED_ESCAPE ─> SAFE_WAIT ─> REPLAN_PENDING
  │
  └─ 完成G7且返回终点可达 ─> RETURN ─> FINISHED
```

伪代码：

```cpp
while (running) {
    Snapshot z = estimate_state_and_gates();
    Risk r = predict_risk(z, active_reference, mppi_solution);

    if (r.emergency()) {
        command = safety_filter.escape(z);
        request_replan_if_idle(predict_switch_pvaj(z));
    } else {
        command = mppi.solve(z, active_reference,
                             hard_dynamic_gate_constraints);
        if (gate_passed_legally(z) || reference_age() >= 0.20 ||
            r.normal_trigger()) {
            request_replan_if_idle(predict_switch_pvaj(z));
        }
    }

    if (planner.has_result() && validate(planner.result(), z)) {
        schedule_atomic_switch(planner.result());
    }
    send(command);
}
```

## 11. 实时预算

目标预算按单周期和异步任务分别验收：

| 模块 | 目标频率/时限 | 主要统计量 |
|---|---:|---|
| 状态与门预测 | 200 Hz，<2 ms | P50/P95/P99 |
| MPPI | 100 Hz，P99<10 ms | 超时率、安全 rollout 比例 |
| 安全监督 | ≥200 Hz，<2 ms | 最坏延迟、漏检数 |
| H=3 TOGT | 异步，P99<100 ms | 每次墙钟时间、核时间、调用数 |
| 候选验证 | P99<20 ms | 稠密样本数、拒绝原因 |
| 轨迹切换保护 | 20–40 ms | 实际切换时间误差 |

当前 5 次规划核最大 `27.36 ms` 支持“有希望低于 100 ms”，但不能直接作为在线 P99：文件解析、状态构造、线程调度、验证和轨迹发布都尚未计入。正式实验必须记录请求到可执行轨迹发布的端到端延迟。

## 12. 实验方案

先在同一 7 门、动态倍率 2.5 的赛道做四组，每组至少 30 个扰动种子：

| 组别 | 控制与重规划 | 目的 |
|---|---|---|
| A | MPPI + 固定初始轨迹 | 检验仅靠局部偏离能否补救轨迹过时 |
| B | MPPI + 5 Hz 固定周期 H=3 | 检验周期重规划收益与计算代价 |
| C | MPPI + 本文混合事件触发 H=3 | 检验同等安全下是否减少重规划 |
| D | C + 独立安全滤波/逃逸 | 检验有限时域之外和求解失败时的安全性 |

扰动包含：初始位置/速度误差、质量和推力模型误差、20–100 ms 门观测延迟、门相位误差、门速度突变、控制计算抖动和外力脉冲。之后再按动态倍率 `1.0/1.5/2.0/2.5` 做难度曲线。

必须记录：

- 完赛率、合法过门率、碰撞率及每门碰撞数；
- 飞行时间、各段时间、最小整机净空；
- 最大/积分推力、最大角速度、最大倾角、动力学违规量；
- MPPI P50/P95/P99、超时率和每周期有效 rollout 比例；
- 每次 H=3 规划的核时间、端到端时间、迭代/调用数与失败原因；
- 每圈重规划次数、周期触发/风险触发/过门触发占比；
- 漏触发、误触发、规划结果被拒绝次数、紧急滤波介入时长；
- 位置/速度 RMS 与 P95/P99、门位姿预测误差和 ETA 误差；
- MPPI cost 分解：进度、contouring、时间、控制、参考和终端项。

主图建议为：成功率/碰撞率随动态倍率曲线；飞行时间—最小净空 Pareto 图；重规划端到端延迟 CDF；每门时序图（净空、TTC、触发、规划完成和轨迹切换）；各方法计算时间箱线图。失败样本不得从统计中删除。

## 13. 实施顺序

1. **先修参考安全语义**：将整机内缩与完整前缀碰撞检查接入 H=3 求解/验收；否则 MPPI 实验会混淆“参考本来碰撞”和“控制跟踪失败”。
2. **离线 MPPI 回放**：读取冻结状态与门运动，验证硬拒绝、门索引和时戳逻辑。
3. **Gazebo 完美状态闭环**：先排除感知误差，确认 MPPI 和事件重规划实时性。
4. **PX4 SITL 闭环**：加入估计延迟、线程抖动和安全逃逸；达到零接触后再做扰动统计。
5. **可选连续域认证与真机**：只有在名义连续安全和闭环鲁棒界明确后进入；Gazebo 零接触不等于真机安全。

## 14. 拟验证的学术贡献

现阶段不应把“使用 MPPI”“滚动 H=3”或“事件触发”单独声称为创新，因为这些组成思想已有充分先例。可成立的贡献需要落在以下问题结构与可验证结论上：

1. **时变窗口任务的双层统一建模**：将连续控制层的随机最优控制与窗口层的穿越位置—时间联合优化，通过未来切换 PVAJ 和绝对窗口相位严格耦合。与独立跟踪器加独立规划器不同，触发量直接来自两层共享的时空可行残差。
2. **时空可行裕度触发机制**：以鲁棒净空、时序残差、价值退化和末端可恢复性共同刻画参考老化。理论上可研究最小事件间隔，以及在有界估计误差与有界求解时间下，新规划完成前安全前缀不被耗尽的充分条件。
3. **延迟一致的 PVAJ 轨迹更新**：把规划延迟显式纳入边界条件，在未来切换状态而非请求状态上构造新轨迹，从而保持多项式轨迹连续性并减少异步规划导致的动态跳变。
4. **整机—窗口—跟踪误差的统一鲁棒几何**：通过时变 Minkowski 内缩把机体姿态投影、跟踪误差管、窗口预测不确定性和切换延迟统一到安全开口与安全时间区间中。

论文的关键假设可以表述为：窗口运动预测误差有界，闭环扰动属于已标定集合，上层求解与验证延迟具有已测上界，并且当前安全前缀长度大于该延迟。由此可尝试证明：在每次候选验收成立、事件检测无延迟超界且安全接管集合前向不变的条件下，轨迹切换不会破坏 PVAJ 连续性，且执行状态在相邻重规划事件之间保持于鲁棒安全集。若没有完成这一证明，应将结果准确描述为“风险触发和采样验证”，不能写成递归可行或严格安全保证。
