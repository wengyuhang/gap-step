# AVS-PPO 算法说明

## 1. 为什么选安全动作掩码赛道

穿窗竞速的安全事件是 state-wise 的：一次穿越点落在 U 形凹槽里就是失败，不能靠整回合平均成本抵消。AVS-PPO 因此不用“碰撞惩罚 + 普通 PPO”作为安全机制，而是在采样之前构造当前状态的安全动作集合。

令离散参数化加速度库为 \(\mathcal A\)，停车备份策略为 \(\pi_b\)。对于状态 \(s\) 和候选 \(a\)，先执行一步 \(a\)，再 rollout \(\pi_b\)。若候选一步以及备份轨迹中的每次门平面交点都满足真实非凸窗口裕度，并且备份能在下一门前停止，则

\[
m(s,a)=1,
\]

否则 \(m(s,a)=0\)。策略分布为

\[
\tilde\pi_\theta(a\mid s)=
\frac{m(s,a)\exp z_\theta(s,a)}
{\sum_{a'}m(s,a')\exp z_\theta(s,a')}.
\]

训练采样、旧 log probability 和新 log probability 都使用同一个状态掩码，所以 PPO 优化的是实际执行分布，不存在“先采危险动作、再投影成另一个动作”的 action mismatch。

## 2. 连续交点与非凸安全判定

一步内加速度 \(a\) 恒定：

\[
p(\tau)=p_0+v_0\tau+\tfrac12a\tau^2,\qquad 0\leq\tau\leq\Delta t.
\]

对当前门平面 \(x=x_g\) 解二次方程得到最早正根 \(\tau_g\)，再计算同一时刻的 \(y,z\) 交点。窗口边界在 \(t+\tau_g\) 查询，包含平移、面内旋转和各向异性缩放。安全条件是

\[
d_{\Omega_g(t+\tau_g)}(p_{yz}(\tau_g))
\ge r_{drone}+r_{guard}=0.195\;\mathrm m,
\]

其中有符号距离在真实简单多边形上计算；凸包内但 U 形凹槽中的点会得到负裕度。

## 3. 可恢复性盾牌

动作 0 是控制不变量备份：纵向使用有界制动直到速度为零，同时横向跟踪下一动态窗口的保守内部锚点。每个非备份动作只有在“该动作 + 最多 36 步备份”验证通过时才可采样。若任何状态没有安全动作，实现会抛出 `RuntimeError`，不会自动放宽裕度。

安全结论依赖两个前提：初态在可恢复集内；窗口运动与动力学和仿真器一致。该实现给出的是模型内安全盾牌和数值审计，不声称 Arb/区间算术级连续域证书。

## 4. PPO

actor-critic 使用两层 Tanh MLP。显式 `model_old` 采样，`model` 使用 clipped surrogate 更新，每轮 rollout 后同步。GAE 用于优势估计。KL early stop 使用标准非负近似

\[
\widehat D_{KL}=\mathbb E[(e^{\Delta\log p}-1)-\Delta\log p]\ge 0.
\]

奖励只优化性能：正向进度、合法穿门奖励、完赛奖励和每步时间成本。即使移除安全惩罚，危险动作仍不会进入采样支持集。

## 5. 验收标准

- 收敛：0-update 确定性策略不完赛，最终策略在独立 200 回合达到至少 95% 成功；后 3 个评估点成功率不下降且时间进入平台；
- 安全：训练评估与独立 200 回合审计均为 0 次违规，所有有效穿越裕度不小于 `0.195 m`；
- 可复现：固定配置、seed、checkpoint、CSV 曲线和 JSON 审计齐全；
- 限定：这些标准只覆盖 README 中定义的仿真模型，不外推为真实飞行认证。
