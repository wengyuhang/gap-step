# AVS-PPO 实验记录

日期：2026-08-25。正式结果目录：`results/formal_seed7_final/`。本文件只记录加入精确恒加速度交点和停车备份不变量后的最终运行；更早的 smoke/中间运行不用于结论。

## 正式训练

- seed：7；
- 60 个 PPO update，8 个并行环境，每次 128 步，共 61,440 个训练环境步；
- 每 10 个 update 在固定的 40 个开发种子上确定性评估；
- `best.pt` 为 update 40；`final.pt` 为 update 60；
- 安全阈值：机体 clearance `0.16 m` + 几何 guard `0.035 m` = `0.195 m`。

| update | 成功率 | 平均成功时间 / s | 最小穿越裕度 / m | 违规数 |
|---:|---:|---:|---:|---:|
| 0 | 0% | — | — | 0 |
| 10 | 100% | 4.800 | 0.241427 | 0 |
| 20 | 100% | 4.800 | 0.241427 | 0 |
| 30 | 100% | 4.293 | 0.195001 | 0 |
| 40 | 100% | 4.290 | 0.195206 | 0 |
| 50 | 100% | 4.290 | 0.195559 | 0 |
| 60 | 100% | 4.290 | 0.195559 | 0 |

从 update 0 的 0% 到 update 10 的 100% 表明策略学会了离开停车备份并完成任务；update 40--60 成功率、时间和价值损失进入平台，作为本实验的经验收敛证据。update 30 有一次 PPO KL early stop，后续 update 未出现失稳。

## 未见种子审计

使用 `best.pt`，种子与训练/开发不重叠。

| 分布 | 回合 | 成功率 | 违规数 | 平均成功时间 / s | 最小裕度 / m |
|---|---:|---:|---:|---:|---:|
| ID，seed 50000--50199 | 200 | 100% | 0 | 4.295 | 0.195046 |
| OOD，seed 70000--70199 | 200 | 100% | 0 | 4.360 | 0.195006 |

OOD 把窗口运动幅值从 `1.0` 提到 `1.15`，domain randomization 从 `0.12` 提到 `0.30`。两个审计的最小裕度都超过 `0.195 m`；相对物理半径仍保留至少约 `0.035 m` guard。

## 结论边界

在 README 定义的确定性三维平移仿真模型内，验收标准已满足：策略成功收敛，400 个独立审计回合共 1,200 次合法非凸动态门穿越，0 次安全违规。这里没有六自由度姿态/电机、感知噪声、模型不确定性、厚门框或区间算术证明，因而不得写成真实四旋翼硬安全认证。
