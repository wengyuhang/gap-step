# 非凸时变窗口穿越问题定义

本项目的研究基础是论文 [*Time-Optimal Gate-Traversing Planner for Autonomous Drone Racing*](../复现/论文/2309.06837v3.pdf) 中提出的 TOGT（Time-Optimal Gate-Traversing，时间最优窗口穿越）问题。

论文研究的是：在考虑四旋翼无人机动力学和执行器限制的情况下，生成一条按指定顺序穿过多个窗口的最短时间轨迹。论文中的窗口主要用球形区域、凸多边形或凸多面体表示。

本项目保留论文中“按指定顺序穿越窗口并优化飞行时间”的基本任务，将窗口从原来的凸形、静态区域扩展为**非凸且随时间变化的区域**。当前只考虑指定顺序中每个窗口穿越一次的情况，暂不考虑重复穿越同一个窗口。

## 1. 非凸窗口的几何约束

每个窗口位于三维空间中的一个平面上，其有效穿越范围是该平面内的二维非凸区域。窗口可以是：

- L 形、U 形等由折线围成的非凸区域；
- 星形、齿轮形、波浪形等轮廓较复杂的区域；
- 月牙形、豆形等具有光滑曲线边界的区域；
- 由直线段和曲线段共同组成的混合边界；
- 通过一组有序边界采样点描述的其他任意非凸形状。

当前的问题范围主要限定为**无洞的简单闭合区域**，即：

- 窗口边界必须闭合；
- 边界不能自相交；
- 窗口内部不包含孔洞；
- 窗口必须具有非零的可穿越面积。

非凸窗口的关键特征是存在向区域内部凹入的边界。一个点即使位于窗口的凸包中，也不一定位于真实的可穿越区域内。例如，U 形窗口中间的凹槽虽然位于凸包内，但它实际上属于窗口外部，无人机不能从该区域穿过。

因此，无人机的穿越点必须满足：

- 位于窗口当前所在的三维平面上；
- 位于窗口真实的非凸区域内；
- 不能落入窗口的凹陷区域；
- 不能只使用窗口的凸包判断穿越是否有效；
- 应当与窗口边界保持一定的安全距离；
- 对于光滑曲线边界，还需要考虑边界表示误差对穿越有效性的影响。

## 2. 窗口随时间变化

论文中的窗口约束主要是与空间位置有关的静态几何约束。本项目进一步考虑窗口的位置、姿态和尺寸会随时间变化。

每个窗口可能发生：

- **平移**：窗口中心在三维空间中随时间移动；
- **旋转**：窗口局部坐标系及其所在平面的方向随时间改变；
- **缩放**：窗口的大小或可穿越面积随时间改变；
- **组合变化**：窗口同时发生平移、旋转和缩放。

记第 \(i\) 个窗口在时刻 \(t\) 的真实可穿越区域为：

\[
G_i(t) \subset \mathbb{R}^3.
\]

若无人机在时刻 \(t_i\) 穿越第 \(i\) 个窗口，无人机的位置 \(p(t_i)\) 必须满足：

\[
p(t_i) \in G_i(t_i).
\]

因此，穿越时间和穿越位置不能彼此独立地确定：

- 改变穿越时间会改变窗口的位置、姿态和大小；
- 窗口状态变化会改变可选择的穿越位置；
- 穿越位置变化会改变前后轨迹的长度和形状；
- 轨迹变化又会影响无人机抵达窗口的时刻。

因此，该问题不是单纯的静态路径规划，而是一个同时包含空间变化和时间变化的时空轨迹规划问题。

## 3. 按照指定顺序穿越窗口

给定无人机的初始状态、终止状态、多个非凸动态窗口以及预先确定的窗口顺序，无人机必须按该顺序依次穿越所有窗口，然后到达终止状态。

例如，指定的窗口顺序可以是：

```text
G1 -> G6 -> G3 -> G2 -> G5 -> G4
```

对于包含 \(L\) 个窗口的任务，需要确定一组严格递增的穿越时刻：

\[
0 < t_1 < t_2 < \cdots < t_L < t_f,
\]

其中：

- \(t_i\) 表示无人机穿越第 \(i\) 个窗口的时刻；
- \(t_f\) 表示整条飞行轨迹的结束时刻；
- \(p(t_i)\) 表示无人机在穿越时刻 \(t_i\) 的三维位置。

每个窗口的穿越条件为：

\[
p(t_i) \in G_i(t_i), \qquad i=1,2,\ldots,L.
\]

同时，轨迹必须满足：

- 不能交换窗口的穿越顺序；
- 不能跳过指定的窗口；
- 当前任务中每个窗口只需穿越一次；
- 每个穿越位置都必须位于对应时刻的真实非凸窗口内；
- 无人机轨迹必须连续，并满足四旋翼的动力学和执行器限制。

在上述约束下，该问题的总体目标是寻找无人机状态轨迹 \(x(t)\)、控制输入 \(u(t)\)、各窗口的穿越时刻 \(t_i\) 和穿越位置 \(p(t_i)\)，使总飞行时间 \(t_f\) 尽可能小：

\[
\min_{x,u,t_1,\ldots,t_L,t_f} t_f.
\]

综上，本项目需要解决的是一个同时包含**非凸几何约束、窗口时变约束、指定穿越顺序和四旋翼动力学约束**的时间最优轨迹规划问题。
