# SC-DynaTOGT vs SIP-DynaTOGT：快速闭环实验

## 赛道

- 起点与终点：`[  0. -18.   4.]`（同一点）
- 窗口存储编号：`L_polygon -> circle_arc -> bezier_notch -> bspline_wave -> arc_capsule -> bezier_diamond`
- 指定穿越顺序：`(3, 4, 1, 5, 0, 2)`
- 六个窗口均含周期平移、完整 RPY 旋转和均匀缩放，所有周期不超过 3.1 s。
- 初始中心空间跨度：`[27. 26. 10.] m`。
- SIP 保留 24 个原始连续边界段：`{'Line': 14, 'CircularArc': 3, 'Bezier': 6, 'BSpline': 1}`；SC 稠密点数仅用于映射：`[3840, 2048, 3203, 3262, 3072, 2734]`。
- 两者使用同一长方体，半尺寸为 `(0.26504, 0.26504, 0.0589) m`。
- SC 映射使用长方体外接球半径加净裕度的保守中心内缩，要求 `0.394423 m`。
- SC/SIP 最终碰撞判定都使用姿态相关的精确长方体距离和 `0.015 m` 净距离。
