# 左小右大非凸窗口：SC 初值迁移实验

2026-10-12，用户要求的独立单窗实验。只验证当前局部规划器最终选点，不启动 Gazebo、不改生产算法。

## 冻结设定

- 左室 1.20×1.20 m，右室 3.20×3.20 m，连接通道长 0.40 m、宽 0.40 m，12 条真实有限边，无洞简单多边形。
- x500 外接球半径沿用 0.38594472 m；框半厚 0.085 m；安全余量 0.10 m；局部复查阈值合计 0.57094472 m。
  左室计入现有球/框/余量后每侧约余 0.029 m。不能把它说成只有机体球直径的开口；物理球额外余量还包含既有跟踪余量。
- 窗口平面固定 y=0、中心高度 3.2 m，沿世界 x 轴已知正弦平移，初相零。主测试 3 Hz / 2 m（中心峰值速度 37.70 m/s），静止对照只把振幅置零。
- 起点 (0,-6,3.2)、终点 (0,6,3.2)，两端静止 PVAJ。一个内部 P/V 节点、两段七次 minimum-snap MINCO，A/J 由 MINCO 消元。
- 目标仍只有总时间；继承当前逐桨推力/角速度/工作空间离散硬约束、有限边安全约束、局部 Bernstein/正弦包络复查和补见证机制。
- SC 映射原始物理多边形，没有内缩、凸包替换或房间标签决策。原 SC polylabel 归一化不变。
- 四个时间初值沿用当前 single_gate_stop_racing 规则，但**每个空间初值都固定左室中心 (-1,0)**。
  分别记录每个种子的迭代，不能把另一空间初值成功称作跨室迁移。第一次收敛且复查通过才接纳。
- 主诊断给 5 s 求解预算以观察收敛选点，另可独立测原 90 ms 预算；5 s 成功不代表在线达标。

当前 SC 默认逆映射在小房间失败；本实验仅离线沿室内中心线连续反求同一个左初值。
这一步不是轨迹求解、不是右室初值，也不改变 SC 映射。SC 解析雅可比与 CasADi 轨迹雅可比链式相乘。

### 能说明什么

- SC 映射的是连通的物理开口，机体安全区域却有两块。所有记录的 SC 候选都在真实多边形内，
  包括中间迭代；没有用凸包、房间标签、混合整数或右室重启替代主实验。
- 当前硬约束局部求解流程在此输入上没有跨过去。恢复和线搜索不要求所有迭代都可行，
  所以并非数学上禁止跨室；但允许不可行迭代不等于会主动越过约束残差较大的区域。
- 失败候选不是“左室局部最优解”：它们仍不可行，SLSQP 也未报告成功。
  不能由单次失败推断必须用混合整数、局部方法永远不能跨室，或左室一定物理不可行。
- 右初值对照只证明有通过当前验收的候选，没有证明完整硬动力学可行或实际飞行安全。

局部复查沿用两段多项式与移动有限边框的浮点 Bernstein/正弦包络；
静止/右初值分别 5/17 次区间细分通过，阈值 0.57094472 m；不是 Arb 有向舍入证书。
另外独立执行 1 ms 整段采样审计，不参与优化或接纳：
