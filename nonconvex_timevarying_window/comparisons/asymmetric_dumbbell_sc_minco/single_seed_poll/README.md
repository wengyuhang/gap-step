# 单左初值 + 非单调圆盘试探

2026-10-13。独立求解器变体，解决旧可行性恢复在左侧正违反量处停滞的问题；不修改共享算法。

算法只有一个轨迹初值：左室中心、现有规则给出的一个时间初值和原穿越速度。
先执行原最小二乘恢复和 SLSQP。若候选仍违反有限约束，则在当前 SC 单位圆盘点周围
沿 8 个对称方向、半径 0.125/0.25/0.5/1 评估试探端点。圆盘外端点丢弃；圆盘内
端点经原 SC 映射，始终在真实物理开口内。时间和速度继承停滞候选。

选取违反量平方和最小的**位移候选**，允许它比当前点更差，再继续同一个局部流程。
这一步明确是非单调的大范围探索，不称纯梯度下降，也不声称无需非局部搜索。
至多 3 次跳步；没有右室目标、房间标签、随机数、旧成功轨迹或第二个预设轨迹初值。
这是单初值的局部求解与远处试探组合，不是任意非凸问题的完备可行性求解器。

几何、运动、MINCO、原硬约束和见证补点不变。有限残差 >= -1e-5 后必须再通过原局部
几何复查；优化器成功标志不替代验收。动力学仍是 17 节点/段，另保存 1 ms 独立审计，
不得把节点通过升级为连续动力学证书。只做离线规划，无 Gazebo 飞行或实际碰撞结论。

初始全部 7 个变量逐项相同。停滞后评估 14 个圆盘内端点，自动选择物理点
(0.584937, 0.453425)；此时违反量平方和从 0.086954 增至 2.177458。
继续恢复和 SLSQP 后降至 3.48e-18，最小残差 -1.47e-9，在原 1e-5 容差内。
全部记录的 SC 候选在原始物理多边形内；没有第二个预设轨迹初值。

1 ms 独立审计：球/框/余量后最小净空 0.004376 m；逐桨上界仍超 0.4763%，
第二轴角速度最大 3.838144 rad/s，比 3.8 上界超 1.0038%。
这是原 17 节点动力学约束之间的漏洞，不因跨室成功而消失。
因此本轮解决的是该例的**单初值有限问题求解失败**，不能称完整连续动力学可行、
Gazebo 无碰撞或普遍单初值必成功；也没有达到 100 ms 在线预算。
