# 同一非凸窗口，单左初值的纯选点验证

2026-10-14。本实验只回答：不分凸块、不换空间初值、不额外作非局部试探，
普通局部优化能否通过 SC 参数化把选点从左室移到右室？不修改当前飞行规划器。

## 问题与边界

复用原 12 边物理多边形、3 Hz / 2 m 横摆、起终点 (0, ±6, 3.2)。
固定一个窗口查询时刻 t，只优化物理开口内部的二维点 q：

`min ||p(q,t)-start|| + ||p(q,t)-goal||`, `p(q,t)=c(t)+R(t)[:,:2]q`。

这是固定时刻的**几何选点子问题**。没有 MINCO、时间/速度决策、机体安全或动力学约束，
固定查询时刻不表示无人机能在该时刻到达，也不把两段直线称作可执行飞行轨迹。
代价没有目标房间标签或人为右侧吸引项；在 t=1.2 s，起终点直线与窗口平面的交点
对应局部 q=(1.1755705,0)，在右室。三角不等式给出此子问题的精确最优值 12 m。

两种坐标设置：原 polylabel 归一化，以及用圆盘自同构归一化到同一个左初值。
两者均映射原物理多边形，物理初值始终 (-1,0)，每个查询时刻各只执行一次 L-BFGS-B。
左归一化改变坐标尺度，但不读右侧答案、不增加初值、不改可选区域；保留原设置作对照。
保存所有目标评估和所有接受迭代。相邻迭代之间以**参数线段经 SC 映射的曲线**展示，
而不是把物理点用直线连接后声称该直线一定在非凸域内。显示的是优化过程，不是飞行。

冻结查询时刻 1.0、1.02、1.1、1.2 s：分别含通道、左室、左边界和右室最优位置。
1.1 s 的最优值为边界下确界，有限无约束变量无法精确到达 SC 开域边界；单独标注。
开发时曾因 state_at 返回数量解包错误而未开始求解，修正读取前两项后进行数值探索；
探索使用的 1.0/1.1/1.2 s 全部保留，不删除左侧/边界条件只报右侧条件。

## 与完整任务的区别

原开口连通，但 0.4 m 窄道小于 x500 外接球直径约 0.772 m，内缩后为两块。
纯选点迭代穿过窄道并不是整机安全的可行迭代。生产算法的硬安全约束未移除或放宽。
历史 full MINCO 单左初值普通局部求解失败；single_seed_poll 加非单调圆盘试探后找到
通过当前有限约束及局部几何检查的右侧候选，但仍存在节点间动力学超限，且不是纯局部法。
因此本实验只能提供“SC 不把点锁在人工凸分区”的存在性实例，不能证明完整安全迁移、
任意初值可行性、SC 性能优于其他参数化，或任意非凸问题无局部最优。

### 这个子问题为何存在一条连续下降的左右迁移路线

记 a=-c_x(1.2)=1.175570504585…，取 q(s)=(-1+(a+1)s,0)，0≤s≤1。
该线段在原多边形内部（窄道沿 y=0，宽 0.4 m），且

`J(q(s)) = 2 sqrt(36 + (a+1)^2 (1-s)^2)`。

因此 J 从左到右严格下降直到 12 m。精确 SC 与圆盘无约束变换内部均可逆，
所以此路线在参数域有连续原像，不存在人为凸块边界障碍。这个论证只证明存在
连续下降路线，不保证任意局部算法会找到它；本次普通 L-BFGS 的实际收敛另由原始记录支持。
机体半径大于窄道半宽，所以同一论证不能用于“全程机体可行的优化迭代”。
