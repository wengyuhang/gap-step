# 同一自旋单窗：SLSQP 与 IPOPT

3 Hz / 2 m 平移 + 2 圈/秒自旋；原几何、分区初值、SC、PV-MINCO、约束与见证交换。
每次从相同几何冷初值开始；计时包含所有区域/时间种子、恢复、优化和局部复查。
两方共用同一个预编译模型。IPOPT 使用解析一阶导数与 limited-memory Hessian。
