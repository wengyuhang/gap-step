# 机体内缩连通分区初始化：单窗口

2026-10-13，按用户要求只改变初值生成，独立于单左初值和非单调试探变体。

## 协议

- 使用原左小右大12边非凸窗口、原起终点，静止对照和3 Hz / 2 m横摆各一次。
- 原开口按机体球半径0.38594472 m做欧氏内缩，每个正面积连通块用polylabel选一个点。
  不按左右标签或历史结果挑选，不使用凸包，不做面积筛选。
- 此内缩**只用于初始化**。SC仍映射原物理多边形，选点、时间、内部V继续自由优化。
  0.085 m框半厚、0.10 m余量、0.005 m见证松紧余量仍按原约束处理，不降低安全标准。
- 每个空间初值沿用原四个时间种子、原恢复/SLSQP/见证交换/收敛及复查条件，
  每块取原流程的首条接纳结果，然后选择各块已接纳结果中名义总时间最短的一条。
- 所有块共享5 s求解预算，不是每块额外5 s。离线SC拟合、内缩、逆映射、图构建分别记录。
- 配对旧单左初值；两方复用同一个构建好的NLP，数学目标和约束完全相同。
- 默认未JIT，只做求解验证；可用`--jit`单独运行，不能混用两种耗时。
- 额外1 ms审计不参与优化或接纳；已有节点间动力学超限必须保留。
  无MPC/PX4/Gazebo，不把名义时间称为实飞竞速成绩。

GEOS圆弧内缩采用64段/象限的数值近似，非严格几何证书；代表点另以原有限边距离复核。
对于临界窄连接，分区数量可能对误差敏感。本例用128段/象限做回归核对。
每块一个初值不覆盖所有时间/速度分支，不保证可行性完备或全局最优。
SC逆映射失败与局部求解失败分别记录，不能将它们当作区域物理不可行。
