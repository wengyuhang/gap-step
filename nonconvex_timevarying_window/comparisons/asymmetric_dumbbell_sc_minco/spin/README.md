# 单非凸窗口：平移叠加法向自旋

2026-10-13，用户要求仍用当前内缩分区初始化算法，只给窗口增加自旋。

## 冻结设置

- 同一12边左小右大非凸窗口，窗口参考原点为原模型的(0,0,3.2)m，不是另移到多边形质心。
- 原3 Hz / 2 m世界x方向平移不变，平面始终y=0。绕移动参考原点、窗口法向匀速自旋：
  `c(t)=c0+(2*sin(6*pi*t),0,0)`，`R(t)=R0*Rz(2*pi*f_spin*t)`。
- 自旋0、0.5、1、2圈/秒，所有初相零，各一次；自旋频率与平移频率分别记录。
- 球半径内缩、每连通块一个polylabel初值、原SC物理域、两段七次PV-MINCO、原四时间种子不变。
- 原目标只有总时间，动力学/安全硬约束、容差、见证交换和各块共享5s预算不变；不按自旋重挑初相。
- 不启用非单调试探，不使用旧成功轨迹热启动；每个转速独立按几何初始化。
- 先未JIT做功能矩阵；JIT另存独立目录，不混用两种求解耗时。无Gazebo/闭环实飞。

## 必要的运动适配，不是关闭原验收

旧符号姿态与安全复查只支持平移。非凸实验基类新增默认等价的场景接口；旋转子类替换：

1. 优化每次查询真实旋转姿态，解析导数包含选点、到达时间引起的旋转变化。
2. 法向不变，因此仍对法向多项式求根，只细分机体可能接触窗口平面的区间。
3. 先用Bernstein控制值与平移正弦范围包围基础坐标，再对`q=Rz(theta)^T*q_base`
   使用sin/cos范围和区间乘积，得到旋转局部坐标包围盒。
4. 用原有限线段距离下界判定，原512细分/1us最小区间/2e-4违反容差不变；
   不通过时仍回到原见证补点流程，不把采样通过当包络通过。
5. 零自旋直接走旧检查器，作为兼容性回归。1ms独立审计也查询旋转姿态，不能复用旧固定姿态审计。

这仍是浮点数值包络，不是Arb证书。固定姿态外接球下，刚体旋转不改变局部内缩区域数量。
每块一个点只覆盖几何分支，不覆盖所有时间/速度/自旋相位分支；求解失败不等于场景无解。
动力学仍只在原节点强制，完整轨迹1ms审计的节点间超限必须保留。
