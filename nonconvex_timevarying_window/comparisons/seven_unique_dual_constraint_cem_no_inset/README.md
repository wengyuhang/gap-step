# 无内缩 SC 双约束 CEM

该消融实验沿用七异形分散闭环赛道和 Dual-Constraint CEM，只取消 SC 建图前的几何内缩：

- SC 映射拟合 Chang 重采样后的物理开口；严格共线直线段只保留端点，不改变窗口几何，曲线采样点保留。
- `rho = r_body + 15 mm` 不变，但不用于构造 SC 多边形，只用于安全软积分。
- 新算法前置 L-BFGS 的目标为原 TOGT 目标加 `100000 J_safe`；该改动只在 `dual_constraint_cem_sc_dynatogt/` 封装，不修改原始 SC-DynaTOGT。
- 严格双零仍指原始动力学软积分和安全软积分都精确为零。
- 最终动力学检测覆盖全程，最终碰撞检测只使用真实无人机外接球。
- 首次严格双零后继续 5 轮；候选按飞行时间升序逐条硬验收，首个成功立即停止。

这种分离允许 SC 参数域保持原物理开口的单连通拓扑，不要求内缩结果仍是单个无洞多边形。安全可通行性由独立软约束和最终硬检测决定。

正式入口：

```bash
conda run -n wyh python -m nonconvex_timevarying_window.comparisons.seven_unique_dual_constraint_cem_no_inset.experiment \
  --outdir nonconvex_timevarying_window/comparisons/seven_unique_dual_constraint_cem_no_inset/results/safety_lbfgs_cold_start_20260910 \
  --population 64 --maximum-rounds 300 --hard-audit-limit 96
```

该入口固定从原生 `d=0` 和按几何距离生成的 TOGT 时长冷启动，不接收旧 baseline、旧候选或旧轨迹。SC 预处理映射可从场景缓存读取，并逐窗记录 cache hit 与耗时；这不是实验轨迹结果复用。

CEM 正常终止条件是首次严格双零后再完成 5 轮，`--maximum-rounds=300` 只是长时间找不到双零时的兜底上限。结果分别记录预处理、L-BFGS、CEM、最终硬验收和前三阶段规划合计时间。

运行前后会核对所依赖 Python 源文件的 SHA-256；正式运行期间不得修改代码。

## 2026-09-10 旧流程结果与原因

七个原始物理开口的 SC 映射全部成功：L/U/star/limacon/wavy/line-bezier/balanced-U 的建图顶点数分别为 `6/8/10/256/256/86/8`，最大顶点重建误差约 `3e-12 m`。因此本次没有发生内缩多连通或 SC 预处理失败。

当时使用的原始无内缩 SC-DynaTOGT 收敛到 `T=24.056228705 s`，但 `Jdyn=1.06456345e-4`、`Jsafe=0.0647503237`，完整动力学和安全检测都失败。50 轮、每轮 64 个候选的 CEM 共评价 3200 条轨迹，没有严格双零候选，故没有调用最终硬验收，也没有返回违规最少者。正式结果见[报告](results/formal_final_20260910/REPORT.md)。该产物是定位遗漏的历史负结果，未使用当前安全增强 L-BFGS，不能作为改后算法结果。

这不是无内缩参数化丢失可行性。把内缩版已验收候选 `id=2701` 的七个局部点逐一逆映射到原始物理开口 SC 后，可原样重建 `T=24.709999069 s`、`Jdyn=Jsafe=0` 的轨迹，完整检测仍通过。

失败来自局部搜索尺度改变。原始 SC 目标没有安全项；取消硬内缩后，它把 W6/W7 穿越点推到距物理边界约 `1.167 mm/0.0237 mm` 的位置，对应无约束 D 模长 `26.30/104.45`。已知成功轨迹的对应模长仅为 `0.859/2.428`，相对新 CEM 初始分布的联合马氏距离约 `16.07`。到第 49 轮，W6/W7 对数半径标准差已收缩到 `0.0596/0.0676`，已知成功点约在 50–60 个标准差之外。搜索把 W1–W5 安全积分压到零后，长期卡在 W6/W7 各约 `0.0025` 的局部盆地。

因此几何内缩在旧流程中同时承担了安全限制和搜索预调节两种作用。取消它后，安全软项虽然进入 CEM 评价，却没有进入前置 L-BFGS 目标，原先由内缩提供的安全初值随之消失。当前代码已补上前置安全软积分；多中心和停滞重启仍未加入。积分定义统一前的三轮冒烟仅用于验证梯度接线，不作为当前算法结果。

## 2026-09-10 安全增强冷启动结果

当前协议不读取任何旧实验轨迹或候选，从原生 `d=0` 与几何时长冷启动。安全项在 L-BFGS 和 CEM 中统一为与动力学项同构的全段时间软积分：每段 8–32 个区间、逐节点 SDF 残差、`smoothedL1` 和梯形积分；只有最终验收使用球平面接触区间。

L-BFGS 经过 939 次迭代、3073 次目标/梯度评估后按 TOGT past-32 条件正常收敛，得到 `T=49.258175348 s`、`Jdyn=9.22874004e-5`、`Jsafe=2.29228853e-13`。CEM 第 2 轮首次得到严格双零，按协议完成第 3–7 轮后停止，共生成 512 条随机候选，其中 24 条严格双零。

24 条双零候选的完整动力学检测全部满足，但真实外接球安全检测全部失败，因此没有验收成功轨迹。最短双零候选 `id=346`、`T=48.143254387 s`，在 W5/W7 碰撞，最小球体余量 `-0.174735050 m`。全段每段最多 32 个区间，而本赛道球平面接触区间只有约 `0.02–0.18 s`，所以离散安全积分可能完全跨过接触区间；严格双零只能说明当前积分网格为零，不能替代密集安全验收。

分阶段时间为：预处理 `7.285 s`，L-BFGS `2356.510 s`，CEM `102.775 s`，三阶段规划合计 `2466.570 s`，24 条最终硬验收 `831.549 s`，完整墙钟时间 `3334.134 s`。七个原始 SC 映射均命中已校验几何缓存；运行前后 Python 源码哈希一致。完整产物见[本次报告](results/safety_lbfgs_cold_start_direct_soft_20260910/REPORT.md)。
