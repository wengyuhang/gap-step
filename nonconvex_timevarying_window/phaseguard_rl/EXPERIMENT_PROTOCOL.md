# 最小实验协议

只做三组对比：

1. 固定窗口中心穿越；
2. 相同 PPO，但不在执行前做连续安全检查；
3. PhaseGuard-RL：PPO 自选穿越点，并且只有认证轨迹能够执行。

每组报告：

- 成功率；
- 实体碰撞率；
- 成功回合总飞行时间；
- 原始曲线到姿态长方体的最小净距；
- 速度、角速度、总推力和每个旋翼推力的最大值；
- 安全检查状态与检查耗时；
- 穿越点到窗口中心的偏移。

场景至少包含一个静态曲线窗口场景和一个同时平移、旋转、缩放的非凸混合曲线场景。场景、随机
种子和训练预算必须在首次正式运行前冻结；不得根据结果修改赛道后仍称为同一次实验。

碰撞率为零只是实验统计。只有连续检查返回 CERTIFIED_FEASIBLE 的轨迹才标记为安全。
