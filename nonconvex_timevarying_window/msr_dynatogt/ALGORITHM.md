# MSR-DynaTOGT 算法

## 1. 保持不变的内层问题

对 (L) 个指定顺序窗口，内层变量仍为

\[
x=[K_0,\ldots,K_L,d_{0x},d_{0y},\ldots,d_{L-1,y}].
\]

正时间映射得到 (T=\tau(K)>0)，穿越时刻是分段时间前缀和。局部变量先经 (B(d)) 进入单位圆盘，再由每个窗口的 Schwarz--Christoffel 映射得到真实非凸安全区内部点：

\[
q_i=\Psi_i(B(d_i)),\qquad
p_i(t_i)=c_i(t_i)+E_i(t_i)s_i(t_i)q_i.
\]

这些点与时间生成 degree-7 minimum-snap MINCO 轨迹。代价仍是总时间与速度、总推力、角速度、四个单旋翼推力软惩罚，空间和窗口时间梯度仍由 SC-DynaTOGT 的解析链式法则回传。

## 2. 多初值

同一场景、同一种子生成：

1. `sc_center`：所有 (d_i=0)；
2. `random_perturbation`：对子种子确定的 (D) 与 (K) 加高斯扰动；
3. `turn_aware`：把前后航段单位方向投影到窗口平面，沿减小折线转角的方向选择安全区内部点，再用 SC 逆映射转成 (d_i)；
4. `dispersed_region`：在圆盘不同方位使用固定半径点，使初值覆盖不同窗口区域。

每个初值独立运行原 `optimize_track`。候选 (c) 的排序键固定为

\[
r(c)=(\neg legal(c),\ \neg dynamic(c),\ T_f(c),\ J(c)).
\]

因此合法且采样动力学可行的候选一定优先于更短但推力超限的候选。近似相同的总时间、分段时间和穿越点组合只保留排序更好的一个。

## 3. 高密度采样检查

每段使用固定高密度节点，计算：

- 速度模长；
- 四旋翼总推力；
- (xy) 角速度模长与 (z) 角速度绝对值；
- 四个单旋翼推力的逐节点上下界；
- 严格递增的指定穿越时刻、MINCO 在该时刻的位置、窗口平面误差、真实非凸安全区内部性和最小边界裕度。

只要任一节点超限，该候选的 `sampled_dynamic_limits_satisfied=false`。这里没有对多项式极值和动态窗口交点做区间证明，因此输出统一标注“高密度采样可行”。

## 4. 时间修复

原分段时间为 (T^0)。`uniform` 搜索

\[
T(\alpha)=\alpha T^0,\quad \alpha\ge 1.
\]

`local` 根据当前高密度报告中的超限段集合 (mathcal V)，只放大这些段及配置半径内的邻段。每次放大后重新计算穿越时刻，并使用相同 (D) 重新通过动态 SC 窗口生成世界穿越点，而不是固定旧世界点。

逐步乘以 `expansion_factor` 直到找到采样可行上界；随后在原时间和该上界的连线上二分，逼近最小采样可行缩放。修复时间再通过原 TOGT 逆映射变成

\[
K^{repair}=\tau^{-1}(T^{repair}).
\]

最后以 ([K^{repair},D]) 为初值再次运行完整的联合 L-BFGS-B 并重新验证。若再优化结果在排序键上劣于已修复的可行轨迹，算法拒绝该退化结果并保留可行 incumbent；再优化的耗时、迭代、改善量及是否接受仍全部记录。

## 5. A0–A3

- A0：原始 SC-DynaTOGT，中心初值一次优化；
- A1：所有原始多初值候选进入可行性优先候选池，不修复；
- A2：中心初值一次优化后执行修复；
- A3：全部多初值候选均检查/按需修复，再由候选池选择。

除原生运行外，实验还从同一批真实测量中构造：

- `matched_starts`：所有方法使用相同初值列表和启动次数；
- `matched_time`：按每次启动的实测墙钟耗时顺序回放，在共同预算内保留能完成的启动，至少接纳第一次启动。
