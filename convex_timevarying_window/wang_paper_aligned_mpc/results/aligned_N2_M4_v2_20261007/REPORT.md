# N=2、M=4 与状态热启动：完整对照结果

2026-10-07。实际 Gazebo / PX4 / x500 闭环，不是只跑名义轨迹。两个预声明条件×四方法，
8趟首尝试全部执行，无重试，6趟主验收通过。另一个版本v1的6趟失败全部保留，未挑最快或回填旧矩阵。

**结论：状态热启动改善了当前实现；但公平地给中心点基线相同热启动后，自由选点没有更快。**
两条件我们的圈时分别多0.048s（0.26%）、0.156s（0.96%）。每格仅一次，不能当作统计显著差异或总体成功率。

## 这次具体改了什么

1. 按用户明确选择，严格 N=2 局部轨迹段、每段M=4五次MINCO片段，每段3个内部三维点。
   是“当前状态→下一动态窗→前方固定PVA”，不是“两窗另加停车段”，也不是先前三未来窗。
2. 中途尾端PVA取全局MINCO参考前方状态，保持速度，最后一窗才接实际返航停止终点。
3. 修正违反积分的时间权重，使用精确jerk能量、动态中心时间链式导数、论文公开的推力/角速度罚项结构。
4. 我们每次窗口内位置初值q=0，但同一窗口已有的到达时刻、V/A和按新头时刻截取的内部轨迹热启动。
   新窗口没有历史状态才回退到共同全局参考。变量继续自由优化，没有加入过窗deadline。
5. 两方都走同一MPC/PX4；中心热启动对照与我们只差窗口位置是否可优化。

不能宣称全部未知设置已经与作者相同：rho、全局参考初值/截取规则等未完整公开，仍为显式共同选择；
零阻力平坦性近似、x500附加界、数值边界和SciPy L-BFGS-B仍是平台适配，非作者完整带阻力模型/求解器。
本场景无另外的动态椭球和指定大姿态窄缝，未冒充复现这些子任务。
详细逐项对账见源码冻结版 `source_snapshot/convex_timevarying_window/wang_paper_aligned_mpc/ALIGNMENT.md`，
论文依据：https://arxiv.org/abs/2306.14461 。

## v1 接口错误及统一修复

首轮6趟失败见 `../aligned_N2_M4_v1_20261007/REPORT.md`。两热启动趟虽然仍有约0.99秒可飞参考，
却因固定1秒MPC预览越界中止。另一趟在离开口边界11.21m的远处穿过无限平面，被误记为漏窗。

v2两方同时改为：MPC时间预览不超过已有参考有效域，节点数/代价/输入界不变，不外推、不虚构停车；
余量不足0.2秒仍显式失败。有限开口外的远处平面变号不算通过或漏窗，不跳过目标。
实际共148次MPC调用缩短时间预览，最短0.358116秒；没有QP失败或参考越界中止。
