# 机制、假设与当前实现边界

2026-09-24。目标是忠实验证三阶段TOGT/自主MPPI思想；不是重新引入旧策略100 ms准入。

## 用户明确的机制

1. 窗口运动完全已知，按时间查询；窗口间距大，主要困难在接近/穿越窗口。
2. TOGT不保证安全，只滚动优化后续三窗。
3. 普通区间跟踪TOGT；危险时释放跟踪目标，由MPPI自主避让；跟踪误差过大也请求规划。
4. 提前准备及穿窗阶段自主决策，目标是尽快安全完成当前穿越；不得退回入口或绕过窗口。
5. 按实际整机脱离门平面计门和重规划，不能用计划到达时间或中心穿面冒充。
6. 不要求执行旧动作100 ms仍安全才更新；MPPI直接输出新的控制量，GPU执行，每次求解预算100 ms。

## 这次自行补充的设计

- **模型假设**：先用状态(p,v)、输入a的双积分器。a范数6.5 m/s²仅约束理想无阻力下的推力/倾角，
  不含姿态和电机响应。这不是用户同意把x500替换成质点，更不能作为最终任务验收。
- 2 s局部预测、20 ms主更新、5 ms执行重新滤波、16384控制序列；不是全赛道安全搜索。
- 准备区阈值max(7 m,2.5 s×向门逼近速度)；这是统一启发式，不是可达性证明。
- 自主目标是当前门完成时间、剩余距离和控制代价，目标点偏好开口中心但不是中心硬约束。
  采样仍直接优化三轴控制序列，实际穿越点由轨迹决定；不宣称全局最短时间，也不保证优于全赛道TOGT。
- 平均安全控制序列仍需重新滚动验证；失败时选已验证样本。短步后备也是当前新生成的动作，不执行过期策略。
- 门框距离使用真实多边形有限边和保守覆盖圆弧的胶囊；未将整个平面填成障碍。
- TOGT入口使用当前名义P/V、已执行A和差分J。六状态模型并没有传感器意义的实际A/J；
  执行模型诊断才从17状态动力学估计PVAJ。

## 时变安全滤波是什么

对每个框架特征，令h(x,t)=d(p,frame(t))²-r²；r包含机体半径、原0.35 m误差假设、门厚及数值余量。
在移动窗口坐标系计算速度/加速度，显式包含窗口平移、转动的一、二阶导数。
因此不是用“现在的静态门位置”判断未来动作。

双积分器下，psi=dh/dt+k1*h，B=softmin(psi)。B的全时间导数可写成A(x,t)*a+c(x,t)。
工作区与速度上限也加入复合函数。每个预测步以及每个执行步，都解

    min 1/2 ||a-a_nom||² + gamma/2 mu²
    s.t. A*a+c+k2*B+mu*B >= 0, ||a|| <= 6.5.

这是带输入球限制的标量对偶求根；不是将碰撞加一个大软惩罚。
mu乘B，因此在B=0边界不能用mu放松安全条件。单元测试还专门验证了边界不可行不能伪装成通过。

**有条件的理论逻辑**：若初始h>=0、B>=0，且边界存在满足输入限幅的动作、模型准确、
正则性和解存在条件成立，则维持B>=0使各psi>=0，进而保持h>=0。
这里没有证明整个场景内的边界可行性，离散执行也没有全域认证；
特别是有输入上限后，不是任意B>=0的状态都可继续保持B>=0。
GS原文的定理不能因复制了滤波公式就自动移植到本机。

## 验证判据与未完成项

实现错误：导数/滤波/门序/代价与上述机制不一致，可用单测或固定失败状态复现。
证据不足：四固定条件通过不是总体成功率，计算暂停不是实际在线，经验余量不是误差界证明。
假设不成立：执行模型不具备“立刻施加任意限幅加速度”的能力，不能沿用双积分器安全结论。

本次13项单测与12条件名义矩阵通过，但17状态执行诊断失败；详见RESULTS.md。
下一必要改动是把可实现的姿态/推力响应纳入预测和安全控制集合，或建立经验证的加速度跟踪误差界
并据此设计鲁棒滤波。仅将a裁剪得更小、增加样本、换一个窗口专用偏移，不足以解决此处模型缺口。
在这个缺口解决前，不将本模块直接部署为PX4安全控制器，也不宣称已完成用户的全窗安全竞速目标。
