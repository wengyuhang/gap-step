## 用户机制

三阶段普通跟踪/穿窗准备/整机穿越；新三窗TOGT不做安全准入。
整机过门、普通跟踪误差、临时避让触发重规划。不要求旧动作未来100 ms安全才接管/重规划。
采样变量是分段常值加速度控制序列，不是穿越点或多项式；首拍加速度为输出。
采样与执行均过滤新的控制量，没有“沿用旧动作直到有效期耗尽”的分支。
普通段当前跟踪动作违反时变滤波条件时，释放TOGT跟踪目标，改为局部惯性目标的自主避让；
执行这一拍后，从实际PVAJ请求重规划。不是把规划器忙或跟踪误差当作危险。
预测与实际都检查有序开口内穿越、禁止退回和整机退出；中心穿过另行记录，不触发计门。

## 首层验证边界（明确新增假设）

当前先验证六状态双积分器，输入为加速度，范数上限6.5 m/s²。
此上限对应理想无阻力x500推力/倾角可行的保守子集，但没有包含姿态建立和电机滞后。
因此不把这个名义模型的通过当成PX4保证；PX4接入前必须单独验证内环实现误差。
原七窗、机体半径0.3859447197 m、误差余量0.35 m、门框厚度0.085 m、工作区保持。

## 安全滤波

每个多边形边框使用有限线段距离。圆形使用32弦的胶囊覆盖，胶囊增加精确弓高，
保守覆盖真实圆边框，不把开口填成实心障碍；最终审计仍查询真实圆。
位姿及一、二阶时间导数来自已知运动函数的中心差分（数值导数，非区间认证）。
对每个特征构造h=d²-r²，psi=hdot+k1*h；房间面与速度上限也纳入。
复合B=softmin(psi)，其导数是加速度的仿射函数A*a+c。
执行端解带球形输入限制的最小修正问题：

min 0.5*||a-v||² + gamma/2*mu²
s.t. A*a+c+k2*B+mu*B >= 0, ||a|| <= 6.5.

用标量对偶变量的单调求根求解；约束残差和输入界重新验证。
mu乘B：在B=0的边界不能用松弛变量绕开安全条件。
这保留GS“在采样中加入安全控制、实际输出也过滤”的机制，但增加输入球约束并使用数值求根，
不是原文无约束闭式公式的逐字复现。

理论前提：初始所有h>=0且B>=0，边界控制可行、足够光滑和准确模型。
线段最近点切换的分段光滑性、有限步长、数值导数、复合梯度抵消和PX4误差尚未全域认证。
不能把在线约束残差通过写成已证明前向不变，更不能把无合格样本说成物理不可行。
额外数值净空为0.5*(12+最大框架速度)*0.005+0.002 m，用于5 ms执行间隔；
原误差余量不减小，仍独立检查真实几何的区间运动界。这不是100 ms旧动作准入条件。

自主代价只累计“当前门尚未完成”的时间和剩余距离，不在预测出门瞬间突然计入远处下一门
的距离平方，防止代价跳变诱发停滞。出门后下一次求解立即按实际下一门/新TOGT切换。
这是有限视界的竞速启发式，不是全局最短时间保证。
安全候选均值再次复核；没有完整合格预测时，可以输出当前新生成且通过单步复核的滤波动作，
不假称这个单步证明未来仍有解。若单步也失败则报告失败，不执行旧动作冒充安全回退。

## 最小实验协议（运行前）

1. 几何时间导数、滤波约束/输入界、CPU/GPU一致性、实际整机退出和无100 ms旧策略门槛单测。
2. 单窗六状态名义模型：1/10倍频率，起点局部横向0/0.9 m偏移，速度3/8 m/s；失败保留。
3. 同一原七窗四条件（1/10倍频率×0/120度），计时含全部采样/加权/复核；100 ms截止。
4. 只有名义与接口验证通过后才接PX4；没有完成的项明确列为未验证。
