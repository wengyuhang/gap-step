## 证据支持的慢因与改进方向

1. 准备种子即使已对准开口仍按入口距离减速：reach最少0.35 s，再加0.35 s，
   因此对准且横向闭合时 forward=clip(d/0.7,0.5,9)。距入口2 m/1 m分别只有2.86/1.43 m/s。
   这是候选引导偏好，不是最终动作硬限速。应在预测可安全通过时保留穿越速度，仅在横向调整确有需要时减速。
2. PREPARE/CROSS通过当前门后不再评价后续位置/速度进度，仍有安全、平顺和yaw代价。
   因此“过门后向哪飞、保留多少速度”缺少竞速目标。应加接续TOGT/下一门的出口状态价值，仍由MPPI和输出过滤决定动作。
3. 一次rollout的mode固定为当前真实阶段；预测中进入CROSS后，PREPARE候选仍按准备代价计分。
   应根据预测的gate/ph推进代价阶段，使准备、穿越、过门后接续在同一候选内连贯。
4. 本次共接入 67 条TOGT，触发原因 {'initial': 1, 'obstacle_recovery': 36, 'gate_exit': 7, 'tracking_error': 23}。异步求解不能简单累加成飞行等待时间。
   重复避让/跟踪失配可能造成参考和yaw切线频繁变化；需要记录参考误差与接入连续性再作独立对照。
5. MPPI中位/最大 45.14/74.94 ms，平均约 22.0 Hz。
   最少首拍合格样本 16313 / 16384，无发送端候选搜索回退。不能据此归因采样数量不足。
   计算满足100 ms要求，但不满足严格50 Hz；提速计算可减少跟踪滞后，尚无证据说它是主要圈时损失。

## 对照和边界

上次旧航向GUI运行 40.992 s；本次差值 -3.192 s。
估计轨迹长度 226.96 → 206.43 m，平均速度 5.549 → 5.475 m/s。
这两次飞行的时间缩短主要对应路程减少，不能说平均速度提高。
两个版本各一次，随机采样与运行时序不同，不能把圈时差全部归因于yaw修订。
最大采样加速度接近8 m/s²，弯道减速部分来自原物理限值；不能直接把206 m/12 m/s当可实现圈速。
本次是固定条件有限采样成功，不是连续安全保证。旧36.912 s曾比本次更快，尚不能称全局最快。
未保存每周期所采用的完整参考及yaw目标，不能从本日志计算真实yaw相对规划切线的误差；实际飞行方向不代替规划切线。
本报告完成试飞和诊断；上述优化建议尚未改入控制器，也未用本次结果宣称其因果收益。
