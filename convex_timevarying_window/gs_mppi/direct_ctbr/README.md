2026-09-24安全过滤竞速变体的历史最难条件结果见[RESULTS.md](RESULTS.md)：
10×频率、4×中心平移、120°相位的七窗PX4/Gazebo固定试飞严格通过，36.912 s。
2 s预测现在用于竞速和远期风险评分，不再要求整段2 s合格才准许当前动作；
当前20 ms输出仍须通过实际门运动下的几何/物理检查，局部投影失败再尝试小规模
CTBR动作搜索。附加离散屏障是优先修正和风险引导，**不是已证明可行的动态CBF安全证书**。
严格通过者才按圈时排序；同条件 checked 冻结结果52.668 s，本次快15.756 s，
仅各一次固定条件试飞，不能推断总体优势。实现细节见[METHOD.md](METHOD.md)。

- MPPI决策变量与实际输出都是 `[总推力N, wx, wy, wz rad/s]`，ENU/FLU；不是加速度或PVA。
- 预测与名义执行采用相同17状态：P/V、四元数、实际角速度、四电机转速。
  复用已有经验CTBR角速度闭环和电机响应模型；不是完整PX4控制分配的证明。
- TOGT只提供普通阶段代价参考。普通段并行生成上一轮均值、TOGT跟踪、减速稳定和下一门汇合CTBR候选；准备段也有独立减速候选。
  MPPI选出的首拍不再进入位置/速度/加速度跟踪器。
- 输入限幅、安全修正与最终复核均直接在四维CTBR空间进行。
- 时变安全投影使用完整模型的离散非线性约束：5 ms积分、当前20 ms内真实未来门位置、区间几何净空、
  速度/加速度/倾角/角速度以及按序开口内穿越。局部有限差分线性化投影后必须重新验证；
  真正物理约束未通过就拒绝，不用软惩罚冒充通过。加权均值首拍也重新验证。

**与GS的差异**：不再套用双积分器CBF闭式公式。这里是输入有界的离散预测安全投影，
只保留GS“采样内和输出端均处理安全”的结构；不是GS原定理的四旋翼复现，
不宣称全局递归可行或连续鲁棒安全。未找到动作不等于物理不可行。

用户的三阶段、实际整机退出/跟踪失配/普通避让重规划保留；没有旧策略100 ms准入。
准备触发、侧移与前进速度协调，以及入窗后加速退出的具体规则见[METHOD.md](METHOD.md)。
窗口、机体、原0.35 m误差假设及物理限值不改。性能预测局部2 s，GPU16384序列，每轮100 ms截止。
先做同源CPU/GPU/独立执行模型一致性，再单窗与原七窗；所有失败保存。
名义实验仍暂停求解期间的仿真时间，不代替真实PX4/Gazebo验收。

PX4入口为`python -m convex_timevarying_window.gs_mppi.direct_ctbr.px4 --duration 60 --outdir <新目录>`。
竞速发送链路只有CTBR安全修正及FLU/FRD、推力归一化编码，保留PX4角速度内环和电机分配；
因此这里的“直接”指飞控输入，不是绕过PX4直接驱动四个电机。准备/结束时的位置保持不计入竞速控制。
计算耗时后按实际时钟裁掉已过期控制，不延长候选尾段。完整剩余预测用于预警，
实际新首拍从新状态检查20 ms，每次发布重新检查；没有旧策略100 ms准入条件。
GPU候选每步最多一次投影；发送端只有四维首拍，可最多四次重线性化并非线性复核。
若局部投影仍未通过，再搜索有限个通用CTBR推力/角速度候选并选择最近的合格动作；
都未通过才报告失败，不放宽真正的20 ms几何/物理约束。
实测状态与实际过门阶段在同一锁内按时间更新，禁止规划线程拿新位置配旧阶段。
两次实测之间使用端点连线的<=5 ms检查，再扣除物理加速度界给出的`A*dt²/8`弯曲包络，
不把稀疏采样的粗Lipschitz下界失败直接说成碰撞，也不把插值点当实测点。
该有限步长检查不证明下一次更新一定仍有可行动作，也不保证估计误差下的真实安全。
