# 名义动力学硬约束版

2026-10-09，用户授权解决两档漏窗，入口 `hard_flight.py`；旧 `flight` 和 `repaired_flight` 不覆盖。
结果及失败版本见 `results/hard_validation_v2_20261009/REPORT.md`。

## 变化是什么

仍然只有起点、窗口内点、终点三个几何节点，两段七次曲线；优化两个时间、窗口内二维点和
穿窗三维速度，共七变量。内部加速度/jerk由耦合最小snap系统确定，C5，不称原版TOGT的C6。
目标变为总时间 `T1+T2`，不再让动力学违规与时间通过罚权重交换。

不是把12m/s、8m/s²等旧名义阈值统统硬化，而是约束x500对应的执行量。
由速度、加速度及阻力近似计算合力F和姿态R，再计算

```
ω = vee(Rᵀ Ṙ)
τ = I ω̇ + ω × (Iω)
f_rotors = mixer⁻¹ [‖F‖, τ]
```

每段17个优化节点强制每个电机 `0.19234305 ≤ f_i ≤ 8.54858 N`，
机体角速度绝对值不超过 `[3.8,3.8,3.49] rad/s`，以及原工作空间位置界。
对约束使用解析梯度；不是求解后把超限轨迹直接拒绝，也没有扫描全轨迹作为在线准入。
`planner.py` 中默认空的扩展接口保留旧方法行为；新目标只在 `hard_planner.py` 生效。

## 为什么还要改窗后形状

旧版本强制窗后法向速度的Bernstein系数非负。这比“不重新穿窗”更强，禁止超过窗后6m的终点
再刹车返回，可能排除高速穿窗后可执行的轨迹。新版改成窗后位置的Bernstein系数位于出口半空间。
因此可以在出口侧超过终点再返回，但不能跨回窗口平面；原终点位置及VAJ、完赛容差均未改变。
整机离窗后的单段终点重规划另要求整机始终在出口半空间，继续施加同一组名义执行量约束。

## 如何让求解及时结束

v1保留旧8个初始局部安全见证，第一档曾等待14.728s才接纳初始规划，另一组固定头90ms失败。
v2将穿越前后0~80ms的初始见证设为5ms间距，再保留100/140/200ms见证及自适应补点。
约束仍随每次轨迹/穿越时间变化重新计算；不是固定旧轨迹上的绝对时刻，也不是全轨迹扫描。
相同四个相位种子按约束残差排序，时间作为并列判据；执行仍只接纳收敛且局部检查通过的解。
90ms预算增加函数评估入口检查，不对超时未收敛候选做多余局部复查；旧方法默认不启用。

## 不保证什么

这些硬约束是在优化节点上的名义约束，不是连续时间证书。报告另做1ms离线诊断，节点之间可能
略超限，必须如实保留。合力/姿态平坦映射也不是完整PX4 PID和电机动态逆模型；姿态与电机初态误差、
电机滞后仍由上轮同一MPC近似预测，不能据此宣称闭环必定安全。实际结果以Gazebo接触和ULog真值为准。
本实验只有单个固定平面、面内平移窗口；不能直接外推七窗、旋转窗口或成功概率。

## 复现

```
python -m convex_timevarying_window.dynamic_passage_velocity_minco.hard_flight \
  --method ours --frequency 4 --amplitude 4 --phase 0 --outdir <新目录>
```

使用wyh环境、单线程BLAS，飞前编译耗时与在线周期分别报告。
固定旧头测试用 `hard_probe`，需显式指定 `--initial-tail-scale 1 --log-cost-scaling --max-solve-ms 90`。
探针不是实飞；完整时间包括起点等待、穿窗后到终点，不只统计移动时间。

## 实测结果

v2各一次：4Hz/4m完整6.504s，最大误差0.256m，规划86.32ms/MPC35.69ms；
3.5Hz/4.5m完整5.488s，最大误差0.199m，规划42.77ms/MPC37.39ms。
均一次正向穿窗、整机离窗、到原终点，窗框接触为零。旧版本两档均漏窗失败。
同旧初态/绝对时刻的固定头测试分别69.08/37.86ms找到候选；飞前编译约19s。
42项相关测试通过，源码快照与同世界审计通过，experiment暂停，replay未操作。

离线1ms诊断：4Hz/4m两条接受轨迹单电机节点间峰值超限5.095%/4.934%；
3.5Hz/4.5m为0.607%/0.032%。这是节点硬约束的离散间隙，不能称整轨迹严格满足硬界。
没有放宽求解节点的物理界，也没有用离线诊断改变本次已飞条件/判据。
其他四档未用hard_v2重跑，不能与旧repaired_v2四档拼接成同一算法“六档全通过”。
