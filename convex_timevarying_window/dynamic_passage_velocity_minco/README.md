# 单窗 MINCO：开放过窗速度的结构消融

2026-10-09。针对旧四变量版本为了提高过窗速度而延长窗后段、越过终点再返回的
实测问题，新建并列方法，不覆盖旧算法或历史结果。当前仅单个原尺寸W1矩形、
固定平面、已知面内正弦平移；不是完整七窗算法。

仍只有起点、窗口内点、终点三个几何节点、两段七次多项式。优化变量为
`log T1, log T2, q0, q1, vx, vy, vz`，最后三个是过窗的世界速度。
给定节点位置/速度和两端PVAJ，求全局最小snap曲线；穿窗处A/J和4/5阶导数
连续且由线性系统确定，不再强制第6阶导数连续。这是增加内部速度条件的
minimum-snap变体，不是未修改的TOGT位置-only MINCO，也不是任意Hermite拟合。
旧曲线在取其原过窗速度时包含在新曲线族中；不据此声称局部求解必然更快。

终点仍在窗后6m，终点VAJ仍为零，完赛容差仍为0.55m和1m/s。安全半径、
余量、双侧自适应见证、动力学软惩罚、90ms预算、运动相位分区、MPC/PX4都不改。
v2增加窗后法向速度的Bernstein系数非负约束：起点系数由原正向穿越约束保证，
终点VAJ为零使末三个速度系数恒零，只需约束三个中间系数。这是保守的连续
前向推进形状条件，不是新增安全认证，不依赖整段时间网格，不限制面内选点。
没有添加防折返罚项/额外路径点，也不移动终点或放宽碰撞判据。

原目标J完全保留，SLSQP数值求解使用log(1+J)及其解析梯度，严格递增变换不改变
同一可行集的全局最优点，但局部迭代/收敛结果可能改变，不能宣称算法等价运行。
因为短尾初值的原软罚可达1e6以上，旧J/1000缩放的SQP直接失败，负结果保留。
初值仍是相邻四个已知极值时刻及窗口中心，尾段用原距离/加速度/jerk尺度本身，
去掉旧3.2倍放大；新增速度初值沿正向法线取0.8倍名义速度。中心变体只锁q0/q1。

flight入口固定为七变量、forward_tail=True、log_cost_scaling=True、initial_tail_scale=1。
开发中开放A、改变相位初值的配置仅为消融；均未启用至本轮实飞，不称为主算法。
仅开放速度的开发解仍有6.85m过冲，不能称修复；v2固定同一旧头状态求解67.34ms，
名义两段2.9189/1.6893s、尾段长度7.131m、零法向过冲；仍需实际飞行确认。

先固定旧实飞记录的PVAJ和起始绝对时间做结构验证，分开报告名义轨迹时间、
在线求解耗时与后续真实闭环时间。编译在飞行前完成，不计入在线预算但单独报告。
失败/超时/碰撞均保留。只有实际有序穿窗、整机离窗、到达目标且无实体窗框接触
才算成功。浮点局部包络与10cm经验余量仍不是闭环安全证明。

本轮验证条件固定为3Hz/4m、初相0。开发探针可诊断求解，不将其冒充真实飞行。
先通过数值/梯度回归和90ms固定输入测试，再执行新自由版一次PX4/Gazebo飞行。
若起飞设施故障只允许额外一次重试，原尝试完整保留；不飞行中调参。

## 执行修复 v2（2026-10-09）

用户授权修复上述缺陷后，新增并列入口 `repaired_flight`，原 `flight` 默认行为保留。
代码为 `allocation_mpc.py`、`repaired_planner.py`、`repaired_worker.py`、`repaired_flight.py`。
共享 planner 仅添加默认空的扩展接口；共享 px4 的末窗后事件监听和漏窗中止均由新配置开关启用。

MPC 不增加避障代价或倾角惩罚，仍用相同跟踪目标、25×40ms 预测域、两次 RTI 和输入箱。
预测模型改为共享四个电机的力/力矩分配、饱和退让与电机响应；转弯不再能同时凭空保持最大合力。
它是物理近似，不是完整 PX4 PID/allocator 的精确复刻。规划仍是七变量、两段 C5 MINCO，
原动力学软代价补入阻力修正的推力残差；不把它作为窗前新的硬准入。

整机离窗仍触发规划；末窗后继续监听跟踪误差，并从测量 PVAJ 求一段七次终点恢复曲线。
此终点段约束采样推力上限，并以位置 Bernstein 半空间约束保证名义整机不回到已过窗平面。
不移动终点、不放宽0.55m/1m/s完赛判据。错过物理开口则明确失败，不能反向重穿凑完赛。

## 名义动力学硬约束分支

用户随后授权将动力学改为硬约束，新增 `hard_flight` 入口，详情见 [HARD_DYNAMICS.md](HARD_DYNAMICS.md)。
目标只有时间；每电机推力、机体角速度及原工作空间界在每段17个节点强制。
去掉“窗后法向速度始终非负”，改用出口位置半空间，可在出口侧越过终点刹车返回，但不重新穿窗。
v2的局部安全见证初始化与物理可行种子排序减少预算内补点次数，MPC保持上轮不变。

两个旧漏窗档各一次：4Hz/4m 6.504s、3.5Hz/4.5m 5.488s，无窗框接触完赛；
规划最大86.32ms、MPC37.39ms。v1等待首解14.728s/完整21.004s及90ms探针失败均保留。

离线1ms诊断仍发现节点间单电机峰值超限，最高5.095%，故这是离散名义硬约束，不是连续/闭环保证。
