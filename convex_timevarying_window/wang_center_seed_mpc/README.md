# 三窗 Wang MINCO：中心初值、自由穿窗状态、无中途停车段

2026-10-07，按用户最新要求独立实现，旧方法、基线与结果不变。

## 问题和机制

- 当前PVA连接接下来最多三扇动态窗；窗口位姿是已知绝对时间函数，不是优化变量。
- 直接使用Wang独立复现的两段等时长五次MINCO归一化矩阵和自由内部位置坐标。
  每窗局部二维穿越位置、三维速度、三维加速度及每段时长/内部位置自由优化。
  段内部C4、窗处C2；不宣称跨窗jerk连续。不是作者官方实现。
- **不追加中途停止点，也不固定最后预测窗的速度/加速度。**
  仅当预测范围包含赛道最后一窗时，追加任务规定的实际返航终点，末端V/A=0；这不是中途停车。
- 每次重新生成窗口中心位置初值，内部点取相邻端点中点，V取前进方向粗估、A=0。
  共用窗口剩余到达时刻只作时长初值，全部时长可优化；不继承旧偏置穿越点或拒绝候选。
- 无公共窗口截止时间、无“首窗不得延迟”或“总时间不得增加”接纳条件。
  保留当前任务的正向过窗、真实有限边框/机体余量、动力学、房间约束及原软净空目标。
  数值正时长边界、55ms内部预算与100ms完整在线门槛仍在，不属于额外竞速时限。
- 原消元MPC、PX4/x500参数、实际中心穿越→整机离面进度管理不变。

## 无停车终点的检查边界

非终局预测恰好结束于第三扇窗平面：它只说明到达该窗，不能声称预测了它的整机离面。
前两扇预测窗仍检查完整单次穿越及离面；末窗检查到达开口、正向速度、进近侧及此前无提前穿越。
该末窗成为近端目标前需要滚动延伸。不会通过虚构离面采样点或把末窗计为实际通过来绕过检查。
尚未延伸的参考末端不能被当悬停点；控制预览越出非终局有效范围时显式报错，不暗中外推或停车。
它没有原可停留终端的备份含义，不能保证所有状态下递归可行。
全部安全检查仍是有限采样，不是连续安全证书。
