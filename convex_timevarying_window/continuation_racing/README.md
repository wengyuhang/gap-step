## 统一求解处理

停车段初始时长由距离及加速度/jerk尺度给出，不用巡航速度简单除距离来初始化停车段。
倾角约束统一针对实际前馈需求`a + tau*j`，零上界二次约束按重力平方归一化，
避免初始迭代的量纲失衡。这两项不依赖赛道或运动倍率，不改变速度/加速度/jerk上限。
错过切换时刻的候选不接收；过终端后PVA保持为规划末端及零速度/加速度，不继续末端jerk前馈。
可执行计划必须经整个局部计划检查、期限和任务一致性准入，和优化中的未执行候选分开缓存。
只有已准入计划按流逝时间缩短剩余段；失败搜索保留相对段长，避免原地等待时不断压缩飞行时间。
同一视界保留IPOPT原始变量与对偶变量热启动，仍使用原65 ms预算。

### v4提前终止及执行延迟修正

低频6次均通过、圈时24.780–25.916 s；10倍频率/1倍双幅度/相位120°球净空−0.011343 m，
10倍频率/2倍双幅度/相位120°W4碰撞后物理数值发散。脚本曾错误自动重试一次，详见该目录`STOPPED.md`，
重试不能替换碰撞失败。剩余条件与布局留出没有完成v4验收，不将它推广为安全版本。

v5在同一算法上加入单一平台跟踪延迟模型：仅用开发相位0.4的参考/实测位置拟合
`p_measured(t) ≈ p_reference(t - tau)`，不使用门编号、窗口位姿或测试相位；得到`tau=0.050 s`。
拟合RMSE由0.421降至0.248 m，说明延迟只解释部分误差，不是误差界证明。
执行时发送`PVA_reference(t + tau)`；窗口查询与验收仍使用真实物理时间，不改变窗口时钟。
候选物理接续时刻设为`now + 0.100 + tau`，必须在物理接续前`tau`到达，
因此计算仍有100 ms准入预算，预览不会引入晚切换跳变。物理参考与命令预览分开维护。
入口：`--continuation --tracking-preview 0.05`；数值发散直接终止并保留逐周期落盘日志。
