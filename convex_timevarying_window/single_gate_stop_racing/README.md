## 2026-10-10 开发修订：对齐 TOGT 选点映射，尚未验证完赛

用户纠正有效：TOGT 的变量映射保证每一次迭代的穿越点在真实开口内（含边界），
不是只有收敛后才成立。2026-10-09 实现用坐标盒及开口不等式，未采用该映射；
此前将其失败迭代的框外点泛化为用户方案的“向外躲”问题，归因撤回。

当前使用2024官方源码6707d3a1d06e4bd33d4aaa5e6f9fa02497ee90c5的取点形式：
圆形用二维版本 `q=2R d/(1+||d||²)`；多边形用归一化平方凸组合（顶点数个变量）。
多边形全零向量用1e-24分母保护映射至顶点0，保证其也有定义且不出框。
没有新增内缩，也没有新增所谓内外分支选择约束。MINCO及窗处速度自由度不变；
圆形共7变量，多边形为5+顶点数，中心分支5变量。机体安全/动力学仍有硬约束，
因此这里只消除了选点不等式，不称整个求解器是原版无约束TOGT/L-BFGS。

同时开发修正：有限边框包络用圆径向范围/有限线段投影下界，代替频繁调用通用距离；
90ms预算覆盖局部复查，重复见证去重；失败候选及相对穿越时刻见证跨请求仅作初值，
绝不执行失败候选，每次用新PVAJ/时刻重新构造轨迹和窗口状态。

下文是2026-10-09冻结版本的机制与历史结果，不代表本次开发版已通过实飞。

2026-10-09。独立于两窗联合规划及旧单窗实验，复用当前hard_v2动力学/MPC。

每次从拼接起点PVAJ规划两段七次minimum-snap：起点→最近未完成窗口内点→停车点。
只有一个窗内点，点和三维速度可优化，停车点VAJ为零。普通区间误差过大也重规划；
整机离开当前窗后立即规划下一窗，旧轨迹在新解安装前继续执行。不是提前保证不停车。
最后一窗的停车点是原赛道起点；末窗整机退出后不再规划，沿最后一条轨迹回终点。

七窗位置、朝向、原开口保留；采用此前固定平面、已知水平面内正弦平移协议。
窗口相位依序均匀错开2π/7。只扫实际频率/幅度，不引入旋转或改赛道间距。
停车点取下一锚点方向的中间切向分量；出口法向距离为max(机体半径+框厚+1m,min(6m,锚点距离/2))。
这是原赛道掉头几何的通用规则，不按条件手工选点。终点不作这种投影。

安全约束推广到真实矩形、多边形及圆形的有限边框，不用外接矩形冒充原开口。
穿越时局部点必须在真实开口内；球与有限边框的距离通过自适应局部Bernstein包络检查。
允许远离有限边框穿过其无限延伸平面，但不允许名义轨迹再次从当前开口内穿过。
不做所有窗口的完整轨迹准入检查；其他窗口/已过窗的真实接触全部计碰撞。
节点电机/角速度界和浮点包络不是连续动力学证书，也不是闭环安全保证。

首轮开发验证0.5Hz/1m；最终冻结五档0.5Hz/1m、1Hz/2m、2Hz/3m、3Hz/4m、3.5Hz/4m。
每条件原初相一次，仅自由点，最大竞速120s；设施故障停止批次，不放宽判据。
主指标：完整七窗后回起点且停稳的时间、Gazebo实体接触。失败保留，不计有效时间。

常规出窗请求沿用共享执行器：从旧参考向前0.15s的PVAJ拼接，新解未安装前继续旧轨迹；
跟踪误差过大才从实测PVAJ恢复。末窗后不再规划。终点完成阈值为距离<0.55m且速度<1m/s，
不是严格零速度。规划失败后有0.2s重试间隔；“各条件一次”指不重飞，不是禁用飞行内重试。

冻结五档已完成：前三档27.392/27.936/27.884s无碰撞返航；3Hz/4m、3.5Hz/4m分别只完成6/1窗，
