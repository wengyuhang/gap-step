# PX4/x500 跟踪模型对齐

用户任务：对齐MPC与PX4/x500实际响应，不增加行为补丁，再测拉远赛道3Hz/4m和3.5Hz/4m。
结果以完整七窗后返航时间、真实窗框接触为主；出窗不算完赛。

## 修正的模型差异

1. 旧模型用固定角速度时间常数；新模型使用实际P/I/D、积分限幅、抗饱和、偏航低通。
2. 旧模型在物理推力空间混控；实际PX4先对归一化电机指令做伪逆/去饱和，
   映射至150–1000rad/s，再由转速平方产生推力。两者在高油门不等价。
3. PX4 CA参数和Gazebo真实桨位并不相同，现在分别模拟，不假定飞控内环是理想逆模型。
4. 旧模型只有平移阻力；新模型包含高于质心的桨处阻力力臂及rolling moment。
5. 原15ms预测偏移小于旧日志中实际约30–40ms的指令送达延迟；现在按计算耗时与8ms
   观测/传输偏移估计预测时刻。该偏移仍是近似，实际日志将再次核对。

参数来源及近似边界见[模型依据](PX4_MODEL_SOURCES.md)。不修改PX4参数本身。
物理状态17维不变；另16维仅表示内环积分/滤波器记忆，由已执行指令和测得状态推进观测器。
不是新增路径决策或安全过滤。

## MPC还是纯跟踪

仍预测1s（25节点×40ms）；输出总推力和机体系角速度，位置/速度/姿态跟踪权重与输入平滑权重不变。
只限制真实输入盒，不新增倾角约束、奖励、避障、速度缩放、误差触发或停车规则。
数值求解改为直接single shooting + L-BFGS-B（最多40迭代、解析反向梯度）。
原因是原RTI线性化在带饱和的新预测上会提出非线性代价不下降的更新，固定十个W5输入测试全部被拒；
直接求解同一非线性目标则十次均有下降。不是更换跟踪目标或把MPPI策略混入MPC。
同一CasADi表达式自动生成C编译，符号/原生预测及Jacobian一致性测试通过。

规划、安全局部包络、机体大小、物理上下界和出窗事件不改；误差触发保持关闭。

### v1负结果与坐标接口诊断

`px4_model_aligned_v1_20261010`源码冻结核验通过，两档各一次：
3Hz/4m在21.384s碰W3，随后失稳；没有有效完整时间。
3.5Hz/4m实际7窗正向各一次并返航，57.216s，七个接触topic全部零。
最大规划89.76/92.97ms，MPC181.99/70.59ms；首档碰撞前MPC最大42.92ms，
181.99ms出现在撞后，不把它当作首次碰撞原因，但整体不满足100ms要求。

首次碰撞前，MPC测得位置跟踪误差约0.022m，实测位置与真实机体中心却相差约0.23m（主要向东）。
原接口只加常数原点/交换坐标轴，未处理Gazebo EARTH_WGS84椭球和PX4 GPS局部地图
R=6371000m球面的比例差异。在本纬度，ENU米数换算比例由地理公式得
`[1.00294074,0.99985318,1]`；没有用飞行误差拟合数值。
公式离线作用于四份不同历史飞行，位置观测偏差中位数均下降；新v1首档0.148→0.060m。
这只是接口偏差诊断，并不将GPS噪声或所有误差都归为投影差异。

v2新增`metric_session.py`，仅将位置观测映射回实际Gazebo米坐标；
速度观测本来已是实际m/s，不重复缩放。继续使用PX4状态估计，不反馈Gazebo真值。
世界datum从本次实际world.sdf读取，不按窗口、频率或轨迹加偏置。
L-BFGS-B另明确85ms整周期数值预算：预算用尽保留已评估、满足原输入盒的最好序列，
不更换目标或另加飞行动作；仍须报告实测周期，不能视为操作系统硬实时保证。
55项相关测试通过。v2将两档重新冻结各一次，旧碰撞记录全部保留。

**3.5Hz仍有短时1.222m真实偏差，不能宣称全程误差彻底消除。**
峰值30.560s，距离W4平面约35.44m，在窗间飞行而非贴框穿越时。
峰值附近1s内分配器采样均记录推力未完全实现，50%电机输出采样至少一桨达到999rad/s；
这时MPC请求推力中位31.956N、由电机遥测估计实际31.622N。
该区间名义推力中位27.225N，不能把它误写成此刻参考本身已超上限；
饱和、累积跟踪偏差、内环记忆与有限迭代的独立贡献尚未分离。
原始诊断在第二档`residual_error_diagnosis.json`，没有为追求零误差新增补丁或隐藏峰值。

MPC原日志还有一个需区别的计时现象：首档31.112s报0.705m，
同一实测位置对当时参考仅0.00174m；求解结束再查询日志参考时，执行线程已经切到31.158s新轨迹，
旧状态被拿来和新轨迹起点比较。证据`logging_timeline_note.json`完整保留。
本表用独立时间对齐真值/已安装多项式审计，不用此类日志尖峰替代真实误差；
未在冻结过程中改日志或执行逻辑。

新飞行也做了14段已接收指令的1s预测对照：旧模型位置偏差中位0.417m，
对齐模型0.100m；推力方向偏差中位7.579°→0.320°。
来源`results/model_alignment_20261010/replay_fresh_f3_v2.json`；不是新增飞行或安全证明。

结论：本轮两档达到完整竞速返航/无实体接触，模型及坐标接口修正有直接证据支撑。
没有证明闭环永不碰撞、全程零跟踪误差或跨相位稳定成功；各一次不能估计成功率。
批次已退出、experiment已暂停，未操作replay容器。
