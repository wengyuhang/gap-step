# 单窗停车点滚动七窗实验

七窗水平锚点相对固定起终点拉开2倍，第一窗额外侧移-5m；高度/开口/朝向/实际米数幅度不变。
固定平面/水平正弦、初相0各一次，仅自由点。MPC预测实际PX4 PID/归一化分配/x500阻力力矩，修正GPS投影坐标单位；同一跟踪代价用直接L-BFGS-B求解。规划/物理界不变。无条件调参/重飞。
整机出窗后重规划；末窗后不重规划，完整返回起点停稳。真实实体接触判碰撞。
