# 单窗匀速横移配对实验

目的：检验自由选点是否提高已知高速横移窗口任务的可完成范围与完整任务速度。不预设中心必碰撞。

## 冻结设置

- 原 W1 小矩形、原单窗起点及窗后 6 m 固定终点；窗口平面、尺寸及 x500 不变。
- `c(t)=c0+v(t-t*)`，沿窗口局部水平轴平移。`t* = max(0.8, ||c0-start||/6.5+0.5)`，与算法、求解结果无关。仿真时间 30 s 为任务计时零点；此前固定窗口在 t=0 的位置。
- 速度 0、±5、±10、±15、±20 m/s。每条件、每方法一次；不称为统计成功率。
- 相同两段七阶 P/V-MINCO，内部 A/J 消元，目标仅总时间；相同硬安全局部交换约束与节点动力学约束。中心只固定两个局部选点坐标为零，时间及穿越速度仍优化。
- 正弦相位种子替换为几何时间的 1、0.8、1.2、1.5 倍；两方法相同、无相位盆地限制；每段时长仍为原 0.3–15 s。
- 使用 execution-aligned MPC、PX4/x500；不为某档修改权重、裕量、控制器、物理参数或验收。
- 单窗采用初始规划及拒绝后的重试；已接受的起点—窗口—终点轨迹完整执行，不启用误差重规划或出窗换尾段。
- 单次在线规划 90 ms，记录实际耗时和超过 100 ms 次数；最多 40 s 完整任务。起点等待与窗后到终点均计时。编译单列，不混入在线时间。
- 实际接触判撞；单次正向穿越、整机出窗、相同终点位置/速度容差判完成。净空仅作解释，不替代碰撞。

## 中心无解的公平处理

在线没有合格解，记“预算内未找到合格轨迹”，不是碰撞，更不是物理无解。保存每次原始请求 PVAJ、时刻与失败状态。

另做相同名义静止起点 PVAJ、同一时刻 t=0.15 s、相同约束的 5 s 规划诊断（双方均做），不得把它混入在线成绩，也不把诊断轨迹用作在线初值。名义诊断找到解排除该名义初态无解；实际请求仍需考虑微小初态差别。仍未找到，也只能记未找到。只有两方都无碰撞完成时比较时间。中心硬约束拒飞不能支撑“中心碰撞率更高”，只支撑该预算下完成能力差异。

离散动力学硬约束、浮点局部包络不是整个闭环安全证书。物理接触分辨率须单列；高速边界条件需更小物理步长复核后才能加强安全结论。

开发测试与冻结批次分别保存，失败不删除、不择优覆盖。
