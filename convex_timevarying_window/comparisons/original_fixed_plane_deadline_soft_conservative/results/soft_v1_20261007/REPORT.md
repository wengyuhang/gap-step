# 更保守软净空：真实 PX4/Gazebo 配对实验

2026-10-07。只改软目标，原无整段事后复查版本保留。本轮两档各首次一次，无重试。

## 改动

- 额外偏好余量 0.15 → 0.25 m，即偏好球/门框净空 0.50 → 0.60 m。
- 权重 1 → 10。归一化分母随余量变化，已以解析充分条件验证新代价和向内梯度在所有距离均不弱于旧版。
- 规划器、MPC、55 ms 内部预算、20 ms 共同窗时限、优化约束/补点/残差与穿窗事件检查保持。
  事后整段几何/动力学复查仍不参与接纳；没有通过更换安全标准来换取成功。
- 保留被测历史算法的可停留尾段；没有悄悄替换为自由终态版。
- 仅在新配置与新实验入口注入两字段。场景/MPC/PX4不改，旧算法入口默认不变。

## 为什么还没严格安全

重建高档实际执行参考，与在线记录参考点误差为0。该计划18.740 s接纳、18.834 s生效。
第六窗附近参考最低净空−0.009328 m（21.922 s），真值最低−0.062324 m（21.928 s）。
因此不能把失败全归于跟踪；参考本身在这里已经侵入保守包络。

软成本均匀采样相邻时刻21.847646/22.012106 s，间隔0.164460 s。
这两点参考净空为0.674913/0.562086 m，但中间最低为负。
已增大的软罚仍只在既有节点积分，且0.60 m只是偏好不是强制下限。
原优化还保留自适应硬约束节点；它们并未阻止这一已接纳参考的间隙违规。
这说明本次残留失败包含采样分辨率/约束覆盖问题，不能只说权重不够。
全程估计跟踪误差最大0.207293 m；真实机体未接触与外接球负净空可以同时成立。

离线原validate会拒绝低档47/103、高档74/99个已接纳候选；这些复查不进入控制。
不能据此认定全部拒绝都必要，也不能从飞完一次推断关闭检查普遍安全。
