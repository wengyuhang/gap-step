# 删除整段几何/动力学复查：两档仿真结果

2026-10-07。结论：低档完成，高档越过原停车位置后在第六窗真实碰框，未完成。
删检查能放行更多候选，但本次不能靠直接删除实现安全全窗竞速。

## 单一消融范围

以紧邻上一轮`wang_progress_mpc`为基准，只跳过求解后的`validate(plan)`及按其净空拒绝的条件。
几何/动力学/末端保持的密集事后检查不执行；日志`prefix_clearance=null`明确表示未检查。
优化目标、全部优化约束、残差门槛、自适应补点、共同窗20ms限制、MPC/PX4和可停车末段不变。
单次正向穿窗/禁止返穿事件检查及真实整机离面进度仍保留；不是“完全取消所有轨迹检查”。
原方法源码及默认入口不改，仅新建独立仿真消融目录。该实验不部署实物。

## 同条件结果

两档都是原不规则七窗、固定平面中心平移、初相0、首次各一次，不重试。

|条件|保留复查的上一轮|本次删除复查|
|---|---|---|
|0.6Hz / 单侧1.2m|24.876s，主验收通过|**24.748s，主验收通过**|
|1Hz / 单侧2m|3窗后停车，60s超时|**5窗后第6窗碰撞，22.556s中止**|

低档只快0.128s，单次对照不声称显著提速。高档没有有效全程圈时，22.556s是中止时间。
两次世界字节、场景、规划配置、MPC配置、PX4参数与保留检查版完全一致。

## 高频：先碰撞，随后MPC失败

- 22.280s首次真实接触，`gate_06_W6_circle::frame::frame_collision`分别与
  `x500_0::rotor_1::rotor_1_collision`、`rotor_3::rotor_3_collision`接触。
- 22.544s MPC才报QP不可行，22.556s主循环中止。不能将这次先发生的碰撞归为“先MPC无解”。
- 碰撞前最大估计跟踪误差0.212m；撞后才增至约0.764m。
- 当时执行的是20.008s接纳的参考。对该保存多项式重跑原检查，净空为−0.157966m，原检查会拒绝。
  接触附近以1ms查询名义轨迹，22.282s最小球净空−0.158409m；首次实际接触时名义净空约−0.157622m。
  因而不仅是整个候选远端不安全：本次实际走到的参考区间已经违反几何安全条件。
- 真值4ms最小球净空−0.094826m。此处同时有真实接触证据，不只是保守球包络负值。

这些证据支持被删除检查确实会挡住本次撞框参考，不代表所有原拒绝都必要或原方法具有安全证明。

## 放行了什么

飞行结束后才对实际接纳候选执行原检查，不影响实时控制：

|条件|实际接纳候选|原整段检查会拒绝|
|---|---:|---:|
|0.6Hz / 1.2m|99|51|
|1Hz / 2m|71|70|

低档虽然接纳了原检查会拒绝的候选，本次实际七窗各一次正向/整机退出/返航、零接触，
真值最小净空0.343323m，工作区通过。不能把整段候选不合格直接等同实际必撞；
也不能由这一例推断删检查普遍安全。尚未逐候选隔离其未执行远端与实际执行前缀。

## 实时与核验

- 216次完整规划最大72.156ms，1852次MPC最大24.652ms，无100ms超限。
- 290个已接纳共同窗口事件延迟均≤20ms；原单次穿越事件检查保留并实际执行。
- 15测试通过，包含控制入口副本只具有声明差异的逐文本对照；158项冻结源/快照无变化，旧基线未改。
- 低档名义峰速12.035m/s、加速度8.030m/s²、倾角43.220°另列。
  高频整段峰加速度294.446m/s²包含碰撞冲击，不解释为正常控制需求，不删除原数据。
- 真值采样不是连续认证，两次飞行不是统计成功率。

证据：`summary.json`、`contact_diagnosis.json`、`verification.json`、`tests.xml`；每条件的
`removed_check_audit.json`、`flight.ulg`、原始门框接触、规划/MPC日志与真值审计。
