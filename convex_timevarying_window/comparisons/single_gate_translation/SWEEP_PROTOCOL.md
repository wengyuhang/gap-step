# 原尺寸单窗：频率与振幅配对升档

2026-10-08用户要求以实际碰撞为安全主判据并继续升高运动强度。沿用单窗pilot_v2相同
W1开口、x500、固定平面、起点、窗后目标、相位0、规划器、MPC、PX4和40秒上限。
每档中心/自由各一次，中心只固定穿越点两坐标，其他决策自由。

pilot_v2已测试静态、1Hz/2m和2Hz/2m；它们保留为独立先前证据，本批不重复。
本批预定频率路线：A=2m，f=1.5、2.5、3、3.5、4Hz；振幅路线：f=1Hz，
A=2.5、3、3.5、4m；联合路线：(1.5Hz,2.5m)、(2Hz,3m)、
(2.5Hz,3.5m)、(3Hz,4m)。三路线逐级交错执行，所有预定档位保留，
不因某档失败便推断更高档必失败。13组26趟，每条件初相各一次。

安全主判据为Gazebo W1窗框与x500的实际接触。一次正常正向越面、整机退出、
到达窗后目标定义完整竞速时间；碰撞后即便到达目标也不是安全成绩。
跟踪误差、采样球净空、求解耗时属于诊断量。碰撞、未完成、缺真值和起飞设施故障
分别记录。只有双方都无碰撞完赛时比较时间差。两方world、MPC和PX4配置逐对核验。
仅起飞前设施故障可重试一次，所有尝试保留。原始结果不覆盖。
