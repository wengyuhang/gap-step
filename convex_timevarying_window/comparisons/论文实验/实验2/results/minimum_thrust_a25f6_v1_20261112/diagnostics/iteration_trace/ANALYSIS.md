# 5000次迭代耗尽的逐次日志诊断

2026-11-12。使用冻结sip_planner二进制、同一图/初值/参数，只启用现有SIP_IPOPT_TRACE=1打印选项。5000次终止的原始PVAJ、目标、违规量和状态与原结果逐位相同，见REPRODUCTION.json。新求解单独保存，原结果保留。

## 观察

96变量，4个等式、683个不等式。初始有限约束违反量约0.00605，第2步降至3.71e-6。第401步首次进入恢复可行性阶段，5000步中共1078步处于恢复阶段，共23次进入。37步的接受步长比例小于1e-8，最小9.19e-16。总计8620次目标评估、13245次约束评估，IPOPT约103.25秒。

| --- | --- | ---: | ---: |
| 0 | 常规 | 6.05e-3 | 1.19 |
| 1889 | 常规 | 6.22e-8 | 2.23e-2 |
| 1890 | 常规 | 7.05e3 | 15.1 |
| 3573 | 恢复可行性 | 3.25e-11 | 1.82e-4 |
| 3574 | 常规 | 0.563 | 0.110 |
| 5000 | 恢复可行性 | 7.47e3 | 4.21e-2 |

恢复阶段的dual infeasibility属于恢复子问题，不能当作原目标的一阶最优性。1889步虽已满足有限约束容差，原目标一阶误差仍为0.0223，大于设置的dual_inf_tol=1e-5。随后继续优化导致约束违反跳升。全过程在压缩目标、失去可行性、恢复可行性、重新优化之间反复，未形成稳定局部收敛。

现有函数中近零推力时存在1/rho、1/rho^3和1/rho^5，前次末点C++Jacobian审计发现动态约束分块范数达1e10至1e11。有限最小推力节点不能限制全部试探点。当前还采用nlp_scaling_method=none和6对历史的L-BFGS Hessian近似。这些设置可能影响病态区域的步模型质量，尚未用单因素对照确定各自贡献。

## 结论边界

记录确认了反复恢复和缩步耗尽迭代的实际过程。它没有证明任意增加迭代均无效，也没有证明当前轨迹问题不可行。原17.359秒中心轨迹可在自由点模型精确表示，提供了合格可行轨迹的直接证据。当前应优先处理近奇异处函数与导数的数值条件，再验证有限问题收敛。

IPOPT字段定义依据 https://www.coin-or.org/Ipopt/OUTPUT.html 。全部解析逐次数据见iterations.jsonl与TRACE_SUMMARY.json。

## 动力学评估节点与推力下界节点不一致

新增C++单点恢复诊断见../singular_nodes.json与../probe_singular_nodes.cpp。原实现为各残差分别保留见证集合，第七项最小推力仅在自己的三个基础点和初值驻点处受约束。其他电机约束在自己的峰值时刻评估原逆平坦映射。

末次候选第5段u=.7898783779的第三电机约束归一化残差约7465.7，总推力只有.682649 N。u=.7836187343的第四电机约束残差约4911.9，总推力只有.249374 N。两个时刻均低于新增.7693722 N下界，却没有在这两个时刻施加第七项约束。它们已处于当前有限NLP的动力学评估位置，故除连续节点间遗漏外，存在定义域下界与动力学评估位置未统一这一具体实现缺口。

修正方向应包含在全部动力学评估节点施加同一最低推力下界。IPOPT仍允许不可行的中间试探点，故统一节点本身仍不足以使每次函数求值都处于正则域，域外公式延拓需另行验证。本次诊断未修改或重跑正式结果。
