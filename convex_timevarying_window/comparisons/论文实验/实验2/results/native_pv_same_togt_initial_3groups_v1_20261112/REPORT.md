# PV MINCO同初值对照实验

日期为2026-11-12。本轮使用C++17、CasADi和IPOPT，评估完整七窗及返航轨迹的规划与几何复查。

## 设置

沿用上轮三组各自已选出的动态TOGT中心轨迹，编号分别为5、7、7。固定相同初始段时长、过窗位置与三维速度。每组自由点和强制中心各使用一个初值，同时运行两个进程。

调用原MincoPV库的derivative_order=1。内部节点开放位置P和三维速度V，A、J由最小snap带状线性系统消元。端点沿用场景起终点及零VAJ。自由点轨迹变量43个，中心29个，均包含21个V变量。每种方法仍有1584个动力学辅助变量。

时间权重1，动力学软惩罚权重1000，每段33个动力学积分节点。保留原安全内缩、0.1 m/s法向速度约束及安全补点复查。段时间使用TOGT正映射，时间范围和工作空间硬约束均关闭。新有限问题使用上一轮原始变量和乘子，单次有限问题上限5000次，失败即结束该初值。

成功候选额外通过独立C++网格碰撞复查、七窗有序正向恰好一次穿越及端点检查。浮点自适应包络与网格距离构成名义轨迹的数值证据。Gazebo闭环执行尚未验证。动力学使用软惩罚，当前结果不提供全域动力学硬约束证书。

运行上限和不可行状态按原始返回值保留。单初值失败表明本次求解未找到合格规划，无法据此推断赛道全局不可行。
