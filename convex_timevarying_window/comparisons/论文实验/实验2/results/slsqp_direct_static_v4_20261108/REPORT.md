# 直接SLSQP与IPOPT静态对照

静态七窗口，自由选点，完整七窗后返航。每方四个相同的独立解析初值。

|求解器|完整参考时间/s|完整目标J|四初值求解耗时/s|合格初值|
|---|---:|---:|---:|---:|
|IPOPT|15.733920592|15.733923383|208.281|4/4|
|SLSQP|16.415551569|16.415598057|646.620|2/4|

SLSQP直接优化96个轨迹变量，不构造辅助变量。保留改进解析初值、固定32积分、TOGT正时长映射、MINCO偏差坐标、多边形规范及原安全交换。
SLSQP使用解析一阶导与拟牛顿曲率，ftol1e-8；IPOPT使用解析二阶导，其各项收敛容差另见原协议。两种停止规则分别记录。
只计算规划轨迹，没有Gazebo飞行。所有失败初值及原始求解记录保留。
