# MincoPV完整PVAJ独立求解与失败诊断

2026-11-12，0.25／6自由点。C++17，单初值。

## 实现与验证

直接编译链接仓库 `静态凸窗口/复现/experiments/free_velocity/minco_pv.cpp`，调用 `MincoPV(head,tail,8,3)`。每次函数评价独立 fit 本轮世界P、实际VAJ和各段T。系数导数通过原类 propagate 和新建 C++ CasADi 几何图计算，包含移动窗位置对到达时刻的导数。8段、96变量，其中时间8维、内缩窗内参数25维、实际VAJ单位缩放63维。

正式新入口跳过旧symbolic、baseline、trajectory、physical_curve轨迹图。输出和外层复查直接共用本轮MINCO系数。仅复用以单段系数/时间为输入的原frame和六项dynamics局部函数。基线加偏移、旧图兼容转换均未进入该入口。

验证12组扰动系数相对误差≤1.4051e-12，初始几何绝对误差≤6.1729e-14，36次方向差分梯度相对误差≤4.4963e-9。系数对求解变量Jacobian声明非零项3072，完整矩阵18432项。最小推力单元测试通过。见VALIDATION.json。

## 设置

沿用最小推力验证批次的原动态TOGT中心物理初值、独立TOGT正时间映射、纯时间目标、95%六项动力学、0.7693722 N最小总推力、窗内缩和安全几何、24轮外循环、每轮5000次有限NLP上限、补点后回到同一原初值。使用原limited-memory Hessian设置。未启用其他开发试验的动力学延拓、范数残差、推力辅助变量或可行SQP。参数及哈希见PROTOCOL.json。

## 少量变量仍未收敛的具体证据

最严重有限约束为第5段u=0.789878391424的第三电机残差，值327801.97516，对单位缩放变量的Jacobian行范数2.83086047624e+14。该点总推力0.162050318843 N，jerk模长215.289828，snap模长4402.15402，Hopf分母0.205833681。这一点对应低推力下的逆平坦映射敏感性。全部段内推力驻点检查又找到最低0.000390512642988 N。

本轮有限问题的最低推力节点与电机约束节点分别维护。第5段最低推力节点为[0.0, 0.5, 0.7798326998438395, 1.0]，未包含发生最大电机残差的u=0.789878391424。因此新增推力下界尚未同步保护全部动力学评价点。即使在设有下界的位置，IPOPT也允许中间迭代暂时违反不等式，原有分母仍会被数值评价。这一设置按本轮“其他设置先不动”的要求沿用，尚未修正。

动力学恢复包含 n=(a+g e3)/||a+g e3|| 及其导数，原式存在r、r^3、r^5分母。低r候选会放大约束及导数。最敏感的第一个时间参数，解析偏导为-1.727255780e14，1e-9中心差分为-1.727224141e14。小步长差分趋向解析值，同时10^-8级参数扰动已使该电机残差从327802升至877809或4326028。这支持约束局部病态的诊断。

完整PVAJ给定后，MINCO系数构造仍为带状线性方程。当前未收敛的是外层时间、选点、VAJ与恢复动力学耦合的有限非线性问题。变量数量和约束数量不能保证该局部算法达到KKT条件。原生MINCO接口与梯度回归通过，外层收敛仍需解决。
