# MincoPV与当前完整PVAJ系数生成核对

2026-11-12。按用户要求只读检查静态凸窗口/复现/experiments/free_velocity/minco_pv.cpp及对应hpp、planner调用。未修改这些文件。

MincoPV的derivative_order=1、2、3分别规定内部PV、PVA、PVAJ，对应C5、C4、C3。fit每次用本轮节点值和时长重建8N维带状线性系统，solve直接得到物理时间幂基系数。propagate通过转置带状求解回传梯度，addSnapEnergy仅在外层传入有效正权重时加入能量代价。

当前论文实验旧路径用位置式MINCO基线加63个VAJ偏移作为坐标，再用共享完整PVAJ生成归一化七次系数。新增direct_pvaj试验将优化图中的VAJ替换为直接缩放的实际VAJ，但结果输出仍通过旧图兼容坐标转换。完整独立C++ MINCO模块尚未接入当前实验。

C++将这份MincoPV编译为参照，读取当前physical_curve导出函数，对20组8段完整PVAJ进行比较。物理时间系数转换为归一化系数后最大逐元素归一化误差9.77275e-12，VAJ伴随梯度与当前自动微分梯度最大归一化误差3.77677e-16。两者完整PVAJ模式的轨迹系数及这项梯度数值相符，不能据此断言更换系数求解模块即可修复外层NLP收敛。

PV或PVA模式仍需通过最小snap条件消去未指定的更高阶节点导数。简单保留位置式基线的A/J并只改变V会形成另一种轨迹表示。当前本文实际开放完整VAJ，和这里默认PV模式的自由度不同。

动态适配时，应在外层查询穿越时刻的窗口位置和姿态，并把节点位置对累计时间的导数贡献加入grad_durations。该文件只提供给定世界节点状态的MINCO核。
