# 第二组动力学半无限约束与补点试验

2026-11-12。原实验2 mixed_base，自由选点，全局七窗与返航。优化和复查均为 C++，图导出使用 wyh 环境。当前完成这一组开发验证。

## 最终设置

初值取本组动态 TOGT 中心轨迹，20.572194510 秒。圆窗与多边形采用原 TOGT 映射。各段时间对齐作者 TrajSolver::forwardT 的独立正映射，初始系数误差为 0。旧正式 IPOPT 图采用到达时刻作差和截断，存在实现差异。

动力学包含两项机体角速度、四电机推力，沿用重力模型、固定 tilt-yaw、x500 参数和 95% 限值。初始集取每段起点、中点、终点及初值各项局部峰值，共 199 条标量约束。每轮有限 NLP 收敛后，搜索整段超限峰值并补入段内归一化时刻。原几何补点同步累计。按用户要求，每轮补点后回到同一动态 TOGT 中心初值，乘子清零。

对于尚未找到超限的候选，用多项式 Bernstein 范围、动力学区间运算和中心导数界覆盖整段。两相邻段的端点分别检查，覆盖 snap 的两侧极限。结果是普通浮点包络数值证据。有限约束要求归一化残差不超过 -1e-5，复查接受上界不超过 1e-6，以预留数值收敛余量。

## 失败诊断与范围

旧时间参数化下，起中终三点初始集达到 5000 次迭代仍未满足约束，精确 Hessian 对照返回 Restoration_Failed，加入初值峰值后仍达到迭代上限。另做过圆窗内支限制和相对时间映射诊断，该版本仍失败。新增圆窗限制已撤销。

本次成功包含半无限动力学补点与时间参数化修正。进一步量化改动贡献需另作同条件消融。原始结果在 free_togt_time/result.json，逐轮统计在 ROUNDS.json，独立复核在 VALIDATION.json 及 free_togt_time 下两个 assessment 文件。失败记录位于 free、free_exact、free_peaks、free_stable。
