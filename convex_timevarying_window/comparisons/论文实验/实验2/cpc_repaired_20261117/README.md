# 动态CPC修复重跑：固定协议（2026-11-17）

本批修复旧CPC适配的数值与验收问题，旧结果在../cpc_audit_20261117完整保留。复用../robust_ipopt_full_20261117/source_inputs的22个冻结场景和QuadA，不改窗口、碰撞球0.15m、起终点或运动。仅规划，不使用Gazebo。

## 最终算法

原作者完整13维刚体状态/4电机输入、CPC进度与顺序、最小总时间，中心替换为已知运动函数c(t)。每场景只有一条作者折线位置/速度3m/s/原进度初值，400控制区间。不使用其他方法或其他场景的优化结果，不做多初值选优。

1. 等价消去τ辅助变量。原0≤τ≤r²、0≤λ(d²−τ)≤ε，在其余变量上的投影严格等价于λ(d²−r²)≤ε，λ≥0。r=0.3米不变。证明见TAU_ELIMINATION.md；没有添加安全代价/过滤/SIP。消去400×窗口数个变量与冗余下界。
2. 保留原四元数微分方程，计算推力方向时使用q/||q||表示旋转；每控制区间16个RK4小步。连续单位四元数模型相同，有限步长数值实现有明确修改。不在每个子步投影四元数，也不强制原始q实部等于1。
3. ε统一按0.01、0.001、1e-4、1e-5、1e-6、1e-7、1e-8延续。上一阶段变量/乘子传下一阶段；非成功状态则终止该条件。Solve_Succeeded和Solved_To_Acceptable_Level都按IPOPT success判阶段完成，原状态逐项保存；最终独立检查有限残差和实际任务。不是多初值，所有阶段耗时累计。
4. 首阶段IPOPT原默认求解设置/10000迭代，后续精确Hessian、adaptive barrier、primal-dual warm start、constr_viol_tol=1e-9、bound_relax_factor=0，每阶段10000迭代；无墙钟截止。原一般约束表达的变量界限保留，未采用开发中试过的lbx消元版。
5. 起终位置、零速度/角速度、终态水平姿态、初末hover电机仍沿本次共同任务适配，区别于作者可选终态配置，不能称完全未修改的官方动态代码。代码里的fidelity参数正式始终为1；rawstep保留作追溯，正式不先求旧模型。

## 验收

使用实体球/真实STL、≤1ms原生参考采样及有限开口括根；导航点最近距离同时包含全部优化节点，避免均匀采样漏掉CPC节点命中。原0.3米判定仅保留既有1e-5米数值容差。实际门序、终点和碰撞分别检查，不把进度清零直接当完成。

终点位于某门平面时遵从场景既有规则：根后整段法向距离均在1e-5米内且末端静止，才作为终端接触排除；真正进入另一侧的事件不排除。旧“仅最后一个控制区间”规则太窄。

从初态用64RK4子步/控制区间独立推进，不重置到优化节点；最大位置偏差>0.01米不接受为有效轨迹。原生采样和独立积分数值检查不是连续安全证书。矩阵报告必须标明积分未通过，不用这种结果断言真实飞行碰撞。
