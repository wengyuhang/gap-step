# 原七窗时间收益为何约4%到5%

按已验收结果，以原目标最小的合格候选择优，分别审查自由点、强制中心。两者均联合优化时间和内部VAJ；自由点额外开放窗口内位置。中心不是只取中心作初值，而是没有选点变量。

|原场景|时间收益/%|平均门距/m|平均点偏移/m|自由/中心实际轨迹路程/m|
|---|---|---|---|---|
|2026111301_low|4.14|22.70|0.815|169.50 / 179.05|
|2026111301_medium|3.81|22.70|0.808|165.10 / 170.29|
|2026111302_medium|4.76|23.01|0.784|166.74 / 176.92|
|2026111303_medium|5.03|22.04|0.837|159.07 / 172.95|

点已经明显偏离中心，不支持“优化器根本没有用自由点”的解释。平均偏移约0.8m，而门距约22–23m，米级切弯相对整条约155–163m中心折线只占较小比例。两方又都能优化到达时刻和节点运动状态，因此强制中心仍是较强对照。

固定同一组到达时刻，把节点从中心c_i移动到p_i，记δ_i=p_i−c_i，起终点不变。三角不等式给出中心折线与选点折线的长度差绝对值不超过2∑‖δ_i‖。因此窗口大小固定时，收益相对量级与可移动距离/门距有关。这个不等式仅说明空间尺度，不是飞行时间上下界；运动相位、加减速和动力学软惩罚还会改变时间。

原数据中，自由点轨迹比中心少约5.2–13.9m，时间少约0.64–0.84s，方向一致。现有结果不能证明已达全局最优，不能把4%到5%当物理上限。

增加窗数可能增加绝对收益，但不保证百分比增大；把门放得更远也可能降低选点的相对作用。因此新实验固定规则同时比较窗数、形状和成对间距，不依据谁赢筛选赛道。
