# 自由点独立优化：数值尺度与求解质量检查

同一设置在原12档完成：自由点快6/12档，另6档仍慢。两方法均12/12找到合格轨迹；不能称为自由点稳定优于中心。全部保持独立求解，未将任何中心优化结果输入自由点优化器。

## 查实的原因

- 将三条落后轨迹的中心结果仅代入自由模型求值：系数和目标逐值一致，未调用优化。因此模型的包含关系成立。
- 六条旧候选全变量、五步长差分检查未发现明显AD错误；例如Split-S中档自由候选返回成功时，归一化目标的时间梯度最大值仍达63.85。未把SLSQP的正常返回当作KKT精度或局部最优证明。
- 动力学软罚在边界附近有很高曲率；固定单位的时间、V/A/J和选点耦合，使有限求解对数值坐标敏感。六条旧、六条新选中曲线均检查了TOGT奇异分支距离，全部没有使用fallback；这些选中曲线的落后不能归因于该分支。
- 仅将ftol从1e-8收紧到1e-12不能修复：三档多数初值反而失败。负结果完整保留。

## 同一数学问题的坐标调整

以h_i=sqrt(T_i*T_{i+1})表示节点相邻段的时间尺度，求解变量与实际d阶导数满足D_i=固定单位×(h_i初值/h_i当前)^d×z_i，d=1,2,3。该映射一一可逆，原始物理初始曲线不变。配合每个有限问题开始时固定的对角数值预调理，仍使用同一PVAJ MINCO、TOGT正时间映射、目标及约束。没有增加snap目标、动力学限制或选点惩罚。新旧曲线/目标等价及全变量梯度通过测试。

## 解释边界

自由点全局最优的总目标不大于中心全局最优总目标，不代表两个独立局部求解器的输出必然有此排序；且总目标同时包含软罚，单独飞行时间没有无条件包含关系保证。本次主要差距仍超过软罚差，因此剩余落后主要是有限局部求解质量问题，未宣称已彻底修复。

Split-S的8个原始启动中实际只有6个不同曲线（0/1及2/3重复）；为使本轮只比较数值求解，未在中途改变初始化。两方重复完全相同。AirSim和AlphaPilot各8个不同曲线。

完整原始来源：results/normalized_equilibrated_v1（三档）与results/normalized_equilibrated_remaining_v1（另外九档）。旧结果与所有负对照均保留。

## 本轮结论

问题空间包含中心点这一点没有实现错误。独立有限局部求解的质量和数值终止确实有问题；等价坐标调整能显著改变结果，说明不能仅将差距解释为轨迹自由度本身。已获得部分提速和更多合格独立初值，但尚未实现自由点稳定快于中心。新增单位/预调理保留为显式实验选项，默认参数未以逐场景择优方式替换。

没有使用所有数值设置各自最好的结果拼出一张“自由点全胜”表。还需在固定同一有限问题上处理SLSQP提前终止和相位非凸盆地；不通过中心优化解初始化规避。
