# 共同原始初始化诊断

2026-11-16。用户要求各方法从相同原始初值独立优化，不用一个优化问题的解作为另一个问题的初值。随后澄清窗口运动函数应直接包含在规划中。

## 当前实现

prepare.cpp不调用任何优化器，不读取求解结果。以当前固定名义门位置的几何距离与3、6、9、12米/秒四档速度、每档两个原始逐段时间扰动模式，生成8条时间序列。给定这些初始时间，在原运动函数上评价初始穿越中心，直接用position-only MincoSnap生成实际VAJ，再供原生完整PVAJ MINCO优化。

自由点与中心对应原始段时间和VAJ逐值相同，自由点位置初值全部在中心。初始轨迹不是某方法优化后的结果。此阶段已实现并测试本文两个方法；五方法完整初始化适配尚未完成，不能声称本轮为新五方法公平对比。

## 运动函数仍在优化中

正式图内为t_i=sum(T_k), p_i=c_i(t_i)+R_i q_i，c_i使用原平移/摆动函数。段时间每次变化都会改变当前穿越点、相位与相应梯度。初始化阶段对c_i(t_i^0)的评价只用于确定初始曲线，正式优化没有把动态中心固定为采样点。

## 测试结果

只针对此前双方未找到的AirSim3Hz，安全球0.20米、碰撞球0.15米。原直接初值从317～352秒改为29～116秒。本文自由/中心各8独立初值，共16个尝试，15个首轮优化失败，1个中心初值在38分42秒仍未返回时主动结束并记为未完成。最后自由seed6自行返回Restoration_Failed，其余完成的主批均Maximum_Iterations_Exceeded。所有尝试均未进入安全复查。

另对相同seed4进行自动数值缩放/目标常数归一化/L-BFGS历史20的对照，自由和中心均首轮5000次，未解决收敛。

尝试给原生PVAJ MINCO添加可二阶微分的等价端点表达用于精确Hessian，原生MINCO仍负责系数求值。选定方向导数检查通过，但中心对照51次Restoration_Failed，自由对照6分30秒时主动结束记为未完成。未将此未验证改动纳入生产，原生产native_minco_pvaj.hpp已按改前字节恢复，诊断头保存为native_minco_pvaj_second_order_diagnostic.hpp。

## 结论与范围

没有获得新的合格轨迹，当前未找到问题尚未解决。新共同原始初始化链满足不借用优化解的要求，但所测原始时间/VAJ策略没有改善该条件的有限收敛。当前证据不足以确定唯一根因，不能将安全可行性或物理可行性与有限优化失败等同。需要继续检查初始状态质量、MINCO全链导数及动力学软惩罚辅助变量的数值条件。
