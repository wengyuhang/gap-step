# TOGT与本文有限求解的交叉核查

2026-11-16。固定AirSim freq3原场景，安全球0.20m、物理碰撞球0.15m，未改任何正式算法、场景或历史结果。所有数值评估和优化均为C++。Python仅整理文件与表格。

## 已确认

1. 由轨迹导数恢复动力学的流程正确。作者TOGT同样用a、jerk、snap恢复角速度、角加速度、力矩与四电机推力。对历史TOGT中心轨迹，在本次评估的5654个节点，两份模型单点罚项最大差约3.55e-12；15个有罚项节点的作者解析导数有限差分最大相对误差1.41e-8。这些是所测轨迹和节点的证据，不是全部模型分支的证明。
2. TOGT每段16区间，本文32区间。历史TOGT中心轨迹时间32.436590秒，16区间动力学罚项积分为0，32区间为1.537471，256区间为1.986152，均包含动力学权重1000。新同初值seed4轨迹23.009462秒，对应为0、5.716511、6.995119。积分更密会发现原积分漏掉的峰值，但这项差异本身不足以解释本文5000次迭代失败。
3. TOGT停止标准为past=3、delta=1e-5、梯度容差关闭。历史中心最终无约束梯度无穷范数1.94895，新seed4为1.72186。作者正常返回不等于满足本文IPOPT的KKT标准，不能直接比较两种success标签。
4. 同8组未经优化的原始时间输入TOGT中心，重新计算同动态中心和最小snap VAJ，8组均正常返回。与本文共享原始物理曲线（原始初始化审计已检查重构误差）。此次未给TOGT加SIP安全约束，也未做新轨迹最终连续安全/顺序检查，故不能记为8次安全成功。
5. 本文此前16候选均未进入安全复查。问题在首个有限NLP求解阶段，不能归因于新补入的安全约束。

## 有限问题结构

21窗下，TOGT中心只优化22个段时间；内部VAJ由最小snap条件消元。本文中心保留211个真实轨迹变量，自由点253个；动力学软罚另有4356个辅助变量，形成4567/4609维NLP。完整PVAJ仍由原生MincoPV独立构轨，没有修改为基线加偏移。

变量数量差异是已经核实的结构事实；大量零罚项辅助变量造成的弱曲率、完整PVAJ方向的尺度与曲率、以及L-BFGS近似质量，是待分离验证的数值机制，不能据此宣称已经找到唯一根因。

## 修复顺序

- 保留运动函数进入优化、完整PVAJ MINCO、由轨迹恢复动力学、原有安全定义与共同原始初值。
- 先在同一个首轮有限问题上排查求解。动力学软罚的辅助变量可精确消去：s>=0、s>=g(z)，最小化rho(s)等价于直接计算rho(max(0,g(z)))；rho为现有C2平滑正部罚函数，直接整体写成该分段C2函数即可，无须改变软惩罚的意义。
- 这会删去4356个辅助变量，但本仓历史直接目标版本也曾失败，故仅删变量不能视为解决。应同时检验原生MINCO一阶链式导数，构造可二阶求导的等价端点表达供稀疏Hessian使用，并在完全相同有限问题上比较。先前精确Hessian诊断仍保留辅助变量且出现Restoration_Failed，也不能视为二阶法已解决。
- 用有限约束违反、对偶残差、步长与线搜索记录判断收敛；只有当前有限问题收敛并满足约束后，才进入原SIP安全复查与补点。未达到条件如实记失败，不用TOGT停止标准冒充IPOPT收敛。
