# 自由穿越点的实际允许范围与使用情况

2026-11-16。审核当前统一固定目标六条件。直接复用规划器的planar_points::domain，并从最终MINCO轨迹恢复穿越时刻的门内坐标。审核全部41条合格自由候选的477个点，其中六条最终选中轨迹共78个点。

## 所有窗口相同的点域尺寸

|窗型|物理开口|内缩量|允许选点区|允许面积|原开口面积|面积保留比例|
|---|---|---|---|---:|---:|---:|
|方窗|1.5×1.5米|每边0.3001米|qx、qy各∈[-0.4499,0.4499]米，边长0.8998米|0.80964004平方米|2.25000000平方米|35.9840%|
|圆窗|直径1.5米|半径内缩0.3001米|qx²+qy²≤0.4499²，直径0.8998米|0.63588980平方米|1.76714587平方米|35.9840%|

方窗单轴最多偏移44.99厘米，角落距中心最多63.625厘米；圆窗向任意方向最多偏移44.99厘米。全部六条件均使用这些尺寸。

有限距离0.3851米以框管中心线为参考，减去框管半径0.085米，得到实际物理开口内缩量0.3001米。代码把框管半径计入一次。核对了实际finite_input.json中的变量上下界乘回point_scale_m，逐项等于这个物理范围；还检查了原生MINCO图中的半空间/圆盘硬约束。

这里的区域定义在每扇门自身坐标中。绝对穿越位置为p_i=c_i(t_i)+R_i[qx,qy,0]，随各窗自己的运动变化。点域是穿越点位置约束，完整穿越过程的安全约束进一步限定时间、VAJ与局部轨迹的组合。

当前数据支持两个具体观察：内缩后保留约36%的开口面积；实际最优候选已经大量使用允许区域边缘。时间提升的幅度还取决于赛道几何、可行时间、VAJ与动力学软代价之间的耦合，单独核对点域尚未完成各项贡献的因果分解。
