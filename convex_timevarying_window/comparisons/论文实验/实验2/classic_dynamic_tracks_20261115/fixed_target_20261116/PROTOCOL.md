# 固定赛道、统一启动规则 v1

2026-11-16。Split-S 7窗、AlphaPilot 11窗、AirSim 21窗各中/高两档。全程直接使用原冻结目标场景，每扇窗有固定的独立运动参数。优化时每次查询都是该目标运动。

## 初始化与优化

同一规则对六条件生效。每条件采用原八组独立逐段时间。每一组先由当前目标场景的动态MINCO中心时间优化生成种子，然后恢复实际PVAJ，同时用于对应的本文自由点和中心点。自由点选点初值是中心，中心版无选点变量。八组都进入各自SIP，不在初始化阶段按某个方法成绩筛选。

时间种子是独立本次生成，只查询当前原目标。其L-BFGS停止条件仅用来生成初值，正式接纳仍要求本文有限NLP收敛及完整安全复查。

采用原生完整PVAJ MINCO、TOGT正时间映射、原33节点动力学软积分、权重1/1000、原安全球/内缩/正向条件、5000有限迭代和24轮。统一把冷/热启动bound/slack push和frac设为1e-9，print_level=0。失败候选按原规则停止。

八路目标时间种子并行，然后自由/中心八组共16路并行。六条件按固定顺序逐一执行。时间包含初始化和实际等待自身结果与复查的墙钟。所有有轨迹候选接受原独立边框碰撞、按序一次穿窗和终点检查，合格候选按原总目标选择。

本协议及二进制冻结后，六条件使用相同规则和参数，出现未找到如实记录。原幅度延续版本保留为开发记录，当前结果单独产生。

逐窗运动来源是原冻结场景。现有移动门分别有横/竖/斜平移，上/侧/斜支点摆动，幅度、频率和相位各自固定。仍保留原场景静止门。运动清单由原JSON直接导出，不重新生成运动。

机器设置见config/protocol.json，原场景SHA见TARGET_SCENES_SHA256.json。规划数据与实飞数据按原项目约定记录，本批只规划。
