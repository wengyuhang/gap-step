# 单次有向穿窗的局部侧别约束设计

2026-11-16。用户指出自由点同样有潜在反穿风险，要求设计共同防止机制。当前为数学设计与只读验证，尚未接入生产IPOPT或重做优化。

## 当前场景与目标

当前窗口平面固定，中心在平面内已知平移/摆动。第i窗的指定穿越时刻是第i段末端，正向单位法线为n_i，定义球心有符号距离

\[
s_i(t)=n_i^\top[p(t)-c_i(t)].
\]

正值为出口侧，负值为入口侧。局部区域取球心在物理开口中的投影、且|s_i|<r，r使用当前0.30米规划球半径。该区域随原窗口运动查询更新。

局部区域内要求预定穿越时刻前s_i≤0，之后s_i≥0。中心/自由点采用同一规则，选点和PVAJ继续联合求解。该条件与现有连续机体—窗框距离条件共同使用。

## 放入同一SIP问题

每个轨迹段以u∈[0,1]归一化。在正段时长映射下，第k段相对于第i窗指定节点的前后关系固定，令σ_ik=−1（节点前）或+1（节点后），要求在当前局部区域中σ_ik s_i(x,u)≥0。优化中仍由当前段时间计算实际时刻，查询当前窗口位置，计算当前多项式和局部坐标。

局部区域条件也应是有限约束表达式的一部分。补点只固定(gate,piece,u)，后续变量变化后，该时刻是否仍处于局部区域会随当前轨迹重新计算。

一种精确连续不等式表示如下。令a(x,u)>0表示球心在局部区域内，b(x,u)=−σ_ik s_i(x,u)>0表示位于错误侧，则

\[
g(x,u)=a+b-\sqrt{a^2+b^2}\le0.
\]

当a和b同时为正时g>0，其他情况g≤0，因此它编码原局部蕴含条件。a可由方窗半空间余量或圆窗(R²−||q||²)/(2R)，再与r±s的正区域交集构造。交集的符号也可由A+B−sqrt(A²+B²)表示。此表达式在两个参数同时为零处存在不可微点，数值接入需要实际检查，此处未实施IPOPT接入。

## 检查与补点

每轮有限问题收敛且有限残差合格后，沿原流程做连续几何和穿窗事件复查。发现额外穿越，沿该根两侧找处在错误侧且仍位于局部区域的点，按该条件的实际违反程度选择每窗一个点。反穿根本身s=0，应取其附近实际错误侧位置。示例失败中心第6窗在穿后20毫秒为s=−1.438毫米，可形成真正被违反的新约束。

原始变量及成功乘子按原规则传给新增有限问题。最终候选仍须通过完整机体几何和单次穿越事件复查。该设计不依赖修改目标权重或给定新的固定过窗速度。

## 为什么能够阻止反穿

假设预定穿越时刻后出现反向穿越，且根处投影位于开口内部。连续性保证根后存在一个时间邻域，球心仍在局部区域中而s<0，与节点后的侧别条件矛盾。节点前出现额外反穿时，根前的s>0违反节点前条件。同样可以排除预定时刻之外的额外横穿。该论证针对真实换侧的穿越事件；原完整事件检查继续作为最终验收。
