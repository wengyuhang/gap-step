# 连续复查与补点流程修复结果

2026-11-16。用户要求修复紧凑交错赛道的复查预算问题。本轮从原同一8组初值重新规划自由点与中心各8条。场景、PVAJ MINCO、TOGT正时间映射、安全球0.30 m、点域内缩0.3001 m、动力学软约束与1/1000权重、5000次有限迭代与24交换轮均保持。只规划。

## 修复内容

1. 每个窗口—轨迹段的几何复查在同一优先队列中继续细分，工作上限由512提高至16384。达到上限仍未解决时保留明确失败状态。
2. 删除固定1微秒区间宽度截止，只在浮点中点无法继续细分时返回unresolved。
3. 删除0.2毫米距离违反死区。任意实际样本距离小于原复查阈值即可返回violated。安全阈值维持0.385 m，包含原0.30 m球和0.085 m框管半径。
4. budget_unresolved与unresolved均不提供违反见证，最小采样位置另列诊断字段。SIP只补入明确violated且实际距离低于阈值的点。每窗仍最多补一个最严重新点。无新约束且复查未解决时记录geometry_verification_unresolved，停止当前初值。
