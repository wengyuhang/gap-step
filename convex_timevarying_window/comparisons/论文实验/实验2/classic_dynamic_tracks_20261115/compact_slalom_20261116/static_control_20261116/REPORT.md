# 同一紧凑交错7窗赛道的静态对照与中心失败分析

2026-11-16。用户要求检查动态中心未找到的原因，并测试相同赛道静态时能否找到合格轨迹。

## 对照定义

静态门固定于原存储名义中心，所有7门运动幅度改为0。平面、朝向、开口、形状、窗框实体、顺序、起终点和车辆模型均采用原场景。频率、相位、摆长等原参数仍保存，实际运动及速度为零。

初始8组逐段时长参数逐值相同，VAJ继续由各自当前目标的同一MINCO初始化规则生成。8路TOGT中心时间初始化后恢复完整PVAJ，给两方法相同对应初值，再16路SIP候选并行。求解器采用上一轮已修复版，规划球0.30 m、有限球0.3001 m、内缩0.3001 m、权重1/1000、5000有限迭代及24交换轮。只规划。

## 动态中心为什么未找到

### 已确认的有限优化与验收差异

动态中心8个初值均完成24个有限NLP，全部Solve_Succeeded。最后连续复查仍发现规划安全距离不足，以及至少一次重复开口穿越。该现象属于收敛的有限约束解未通过原连续安全/单次穿越任务要求。

当前有限问题要求在指定节点穿过移动中心，并在该节点具有至少0.1 m/s的前向法向速度。每个新增窗框距离点也被加入有限问题。单次穿越条件目前只在复查器中检查，repeat_aperture_crossing返回空witness，外层没有对应的单次穿越约束补回优化器。倒穿开口可以同时满足边框距离约束，因此仅补窗框距离无法直接排除这种动作。程序会在其他距离违反处继续补点，而重复穿越可以持续存在。

### 同一候选的独立根核对

以动态中心seed2末轮严格有限解为例，第6窗指定穿越时刻3.441436216 s，随后在3.454416857 s再次穿过同一开口，间隔12.980641 ms。该根处平面两侧符号改变、法向运动方向反转，局部平面点约(0.021424, −0.002305) m，距框中心线约0.813452 m。此处离框充足，纯距离约束不会阻止它倒穿。

动态中心seed0还在通过第2窗约163.6 ms后、第6窗约59.5 ms后出现同类额外穿越。用原生PVAJ MINCO恢复候选，节点误差均小于1e−10 m，再以原LAPACK多项式根内核及根两侧符号检查核对，见[DYNAMIC_CROSSING_AUDIT.json](DYNAMIC_CROSSING_AUDIT.json)。诊断候选仍保留found=false。

### 布局与运动的影响

名义相邻门中心距离2.973 m，但下一门中心距上一门平面的法向距离仅0.117956 m。相邻门方向变化80°、中心连线连续急转，这使出窗后的转向很紧凑。静态对照已找到中心轨迹，说明这些几何条件允许当前中心模型完成任务。动态窗口改变到达点与时序，激活了上述额外穿越与安全距离违反。当前结果同时受非凸优化、24轮补点预算及缺少单次穿越有限约束影响，尚不能推出动态中心问题物理不可行或全局无解。

## 第6窗反向的直接运动学原因

对动态中心seed2同一失败有限候选，沿第6窗前向法线投影，指定穿越瞬间速度0.133697937 m/s，加速度-20.649865 m/s²。穿后6.485191 ms速度降为零，球心最多前进0.433265 mm，随后倒退，12.980641 ms再次穿过开口。机体半径0.15 m，规划球半径0.30 m，此时机体仍跨在门平面两侧。

节点前向速度约束满足，但其后加速度与完整PVAJ曲线决定速度很快反转。有限目标当前惩罚时间/动力学，距离约束允许在开口中远离边框的倒穿，单次穿越只由复查拒绝，缺少传回有限问题的对应任务条件。逐时刻投影见[NORMAL_MOTION_AUDIT.json](NORMAL_MOTION_AUDIT.json)。本次只读分析，不修改生产算法。
