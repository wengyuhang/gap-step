# C++补点求解分岔诊断

本轮0.75／6×自由点未找到、0.75／3×自由点变慢的首次分岔均定位到补点后的有限NLP。冷初值第一轮相同，补点数值与有限问题计算图的组装方式改变了后续IPOPT迭代。两项受控实验使用相同起始变量、辅助量、乘子、参数和求解选项，分别精确重现旧版和新版的下一轮输出。

## 新旧结果

|条件|旧版选中时间|C++本轮选中时间|旧版独立自由点合格初值|
|---|---:|---:|---:|
|0.75／3×|16.307210415 s|18.062665465 s|5/8|
|0.75／6×|19.172615343 s|未找到合格规划|1/8|

时间含七窗与完整返航。最高档旧版只有ours_5合格，中心释放分支也失败。旧批十条件选中方案全部成功这一事实，与最高档只有一条初值成功同时成立。本轮丢失了这条原先唯一成功的分支。

两条旧自由点轨迹已使用当前C++边框复查及实体STL复查器重新检查，均通过56项边框检查、实体窗框、顺序和端点检查。复查的几何模型仍采用当前外包球与普通浮点包络。

## 第一处差异

0.75／3×与0.75／6×，两方法各8初值，共32对。第一轮有限NLP的全部返回物理变量逐位相同，迭代次数也相同。首次增加危险点后开始分岔。

最高档ours_5的首轮4471次迭代，两版原始变量完全一致。第一次复查中9项违规的通过/失败判定相同，但危险位置的归一化参数u最大相差3.441691376e-15。C++采用Eigen求根与原生算术，旧实现采用NumPy求根及其原坐标回代，两条数值计算链存在细微差别。

补点后的有限问题也采用不同计算图组装。原Python定义通过CasADi map批量生成边框约束，C++把已导出的函数逐点组合。固定为完全相同的旧补点数值后，在相同热启动状态上，目标值、约束值和目标梯度完全一致，约束Jacobian最大绝对差2.420619261e-12，稀疏结构相同。原有1e-8量级的迁移核对会判为通过，却没有覆盖这些数值差异对完整优化路径的影响。

## 固定相同热启动状态的受控求解

每个对照从同一份首轮返回的1680维变量、变量界乘子、约束乘子和参数出发。四组热启动原始量和对偶量数组完全相同，有限约束行数相同，求解器选项相同。Python图经离线导出后，仍由C++进程加载并调用相同IPOPT。

|当前C++补点和当前C++组装|403|491|
|旧补点数值和当前C++组装|392|242|
|旧补点数值和原有限问题计算图|349|684|
|上一行另采用原NumPy圆点规范化运算|349|684|

第一行逐位重现正式C++批次的下一轮返回变量。第三、四行逐位重现旧正式批次的下一轮返回变量。该两例的圆点规范化数组本身相同，规范化运算对这次分岔没有贡献。分别恢复补点数值与计算图的对照表明，两处迁移差异都能改变迭代路径。

## 最高档为什么最终变成未找到

|有限子问题顺序|旧ours_5迭代数|C++ ours_5迭代数|
|---|---:|---:|
|第1次|4471|4471|
|第2次|349|403|
|第3次|292|309|
|第4次|568|5000，有限几何约束仍违反|
|后续|继续到第8次，通过完整复查|本次尝试结束|

两版第2次的目标值仅相差约1.79e-9，但返回的完整PVAJ/选点变量最大相差0.273210013。相近目标值容许不同的高阶状态，后续轨迹与危险位置继续变化。旧版这条分支完成8个有限子问题，新版在第4个达到迭代上限且有限几何约束违反，依现有接纳流程结束。

最高档的中心已找到20.119989941秒轨迹。当前程序将中心解用于额外一次开放自由点优化，选中集只接纳优化完成并复查通过的返回轨迹。该释放优化失败后，初始化的中心轨迹本身没有成为自由点分支的最终候选，因此本轮标为未找到。旧版同样采用这项规则，先前由独立ours_5的成功掩盖了这个现象。

## 迁移核对的遗漏与本次范围

此前核对覆盖初值、目标、约束、导数和几何通过/失败，未检查补点后热启动的逐轮数值重现。将其概括为仅更换运行语言、可以直接沿用原求解表现过于乐观。当前已通过受控求解定位到补点数值和有限问题计算图两项差异，生产求解链尚待按这些差异修复并重新验证。

本次仅做诊断和局部受控求解。原正式50格规划、所有原始候选与实飞记录保留。旧批4222个文件SHA-256逐项核对通过。没有启动新实飞。

同目录history_comparison.json保存32对冷求解核对，validation.json保存对照断言，hard和slower分别保存同起点四分支输出与首轮变量/乘子。hard/finite_comparison/validation.json保存固定补点后的Jacobian比较。warm_probe.cpp及导出、运行脚本可复核诊断步骤。
