# cem_projected_state_initialization

2026-11-13

沿v3的71维CEM，每个独立搜索的最好候选增加最多40步阻尼Gauss-Newton可行性投影。有限差分原节点约束，联合调整到达时刻、返航时间及实际VAJ，接受原归一化违规平方和下降的步长。新增投影是算法机制变化，不得称为纯CEM。全部算入生成墙钟。当前批v4。

轨迹采用原生MincoPV derivative_order=3。起终状态固定，穿越点随实际时刻查询窗口中心。实际VAJ参与独立优化，不重新覆盖为最小snap。C++生成与导出，后端保持冻结原始Python/SciPy SLSQP。有限节点评价与连续几何最终复查分别保留。该版本不新增物理约束或放宽验收。

64个体、80轮、8个独立搜索并行；20%精英，均值/协方差0.7平滑，加1e-6单位阵用于采样，原节点容差1e-5。每轮已有精英保留，日志检查最好质量不退化。最终从全搜索档案中筛8条，不设来源配额。
