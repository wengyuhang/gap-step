# 时间—违规双目标八初值验证

使用当前高起伏七窗赛道，验证0.5/6与0.75/6。位置初值均取实际过窗时刻的窗口中心，VAJ由原TOGT位置型MINCO生成，后端使用原完整PVAJ硬约束SLSQP。

## 改动依据

前一版在有限节点可行之前，以最大违规量主导排序，容易选到较长的飞行时间。原0.75/6候选档案中720/1296条时长为30至50秒。当前将完整飞行时间和约束违规共同参与搜索，后端的模型、目标和验收流程沿用原设置。

定义T为七窗及返航总时长，V为原有限约束最大归一化违规量，Tref为原八个初值时长中位数。每轮CMA-ES采用评分J=T/Tref+lambda V，lambda取1、2、4、8；每次搜索保留时间—违规非支配候选。16次搜索共享候选池，最终按八个折中方向选8条，来源搜索数量自由。

每档16次搜索、最多8路并行、80代、每代24候选，共30736次评价。所有新生成与评分、MINCO构造使用C++。

## 文件

- initials_a50_f6.json、initials_a75_f6.json分别保存完整8初值、PVAJ、分段系数、原后端变量及违规数据。
- INITIALS.csv保存逐初值时长、8段时间、违规和来源。
- CANDIDATES.csv与FINITE_DETAILS.json保存后端逐初值结果和迭代信息。
- generation各档/PARETO_FRONT.json保存实际全局非支配候选。
- VALIDATION.json保存源文件SHA、数值等价、非支配性、择优与时间统计验证。
