# CEM结构修复与可行性投影验证

本版为CEM加可行性投影。每档8个独立CEM并行，各64个体80轮，实际时间和VAJ共71维，原生PVAJ-MINCO。原SLSQP自由点后端保持。

修改为完整正则协方差、精英保留、周期归一化绝对到达坐标、严格原采样容差排序。每个搜索最好候选做最多40步阻尼Gauss-Newton修复，有限差分原约束，联合调整时间和VAJ，按违规平方和下降接受。投影不是纯CEM，也不是连续安全证书。

## 证据与限制

八个搜索精英质量单调性检查通过；16条最终初值与原后端系数及约束一致性通过；合格候选原有限收敛、全窗数值复查和独立实体检查通过。见VALIDATION.json。完整结果见INITIALS.csv、CANDIDATES.csv及groups。

v2全协方差仍约0.26超限，v3到达坐标约0.25超限，因此开发批提前停止，已有原始文件保留，不能当成完成实验。v4第一档最小超限约0.103，第二档约0.283。

原对角高斯混合不同时间分支、未保留精英及时间采样尺度是可观察的设计限制。本轮多项同时调整，未进行逐项消融，不能把改善归于任意单独一项。进一步的关键困难是中心点候选下时间与VAJ的可行域搜索，不能仅靠本轮结果断言CEM本身无效。
