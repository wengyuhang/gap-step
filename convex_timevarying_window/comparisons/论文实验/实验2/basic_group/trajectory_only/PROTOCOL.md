# 实验二：基础组纯轨迹对比

2026-11-06起替代后续Gazebo实飞；历史实飞原始记录与结论不覆盖。

本阶段：静态，以及振幅2m、频率0.5/1/1.5/2/2.5/3Hz，共7条件×4方法。
只有original紧凑基础布局；4平移窗、3外支点摆动窗，固定窗平面，初相零。
窗口形状/尺寸/位置与基础组不变。增加幅度是下一阶段，不在本阶段扩矩阵。

四方法仍为本文全局自由点、本文全局中心、动态TOGT自由点、动态TOGT中心。
不改规划目标、动力学约束、选点映射/内缩、初值或优化器。每条件均四时间尺度1/.8/1.2/1.5，180s/初值。
本文取最短合格收敛候选，TOGT取原目标最低的收敛候选；不得按新的碰撞评估结果换选另一初值。
不补用别的方法的初值，不因结果不好重求。未找到规划单独列出，不认定物理无解。

一次全局规划起点→七窗→起点，八段七次轨迹，无滚动、无中途停车。
完整任务时间为八段时长之和，含最后窗后返航与终点VAJ=0，不用实飞提前结束阈值。
旧规划核对被冻结源码/场景/择解规则/结果哈希后复用，旧成功和失败均保留；新评估重新计算。
不得把旧Gazebo完成时间填入新表，也不得把旧实际碰撞直接搬成名义碰撞。

统一独立碰撞模型：现有x500整机外接球，半径0.3859447197013662m；窗框采用当前实际sleeve STL，不额外加规划安全余量。
检查每一段对每一窗的距离，含返航与非目标窗；地面也检查。
用多项式Bernstein位置包络、已知窗口运动范围、点到STL三角面的距离及1-Lipschitz下界自适应细分。
下界全通过才记“名义无碰撞”；发现负距离见证记“名义碰撞”；预算耗尽或近切触未分清记“检查待定”。
使用原始STL圆环多面体网格，不用其凸包替代。包络球可能比真实姿态机体保守，结果不能称Gazebo实体接触。
普通浮点包络不是Arb严格区间证书；结果不评价跟踪器，不证明连续动力学或闭环安全。

主表按同幅度频率递增，给完整名义任务时间与碰撞分类；求解/建图/独立检查耗时另列。
只有双方名义无碰撞且完成任务，才计算时间优势。每条件一次确定性比较，不估计随机成功概率。
