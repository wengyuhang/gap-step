# TOGT原始布局适配：先预检，后完整实验

用户否决外围环线，要求TOGT式赛道。已停止separated_mixed_v1，8条参考及中断求解保留，不用于此布局。
本布局来自官方FSC-Lab/TOGT-Planner固定提交6707d3a的resources/racetrack/race_uzh_7g_multiprisma.yaml；官方API提取元数据与原始文件哈希见upstream.json。

保留官方全部7位置的相对关系、穿越顺序与前6姿态，包括上下叠置Gate4/Gate5和交错折返。
场地统一乘2.2（沿用此前x500 TOGT布局适配尺度），统一z平移+2m离地；不再沿外围重新排窗。
继续使用当前2.9×2.3等七种小窗/原sleeve网格与x500内缩，未把开口同步放大。
原Gate7是半径0.3m SingleBall位置区域，没有物理窗平面；本任务将其换为当前第7矩形窗、yaw200°。
原终点是Gate6附近，本任务按用户完整竞速定义返回起点；原Gate3长度16m corridor/1个midpoint不移植，本任务仍8段和窗内节点。
因此这是TOGT布局的动态七窗适配，不能说原场景/形状/轨迹结构原样复刻。

四平移窗W1/3/5/7，三摆动窗W2/4/6，平面固定；W3平移与W4上层摆动是两个挑战窗，交替升档。
其他五窗固定W1=.30Hz/.75m、W2=.40Hz/1m、W5=.55Hz/1m、W6=.45Hz/.75m、W7=.35Hz/.75m，初相全0。

该筛查不保证任意轨迹不绕入其他窗；随后静态4方参考必须完整通过，低/最高动态TOGT必须无非相邻窗风险，全部预检通过才运行余下40项。
若实际参考出现非相邻窗碰撞或待定，保存并停止，不能忽略。预检参考直接复用，不因输赢重求。

本文自由/中心、动态TOGT自由/中心，10×4条，各4时间尺度1/.8/1.2/1.5、180s/初值。
规划目标、动力学和安全约束、选点映射/内缩、求解器和择解规则与前批完全相同，不添加中心回退或其他算法改动。
时间为七窗返航零VAJ完整8段之和；全部窗×全部段与地面用原独立自适应STL/球数值评估。
名义碰撞/任务异常/待定/未找到分开，只有共同名义成功比较时间；求解/建图/几何检查成本另列。
