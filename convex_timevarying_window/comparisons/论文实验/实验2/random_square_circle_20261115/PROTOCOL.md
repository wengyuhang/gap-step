# 随机方圆动态赛道冻结协议

参考Green等2026预印本A.2的周期样条、等弧长布门、切向布门及几何间距筛选。用C++周期三次均匀B样条，10个极坐标分区采样控制点；三个布局分别使用近椭圆、径向起伏、较大高度起伏的同族生成规则。布门法向取样条水平切向，窗口竖直。起点在第7与第1窗之间，终点与起点相同，零VAJ，全部方法计完整一圈。来源 https://arxiv.org/html/2606.27348v1#A2 。本研究加入方圆混合与动态运动。
