# Wang 2023：源码核对、修复与22场景规划

原论文：Qianhao Wang et al., Polynomial-based Online Planning for Autonomous Drone Racing in Dynamic Environments, IROS 2023, https://arxiv.org/pdf/2306.14461 。这是独立复现，不是作者官方完整实现。

## 最终批次

results_aligned为统一PVAJ初值对齐后的完整22条件：12通过、8碰撞、2未完成。22条均生成到终点的参考，但碰撞、重复/反向穿窗不能算成功。904个局部候选897收敛合格，226个局部请求均选到候选。每个条件独立运行一次，不从新旧结果择优。

修复前的本轮控制结果保存在results：11通过、7碰撞、4未完成，其中5个条件在局部规划阶段中止（部分已生成前缀同时碰撞）。三场景开发记录保留在aligned_dev，未混入正式结果。

## 查到的问题和改动

1. 全局参考迁移到当前局部状态时，原来只修正端点位置，没有修正实际速度、加速度、jerk及时间缩放对应的中间点。现在通过唯一七次Hermite修正对齐两端完整PVAJ，再生成原Q初值。MINCO、约束、目标、终点和4时间初值数量不变。单测误差2.3e-10。
2. 原来先选最低代价候选，再发现反穿便停止，可能丢掉其他可执行候选。现在先对每个收敛候选检查当前窗的正向穿越及整机退出，再按原目标选取；不使用整条安全复查择优，不给优化器加新方向约束。
3. 原来试探计算异常永久污染候选资格；现在以最终点独立重算的目标、梯度和有限性判断。此次最终批次没有发生试探异常，该修复不是本批改善的原因。
4. 区分求解失败、任务未完成及碰撞；部分轨迹时间不得冒充完整竞速时间。C3、实际中心误差、返回目标与标签也重新核对。

## 原文对齐与尚存适配

保持Eq8–11的time-uniform MINCO、TableIII N2/M4、动态中心硬等式、内部VAJ与Q自由、Eq18/21/31的snap能量+时间+三次积分软罚以及LBFGS-Lite。全局参考只由本场景解析MINCO生成，无其他方法优化解。226张图与独立MINCO系数/动态中心/有限差分梯度核对通过；最终拼接C3相对误差3.65e-11，中心等式误差1.39e-13m。

论文未充分公开固定局部末端、触发、s/rho/kappa和数值初始化细节。沿用s4、rho1e4、32积分、四时间比例、6.5m/s几何末端和整机离面触发，并明确标为复现适配。2秒/5000迭代预算保留。当前QuadA采用零阻力的公共模型，原总推力/角速度范数软限与本文单电机/逐轴软限不同。不存在仅凭全文就能核实这些部署设置完全等同作者的依据。

反向穿越/重复穿越尚未从数学问题中禁止。原硬等式只要求某时刻在中心，不保证全程按序正向仅一次，也不保证球形机体过窗期间不撞边框。因此不能通过忽略真实反向事件、删碰撞或添加本文SIP来“修好”基线。
