# 0.75/6圆窗上下起伏增大实验

保持原七窗布局、实体尺寸、朝向、0.75幅度比和6倍频率。只将第2、4、6圆窗的单摆绳长从4.618802米改为2.20米，原横向幅度分别2.025、1.875、2.10米，频率2.4、3.6、2.7Hz。两侧最大升高分别从0.467572、0.397699、0.505004米变为1.340131、1.049185、1.544256米。角度仍按原正弦时间函数变化，缩短绳长也相应改变轨迹中间的水平位移与速度波形。四个平移窗保持原运动。

scenario.py统一描述本次运动，解析位姿/速度/范围、符号规划表达和Gazebo插件均读取同一个逐窗length。物理窗口与原MPC/PX4保持，结果归新的独立目录。4项回归验证改动范围、解析导数/包络、Gazebo参数一致性和同物理初始MINCO曲线。

规划run.py沿用已验证的best_center_release实验流程，8个独立自由点与8个独立中心初值，中心位置初始化、逐窗时间相位采样、解析MINCO PVAJ；再从最佳合格中心释放选点一次。原95%动力学软界、.15米安全附加距离、TOGT内缩映射、目标和积分、5000有限迭代及24补点轮保持。新场景独立求解，原场景优化结果仅保护。

flight.py在同一执行器中注入本场景构建、Gazebo运动参数和实际运动审计，源参考必须携带higher_swing_length_2p20标记。所有找到并选中的原始时长与系数保留后进入x500/PX4/MPC正式一次实际执行。规划、实际接触、七窗有序整机退出、返航时间和末端状态分别记录。Gazebo可视化沿用飞行方向第三人称跟随。
