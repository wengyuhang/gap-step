# 四时间初值直接优化：自由与中心对比

双方均从窗口中心起步，各自直接优化四组相同的时间初值，选最短合格候选；不先求中心给自由热启动。
每条件每方法实飞一次，未按四条轨迹各飞一次择优。时间含首解等待、过窗、到同一终点及减速；全部四候选计算及验收计入规划耗时。
当前无墙钟上限，保持原小窗/约束/MPC/PX4/碰撞/终点；不保证100ms或全局最优。
