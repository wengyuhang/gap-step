## 要回答的问题与预期

- 相同动力学、安全条件和跟踪器下，自由选点是否缩短起点到共同窗后终点的完整时间？
- 运动更强时，各方法的无碰撞可完成条件是否不同？圆弧摆动下是否仍有收益？
- 预期低动态差别较小，较强运动下自由点可能更快或完成更多条件；不预设中心必撞或自由点逐档胜出。
- 双方都无碰撞时只讨论时间／完成能力；中心未找到解不等于物理无解或已经碰撞。
