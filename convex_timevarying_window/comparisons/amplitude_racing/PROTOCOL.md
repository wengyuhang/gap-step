# 2026-09-19 窗口运动幅度实验

固定同一七窗/x500/PX4、local_sweep算法、跟踪余量0.35 m、速度12 m/s和全部求解配置。
只改变场景输入；原始资产不覆盖，规划/世界SDF/事后审计共用幅度倍率。

主扫描：频率1、10倍；平移与RPY幅度同时1、2、4倍；相位0、2π/3。共12次。
拆分对照：10倍频率下，仅平移4倍、仅旋转4倍，同样两个相位。另4次，总16次。
这是固定相位小样本条件扫描，不是总体成功概率估计，不给统计显著性或泛化保证。

1倍平移单轴幅度0.10–0.20 m、RPY单轴幅度5–10°。
2倍为±0.20–0.40 m、±10–20°；4倍为±0.40–0.80 m、±20–40°。
幅度是中心到极值，峰峰行程为其2倍。窗口开口尺寸、中心布局、运动周期之外的参数不变。
1/10倍频率沿用原定义，保持仿真时间尺度不变。

每次飞行上限60 s，包含初始规划等待，不包含30 s起飞准备。未完赛不填圈速。
物理通过：七门按序、回起点误差<0.55 m且速度<1 m/s、Gazebo门框零接触、
事后10 ms真值外接球门套净空非负、真值机心处于配置的六侧工作区（容差1 cm）。
实时通过额外要求全部完整规划周期<100 ms，包括失败候选。超时悬停、漏门、越界、碰撞全部保留。
基础设施启动失败最多重试1次；算法失败不重试。不按窗口、幅度、频率或相位调参。
GUI关闭、BLAS/OMP单线程，记录Python/NumPy/Scipy版本、源码SHA256和每次原始结果。
名义约束与经验跟踪管并无连续域安全或递归可行证明，所有成功只表示本次仿真/采样验收。

指标：成功数/条件数、成功飞行时间、平均/峰值无人机速度、最小真值净空、完整周期P99/最大、
规划接收率、过门数、失败原因。附频率/幅度作用分离图、实际速度曲线和窗口局部穿越点。
