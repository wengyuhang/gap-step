# 原始 Checked：同赛道两档真实飞行

2026-10-07。用户要求“用最原始的check方法看下能不能完成”。

结论：两次均真实飞完七窗并返航，但只有低频档通过全部约定验收。最难档没有记录到门框接触，
却在第七窗前出现保守球包络负净空，不能称严格安全完成。不是随机重复成功率或全矩阵结果。

## 使用的版本

`continuation_racing.guard.CheckedPlanner`，原`--checked --tracking-preview .05`：
两未来窗＋可停车末段、五次Hermite、IPOPT65ms、每0.2s重规划、整个局部轨迹检查及自适应补点。
PX4直接跟踪100Hz PVA/50ms预览；不使用外部MPC、软净空目标或新自由末端。
只适配新固定平面场景查询，没有改旧规划器/控制发送逻辑，没有按门调参。

场景是同一原不规则七窗、固定平面/中心面内平移，两档各初相0、首次一次、不重试。
世界字节、场景manifest、PX4参数逐项与前批一致；跟踪器按要求恢复原PVA，所以不是只改规划器的消融。
原程序按中心事件计数，本次额外用真值检查整机离面、正向各一次及反穿，不把原程序“完成”直接当严格通过。

## 结果

|条件|第七窗整机退出|七窗＋返航|真值最小球净空|完整验收|
|---|---:|---:|---:|---|
|0.6Hz / 单侧1.2m / 0相|24.880s|28.284s|+0.179184m|通过|
|1Hz / 单侧2m / 0相|53.976s|57.360s|−0.005323m|不通过：保守球包络净空|

两次均七窗正向各一次、无反穿、完整离面顺序正确、返回起点，工作区通过；未记录到门框接触。
返航真值位置误差0.077/0.130m，速度0.925/0.969m/s。

最难档53.780s、第七窗附近有3个4ms采样点负净空，最小约−5.3毫米。
这是包围球/边框套筒保守几何条件违反，不等于已证实真实机体碰撞；但依同一标准不能记为安全通过。
不能因为没有Gazebo接触就把该负结果忽略。

最难档约24.296s速度低于1m/s，规划288次仅31次接纳；原可停车机制允许继续执行旧计划至停车点，
所以能保持任务继续尝试，但不能据57.360s声称快速竞速。低频档145次规划68次接纳，低于1m/s约0.984s。

## 实时、动力学与可追溯性

- 433次规划，最大76.796ms；PVA发送最大0.870ms。没有外部MPC，不虚构MPC求解耗时。
- 14项原方法/场景接口测试通过；141项冻结源和快照无变化，基线结果未改。
- 实测名义峰加速度低/高两档为9.450/8.363m/s²，倾角43.638/41.653°；按此前约定单列，
  不把它们藏成“全部名义参数满足”。主验收安全几何失败仍否决最难档。
- 真值4ms采样不是连续域证书，两次试飞不是任意扰动的保证。
