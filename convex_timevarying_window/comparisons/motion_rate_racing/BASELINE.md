# 独立 GP-MPPI 实现说明（不是作者代码）

来源：作者主页将 Beyond Reference Trajectories 标题链接至
[arXiv:2509.14726v1](https://arxiv.org/html/2509.14726v1)。[项目页](https://zhaofangguo.github.io/racing_mppi/)
代码未公开。用户于 2026-09-18 明确同意独立复现并说明差异。

## 对应与差异

| 项目 | 本实现 |
|---|---|
| 论文 Eq.2 | p/v/q/ω 刚体动力学，额外积分四桨推力状态；RK4、四元数归一化；目前未建模气动阻力 |
| 论文 Eq.3–5 | 高斯扰动单桨推力变化率，指数权重更新控制序列、移位热启动 |
| Table I | M=8192, K=20, dt=0.03 s, λ=0.01, 推力变化率限幅±10 |
| 论文 Eq.6–7 | 平方距离进度 + 近门代价，无离线轨迹；预测期间切换目标门 |
| 时间一致切换 | 保留旧预测已通过的门；新切换要求当前跨平面且对应旧预测位于门前；公开描述仍存在实现歧义 |
| 机体参数 | 改为场景真实 x500 的质量2.0643 kg、惯量、混控力臂、单桨最大8.54858 N |
| 未公开参数 | 独立选择噪声标准差3 N/s、近门法向距离阈值1.5 m、近门权重1、约束罚权1000；不声称是原文参数 |
| 动态窗口扩展 | 每个预测时刻查询真实门位姿；进度差两端使用相同未来目标，避免窗口运动产生虚假进度 |
| 几何/环境扩展 | 相同门套及机体/跟踪余量，房间、速度12、加速度8、倾角42°、总推力90%留量的软罚；不是我们的法向可通过性硬约束 |
| 终点扩展 | 七门后返回起点并减速，增加距离/速度代价；原文多圈竞速并无此终态协议 |
| PX4 接口 | 由一步刚体预测得到总推力和机体角速度，发 CTBR；不直接下发四桨推力变化率。由估计线加速度和角加速度、x500 混控矩阵推算桨推力状态，不读取真值；导数用系数0.2的一阶滤波 |
| 计算平台 | 本地 C++/OpenMP四线程，不是原文 JAX/GPU；采样数不变，实测整个周期并报告硬件差异 |

主方法使用 PVA + PX4 位置环，本基线使用 CTBR + PX4 角速度环；这属于端到端控制系统对比，
不是同一执行接口下仅替换优化目标的受控消融。为追求后者改为点质量 MPPI 将偏离原论文刚体模型，
本次没有把旧 VT-GP-MPPI 简化算法冒充文献基线。

## 验证界限

### 2026-09-18 接口验证状态：未通过，不能作为论文性能排名

`results/gp_frozen_20260918` 名称沿用首次批次启动时的命名，但其 7 次运行均为
**未验证实现的集成试飞**：1、3倍各3次，6倍1次，均未过第一门。其余条件未运行。
不得把这些结果列为论文 GP-MPPI 的正式成功率。

后续定位并修正 ACTUATOR_OUTPUT_STATUS 在本 Gazebo 后端的单位：前四路是 rad/s，
不是归一化油门。启用 `--motor-telemetry` 时由 PX4 电机输出及电机时间常数估算推力，
不再用加速度逆混控，不读取 Gazebo 真值。错误单位试飞保留但不作有效评测。
修正后，单桨推力变化率预测再投影到 CTBR 的版本仍未完赛。

另增加明确分开的 `--input-mode ctbr` 适配变体：直接优化总推力/三轴机体角速度，
用25 ms总推力响应、50 ms角速度响应与 x500 旋翼平面阻力预测，执行同一控制输入。
噪声标准差为 `[2 N, 0.4, 0.4, 0.15 rad/s]`；这改变了论文的控制变量，
不能称为严格复现。固定留出相位0.4 rad下，K20试飞42.84 s才过首门、45.276 s越界中止；
K40试飞5.956 s越界中止、零过门。两次均无门框接触，但均失败。
结果分别保存在 `results/gp_ctbr_calibration_h20` 和 `results/gp_ctbr_calibration_h40`。
延长视界尚未解决稳定性；上述一阶内环模型仍是未经辨识的近似。

单元测试覆盖悬停平衡、增加总推力上升、单步与批量传播一致、随机种子和限幅。
理想模型初步测试中原0.6 s视界会出现转弯过晚；1.8 s探查也未建立稳定完赛能力，故不据此替换原设置。
尚未复现作者原赛道的圈速或实机结果。即使完成本场景试飞，结果也只能归属于这个
**独立 GP-MPPI/PX4 适配实现**，不能归因于作者原方法，更不能用适配失败证明论文方法不行。
所有试飞配置与失败留存，参数一经进入频率批次不再按倍率调节。
