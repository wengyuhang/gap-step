# 短自由前缀＋中心续接代价

2026-10-07独立试验。只在接下来两个窗口释放二维穿越点；更远窗口固定中心。
远端仍有时间/PVA/内部MINCO自由度，用以计算前缀出窗状态的后续影响。
这些远端变量与前缀联合求解，不是把所有剩余窗的点都释放，也不是逐门反复调用完整规划器。
这是显式中心续接的近似价值评估，**不是原两窗中心滚动策略的精确cost-to-go**。
维度仍随剩余门数增长，本次只验证已知运动的七窗，不声称任意长赛道有固定复杂度。

每次先中心候选35ms，再释放前两窗25ms，保留合格中心候选；以最后一窗预计整机退出时刻
而不是第一窗时间选择。新计划不得推迟已接纳计划的预计完赛时刻，但允许前面的门较晚。
保持参考头PVA接续、真实整机退出事件/MPC/PX4，未加危机MPPI或CBF。
冷初值统一用距离/8m/s时长及0.45倍限速，无按窗口编号或场景频率设计的参数。唯一固定零VA端点是真正返航终点。
开发计算探测比较过6/8m/s种子和更大罚系数；冻结8m/s时长种子、原罚系数，未改变安全阈值。
中心热启动保留下游绝对时刻，而不是随着下一次请求整体平移门运动相位；该修正对两分支一致。
继承race_to_go_mpc的残差/事件检查、frame软代价与穿越邻域加密；都不是连续认证。
未启用编译JIT。完整在线周期（两次搜索＋选择＋通信）仍须<100ms。

理论边界：同一输入时保留的合格中心候选不被更慢的候选替换；整条名义参考的最终时刻单调不增。
在精确跟踪、所有接续可行且初始中心完整轨迹可行等条件下，可对该初始名义轨迹给条件性不劣结论。
这不保证对旧周期中心闭环策略更快，也不保证对本版中心闭环分支更快；严格优势靠独立实飞检验。

实验先做统一初始化/梯度/候选保留测试，随后在0.7Hz/2m、1Hz/1.2m、1Hz/2m、初相位各一次，
本版自由前缀和本版全中心配对共6趟；另列历史旧两窗中心成绩27.640/24.432/24.428s，不混为单变量对照。
两分支求中心同35ms；自由分支额外25ms，明确不称等计算量实验。世界/MPC/PX4相同。
每场仅竞速前证明的设施故障允许一次重试；算法失败不重飞挑成绩。保存全部源和日志。
