# 单窗动态整机穿越约束验证

2026-10-09，独立开发验证；仅支持原 W1 矩形、固定平面、已知面内正弦平移。
原两段全局 MINCO-s4 保留，优化变量为两段 log 时长及窗内二维点。中心对照
只把二维点固定为零。完整时间目标和动力学三次软惩罚保留，窗框安全改为
有约束 SLSQP + 局部最危险时刻约束生成。没有增加轨迹控制节点。

几何采用原 x500 足迹半径 0.38594472 m 的球代理、窗框中心线外移 0.065 m、
框管半径 0.085 m，另加 0.10 m 跟踪设计余量。足迹球是代理，未声称它是
所有姿态下的三维完整网格外接球；最终碰撞以原 x500/Gazebo 接触为准。
各时刻使用球到矩形开口外侧四个平面半区的距离。这比有限边框保守，
但能防止求解器跳到窗框外侧的错误分支。只在接近窗平面时限制机体截面，
不把所有时间的开口固定内缩。初值选相邻运动极值时刻，不指定选点侧；
两方用完全相同初值。找到第一个收敛且局部包络通过的解即返回，不声称全局最优。

先解析求多项式法向位置达到球/框作用半径的根，仅对可能接触的时间区间
用 Bernstein 包络与正弦极值范围自适应细分。最危险时刻加入当前优化，
直到局部所有区间的浮点包络通过。此为数值包络，不是区间算术安全证书。
没有全轨迹均匀在线扫描。离线0.5ms代理审计与Gazebo接触用于独立评价。
求解预算90ms，未获得满足局部约束的候选明确失败，不返回已知违反解。
预编译时间单列；实际请求端到端也须报告，不能只报优化核耗时。

v1最小飞行验证冻结在开发修正结束后：3.5Hz/2m，中心/自由各一次，
初相0、原开口/起终点/40s时限/MPC/PX4。两方实际输入PVAJ保存；所有失败
保留，不把不同输入的仿真误称逐位重复。若需要扩展，另建版本及结果目录。
开发探针还测试了3Hz/4m；v4两方均未找到局部约束合格解，保留该负结果，
v1未在此条件启动飞机。这不证明赛道物理不可行。该失败已继续处理，见下文v2。
