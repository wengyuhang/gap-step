# 单窗相对运动穿越约束

该并列验证方法不改变原场景、MPC、PX4或x500，不再只靠有限权重的安全软罚项。
当前只实现固定平面矩形的已知面内正弦平移，不外推到旋转/非凸窗口。

## 决策与目标

起点是当前实际/执行参考的PVAJ，终点是窗后6m固定目标且VAJ为零。使用两段
degree-7全局minimum-snap MINCO，唯一内部节点是动态窗口穿越点。优化变量
是`log T1, log T2, q0, q1`；窗口处VAJ由耦合MINCO自动确定，不额外添加控制节点。
中心对照仅令`q0=q1=0`，其余均一致。

目标为总时长加原速度/加速度/jerk/执行响应/推力/倾角/工作区违反的三次软惩罚。
动态约束仍可有残差，不作为飞行成绩否决。安全改成明确不等式，故使用解析
梯度SLSQP而非仅能处理边界的L-BFGS-B。找到第一个收敛且局部安全包络通过的
候选后返回，不宣称全局最短或必然优于中心。

## 约束不是“穿越点离边框远一点”

令`q(t)=Rᵀ[p(t)-c(t)]`，`z=q2`为离平面的法向距离。物理矩形半宽高为
`h=(1.45,1.15)m`，框中心线外移`o=.065m`。对两个面内轴和正负两个方向，约束

`z(t)² + max(h_i + o - s*q_i(t), 0)² >= rho²`，其中`s=±1`。

`rho = .38594472 + .085 + .10 m`，分别是原机体足迹球代理、框管半径、经验跟踪
设计余量；优化见证时刻另留5mm数值松弛。这个量是球心到开口外侧平面半区的
距离，比到有限框线更保守，但防止解从框的内侧跳到外侧。远离窗口时`|z|>=rho`
自动满足；接近平面时，允许横向位置随法向截面收缩而变化。每个时刻都查询实际
`c(t)`，不是用过平面瞬间的窗口位置冻结整段穿越，也不是只看瞬时相对速度。

## 怎样控制计算量

1. 从窗口已知运动查询相邻四个极值时刻，作为两方相同的到达时间初值；不规定
   穿越点必须在运动方向的一侧。尾段初值按距离/动力学尺度计算。各次优化限制在
   该极值两侧四分之一周期内，分别搜索相邻相位区域，而不是修改外生窗口运动。
2. 初始只约束穿越前后少量时刻。SLSQP收敛后，用多项式求根确定`|z|<=rho`
   的全部可能接触区间，包括可能的再次接近平面。
3. 只在这些区间用多项式Bernstein包络与正弦范围自适应细分；若发现违反，将
   穿越前、后各自的最危险时刻同时加入下一轮优化。时间变量按`1/(omega*T1)`
   缩放，避免log时长对高频相位的巨大敏感度使SQP跳过几个安全机会。
   没有全航程均匀扫描，也没有固定100ms前缀准入。
4. 区间浮点包络全通过才返回；失败不执行已知违反候选。求解90ms名义预算，
   请求实际端到端耗时另记，不把编译或消息延迟藏进内核计时。
5. MPC按原机制跟踪；整机离窗后更新任务编号，误差过大按原机制重规划。本单窗
   飞行没有后续窗口，只继续到固定目标。

这不是形式化连续域认证或闭环安全定理：包络使用浮点数，球只是原足迹代理，
0.10m没有被证明为跟踪误差界。实际成败仍由Gazebo实体接触和实际任务完成共同
判定。独立0.5ms离线轨迹采样只用于诊断，绝不充当在线计算或正式证书。
