# 穿窗邻域加密的 MINCO/MPC 修复

2026-10-07。针对no-postcheck更保守软目标重复展示时真实撞框，新增独立方法，不覆盖旧算法。
第六窗21.288s旋翼接触，实际参考最低净空约−0.123m，MPC失败在21.968s，不能倒因为控制器先失败。

保留两窗MINCO-s3、自由窗点/PVA/抵达J、原可停留尾段、初值/热启动、共同窗20ms时限、
55ms搜索、原MPC及no-postcheck准入。软余量.25m、权重10不再加大。
改变仅为：每个计划穿窗事件的前后各最多.5s，沿实际相邻多项式片段各放26个几何节点，
时间间距不超过20ms；窗体状态在节点绝对时刻查询。对本窗真实有限框加入原.35m几何余量残差，
并以梯形积分加入原软净空目标。节点随到达时刻、片段时长自动移动，梯度包含该依赖。
事件点两侧分别半权，没有额外重复积分；短片段覆盖整个邻接片段，未扩展到更远片段。
常规飞行区间沿用旧采样，保留旧补点、事件判断，不重新扫描或拒绝整条候选几何。
新增残差同时进入求解器best-feasible选择、evaluate和原.003准入，不只加一个可忽略的奖励。

这是局部时间分辨率修复，不是连续安全证书：没有证明±.5s外绝对无危险，也不证明所有跟踪误差
都小于.35m，不能声称不会撞。适用当前远间距固定平面动态中心测试；不按窗编号/频率/撞点调参。
所有新增运算计入完整规划<100ms。几何采样只查询目标窗，不对每个新增点遍历全部赛道。

实验入口在comparisons/original_fixed_plane_crossing_resolved。先用已保存碰撞参考验证新节点能
识别原漏检、解析梯度正确、原MINCO系数未变；再同场景重复闭环，负结果全部保留。
