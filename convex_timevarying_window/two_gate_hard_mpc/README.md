# 两窗联合规划验证

2026-10-09：按用户要求扩展当前单窗 hard_v2 方法，不将任务拆成两个独立单窗求解。

## 结构

一次求解起点 → 第一窗内点 → 第二窗内点 → 终点，共三个七次多项式段。
两个内部节点同时优化位置、速度；全局最小 snap 消元保持 C5 连续，起终点指定 PVAJ。
变量为三个对数段时长、四个窗内坐标和六个过窗速度分量，共 13 维。
目标仍为总时间，沿用 hard_v2 的动力学节点约束、局部动态窗口安全约束与见证点交换，MPC 沿用原跟踪器。
完成第一窗的整机出窗后，原滚动机制只对剩余一窗重规划；初始轨迹确实同时包含两窗。
不是完整连续动力学认证，也不承诺任意初值在预算内求解成功。

## 场景

小窗开口 2.9 × 2.3 m。第一窗锚点 (-2.42,-3.52,6.48)，第二窗 (18,8,6.48)。
两平面固定平行，水平间距 20.42 m，横向错开 11.52 m；不是直线赛道。
起点 (-16,4,3.2)，终点 (24,8,6.48)。两窗沿各自水平面内方向正弦平移，相位差 π。

运行：

```bash
env OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 GZ_SHOW_GUI=0 \
 /home/jack/anaconda3/envs/wyh/bin/python -m convex_timevarying_window.two_gate_hard_mpc.flight \
 --method ours --frequency 1 --amplitude 2 --phase 0 --outdir <新的结果目录>
```

- 三段轨迹的 PVAJ 边界、内部 P/V、C5 连续性和解析约束梯度测试通过。
- `results/joint_f1_a2_aligned_v1_20261009`：1 Hz / 2 m，初始求解连续 20 次预算到期，随后接收结果时因父子进程 NumPy 版本不同报 `numpy._core` 缺失而退出，未起飞穿窗。不能计作成功或碰撞，也不能据此断言后续求解都失败。
