# 中心解初始化的自由选点 MINCO

2026-11-05。保留的中心初始化两阶段版本；用户随后改用multistart_minco，双方均直接四时间初值优化。
旧single_gate_swing保留以复现旧实验。
用户要求先求中心可行轨迹，再从其结果继续开放选点，保留不劣于中心的名义候选。

同一请求内使用同一实际PVAJ、绝对起始时刻、MINCO图、动力学/安全约束和终点：

1. 仅固定两维窗内坐标为零，调用原中心规划。
2. 中心解通过原有限动力学约束及局部安全验收后，保存完整时长、速度和曲线。
3. 原两维选点界恢复，从中心解全部七个变量作为唯一初值继续SLSQP；不再重新排序其他时间种子。
4. 只有新解同样通过原验收且总时长严格减小才替换，失败或变慢均返回原中心轨迹。

只构建一次原MINCO图；中心/自由阶段分别修改变量界，没有重复JIT或改目标。
动力学仍为每段17节点的原名义约束，安全仍为浮点局部包络/见证交换，MPC/PX4及窗的外生时钟不改。
两阶段总耗时计入solve_ms、optimization_ms和worker端到端计时。有限墙钟预算由两阶段共享；当前生产默认仍无墙钟限。
不在第二阶段重新计算now、不暂停窗口，也不以历史对比航次中的中心解作为在线初值。

返回名义时间不大于本次中心解；不保证全局最优、闭环完成时间更短或所有请求小于100ms。
中心阶段未找到可接纳解时，本方法也不产生可执行轨迹；不会绕过中心阶段改成自由冷启动。
正常优化失败可返回已验收中心轨迹；未知程序错误仍抛出，不能靠兜底隐去实现故障。
