# 独立验证协议（运行前记录）

2026-09-23。原七窗布局、x500、物理净空/工作区不变；GPU16384候选；MPPI与TOGT每次100 ms预算。
默认相位0.4用于开发；开发所有版本/失败保存新目录和源码快照，不合并成成功率。

顺序：
1. 单元测试：未来窗口查询、三阶段、顺序、不退回、完整机身退出、加权策略复查、100 ms重规划规则。
2. 原七窗名义同模型闭环开发；先定位机制与实现问题，不把模型时间当PX4圈速。
3. 同配置冻结相位0/120度 × 频率1/10倍名义诊断，原幅度；包括失败与>=100 ms样本。
4. PX4/Gazebo先原场景开发，再按诊断情况完成独立条件运行；每次30秒准备、60秒比赛上限，
   初始TOGT计算计比赛时间，返回原起点（位置<0.55 m、速度<1 m/s）才完成。
5. 事后真值审计：10 ms球体门框净空、实际接触、工作区、速度/加速度/倾角、定位误差、
   实际过门位置和速度。保留原始ULog/执行日志/源码哈希。

若开发阶段暴露机制不能成立，报告当前完整运行的证据和未执行项，不把未运行条件写为成功或失败。
不修改旧算法、两个论文baseline或其结果，不对失败方法列出“成功圈速”。
统计报告：过门数、完整任务时间、最小净空、退回次数、每阶段时长、采样拒绝原因、
MPPI完整周期median/p99/max/>=100 ms，TOGT求解/接入结果；预热另报。

错误分类：实现错误（代码违反机制）、证据不足（有限采样无解/未完赛）、假设不成立
（实测误差/模型/延迟超设计范围）；不把有限样本无解解释为物理不可行。
