# 实际时刻局部穿越约束（2026-09-18）

`local_sweep` 完成12个条件后提升为默认；`--local-sweep` 仍可显式选择，
旧 `worst_case` 通过 `--legacy-crossing` 保留以复查历史失败。
不改变安全余量、飞控参数、目标函数、采样门框几何和在线时间预算。

用局部实际运动替代全周期最坏加速度诱导的最低法向速度：

1. 过门结点相对法向速度仅要求正向（>=0.1 m/s），不设错误的相对速度上界。
2. 入门段末端与出门段开端分别在40/80/160/280/420 ms附近查询真实窗口位姿。
   若段很短，偏移不超过该段45%，使用实际偏移计算要求。
3. 沿正确方向的平面距离至少为 `rho * min(1,实际偏移/0.28)`。
   这要求实际多项式在局部时间内离开扫掠平面附近，不再用全周期最大转速排除有利相位。
4. 同时保留这些位置的门框胶囊净空约束和0.3 s短前缀检查；方向条件不是碰撞检查的替代品。

这是统一的局部采样条件，仍含0.28 s离面时间这一设计参数，不是最优性或连续安全证明。
最后一个预测窗的离窗段在后续滚动视界中补齐；只执行短前缀，不能把预测末端算作已认证轨迹。
不按门编号或频率修改参数。

开发留出条件：10倍频率、相位0.4 rad；正式冻结条件仍为1/3/6/10倍×0/120/240度。
完整日志保存在results；开发成功不能代替冻结批次成功率。
