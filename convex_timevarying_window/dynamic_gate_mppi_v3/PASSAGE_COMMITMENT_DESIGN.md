# 单窗闭环穿越设计（开发实现中，未完成验收）

日期：2026-09-20。依据用户批准的“入窗前选择、入窗后完整退出”方向。

## 范围与目标

保留动态三窗TOGT、GPU MPPI、实际整机过门计数、当前实际PVAJ重规划和100 ms安全计算窗口。
窗口运动完全已知，门间飞行按用户新假设无碰撞风险；不修改原七窗位置或运动来制造成功。
原七窗是否满足局部窗口互不干扰须单独检查，不能直接删除其他门框碰撞检查。
目标是原60秒协议下全七门和返航、动力学/碰撞审计通过，逐步缩短时间；不是只让控制程序不报错。

## 为什么不是只补状态检查

旧缓存只按位置误差放行，可能在姿态已经偏离时继续执行固定电机序列。
新增姿态检查能发现问题，但不能提供下一条控制，故需要改变缓存内容和执行闭环。
不采纳“故障就证明赛道不可行”；分别记录预算内未找到解、当前状态不可恢复的证据和赛道不可行证明。

## 四阶段，两个核心决策

使用当前运动窗口坐标和整机包络，不用参考时间表或中心过面代替任务完成。

1. APPROACH：整机在入口侧。正常跟踪TOGT，始终保留入口侧可执行的调整动作。
   允许入窗的必要条件是已有完整退出的反馈机动，而不是仅未来100 ms无碰撞。
   未找到退出机动时选择仍在入口侧、不会被运动门框扫中的调整动作；不能默认悬停一定安全。
2. ENTERED_PRE_CENTER：机身已进入、中心尚未过面。保持完整前出机动；退回必须另有全段安全见证，
   不能因本轮没有新候选就盲目倒退或继续旧电机输入。前出/退回按完整动作切换，不每拍随代价抖动。
3. ENTERED_POST_CENTER：中心已过面、尾部尚未退出。退出优先，不切下一门参考、不提前大转弯。
   新候选必须仍能完整前出；若退出能力因实际误差丧失，记录假设失效，不能伪称仍有保证。
4. CLEARED：整机退出且已验证短后续片段不会被当前门扫回。仅此时计门，更新实际门序，
   在当前执行方案未来100 ms安全且不在穿越区时，从当前实际PVAJ请求后续三窗TOGT。

状态随相对运动更新；中心可反向越面，但门序不得因此提前增加或遗忘当前目标。

## 缓存从电机序列变为反馈机动

机动记录：当前门、绝对时间、阶段、局部期望状态/前馈、出口时刻和状态、反馈律、适用误差范围、验证信息。
推荐执行接口为总推力和机体角速度，PX4角速度内环持续闭环，不让MPPI更新中断等同开环。
替代方案是自行以高频反馈修正电机输入；需要自行验证姿态稳定性和时延，复杂度更高，不作为首选。
直接电机旧版本和所有实验快照保留，新接口独立标识，不能沿用旧模型宣称验证通过。
预测模型须包含内环、饱和、电机滞后和实测通信时延；先通过单机响应实验再接入动态门。

每周期从完整实际状态检查当前反馈机动剩余段及适用范围。新机动只有通过相同检查才能替换。
控制指令是否实际按时激活、反馈是否新鲜须独立记录。失去适用范围是控制失败，不是“安全停止”。
不承诺有限随机样本总有解；保留已有可执行反馈机动是防止采样断供的核心。

## 局部优化

危险模式不读取旧TOGT作为跟踪目标。统一搜索穿越位置、进入/退出时间、出口速度方向。
以“完整退出时间 + 到下一门入口状态的动力学时间估计”为目标，不奖励朝错误方向高速飞行。
碰撞、按序穿越、姿态/推力/速度约束为硬条件；禁止逐门专用参数。
门内候选须覆盖完整退出，不能因固定视界到期而只验证一半；计算预算不足时保留原适用机动，
若入窗前尚无完整见证则不准进入。门外可达性不能仅用一维制动距离冒充四旋翼安全不变集。

## 保证边界

完整退出名义见证不等于鲁棒保证。需明确扰动/状态估计/时延边界和反馈误差范围；
有限扰动测试只提供经验鲁棒性，不称连续认证或递归可行性证明。
不缩小现有机体模型或0.35 m误差裕量，不在失稳后放宽42度限制以获得“成功”。
100 ms为每次在线规划/控制的墙钟上限，所有筛选、回退与数据传输计入；预热单列。
20 ms更新目标也报告超期，禁止仅报告CUDA核时间。

## 验证次序与验收

1. 从已有失败运行抽取状态，增加约束拒绝分类（可多标签）：碰撞、任务、速度、加速度、倾角、角速度、推力、终端条件、截止。
2. 无门：验证执行接口、内环响应和模型预测；主动制造一次/多次MPPI更新缺失，检查反馈仍稳定，不能用位置接管当算法成功。
3. 单门：静止/平移/旋转；分别在整机未入、前部入、中心已过、完整退出阶段注入相同范围状态扰动。
   检查门内不切下一门、合法退回不计门、未完整退出不计门、移动门扫回被检测。
4. 完整七窗：同配置三种子名义实验，然后同配置三次PX4；保持60秒上限，保存全部失败与源码哈希。
5. 消融：关闭入窗完整见证、关闭反馈续行分别观察差异，不通过改变赛道或安全标准改善成绩。

报告七门退出时间和返航完成时间、接触和真值整机净空、动力学超限、规划/控制耗时分布、拒绝原因与更新断供时长。
仅全部测试完成后评估是否稳定完赛；三次成功也不表述为所有同类赛道永不失败。
