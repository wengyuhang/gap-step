# CUDA迁移与采样量验证

2026-09-20，RTX A4000 16 GB。默认在线入口为CUDA、16384候选，原512的32倍；显式`--backend cpu`仅用于对照。
没有CUDA时直接报错，不静默退回CPU。旧9月19日矩阵不覆盖、不改成GPU结果。

## 实现边界

- CuPy RawModule生成与CPU同源的RK4、电机滞后、几何距离、动力学筛选、局部穿越状态机CUDA核。
- 采样、候选预测、硬筛、比赛/参考代价、安全计算窗口、加权归约均在GPU；候选状态不整批拷回CPU。
- 已知门几何统一查询后上传；CPU做单条基准检查和最终少量候选的FP64复核、缓存/飞控通信。
  FP32候选即使误判为安全，也不能绕过最后FP64复核；这不是额外的跟踪误差证明。
- GPU加权候选复核失败后，按代价最多检查8个合格原样本；仍无可执行结果则用有效缓存，不能放宽约束。
- 编译、首次分配和核热身在在线计时前完成。温度、裕量、视界、动力学和24个几何提案均未为GPU实验逐门修改。
- 5项GPU回归核对状态/净空/门序、20区间计算窗口、参考代价、避险不读取参考及CPU最终准入；全方法33项测试通过（1.35秒）。

## 完整select耗时，不是仅计CUDA核

来源：[采样扫描](results/gpu_benchmark_20260920_01/summary.json)，每档起点12次热身后计时，包含CPU最终准入，不含PX4收发。

|后端|候选数|中位ms|最大ms|起点合格候选范围|
|---|---:|---:|---:|---:|
|CPU|512|18.863|24.308|50–62|
|GPU|512|5.648|6.589|48–70|
|GPU|4096|5.857|6.456|422–469|
|GPU|8192|6.132|7.235|830–948|
|GPU|16384|7.416|8.798|1721–1877|
|GPU|32768|13.935|15.016|3443–3628|

各GPU档在该小测试均未超过20 ms，但不是最坏执行时间保证；共享机器其他负载未隔离。
另一个历史失败状态的固定电机保持基准探查，各档都没有合格候选。
该探查不是原缓存重放，也不能证明物理不可行，只说明增大样本不保证在该提案分布下找出解。

## 闭环开发证据

- [16384候选单门](results/gpu_single_passage_20260920_01/summary.json)：静态/运动门，门前、门内前行、门内退回，3个种子共18项全部完整退出；12前行、6退回。最大select为7.585 ms。
- [8192候选原七窗](results/gpu_passage_20260920_01/summary.json)：同模型60秒只过1门并超时，未耗尽缓存。
  合格候选每轮68–3303，中位1193；MPPI中位7.243、最大20.036 ms，3000周期1次超过20 ms、0次超过100 ms。
  最小执行区间剩余净空0.184025 m。仍有低速徘徊，不能称成功竞速。
- 上面两项不包含真实执行延迟，不是Gazebo或连续安全证书。
- PX4/Gazebo16384候选接入开发`results/gpu_px4_20260920_01`已结束：20秒0门超时、零接触、工作区通过，10 ms真值净空最小1.207183 m。
  906个MPPI完整周期均有准入，中位14.579/P99 22.748/最大24.632 ms；57次超20 ms、0次超100 ms。
  每轮至少1555条合格候选。含初始TOGT最大求解周期76.428 ms；不是成功竞速，不列作正式矩阵。
  此试飞发生在“每门滚动重规划与飞行模式解耦”修改之前，不能代表修改后成绩。
