# 中心空间初值＋四时间初值直接优化

2026-11-05，按用户最新要求：空间点每次从中心开始，时长用多个初值，选本次求得的最短合格轨迹。
自由和强制中心双方采用完全相同的候选生成/求解/选择规则，旧中心初始化两阶段版独立保留。

- 两段P/V-MINCO，原时间目标、名义执行量节点硬约束、局部安全包络/见证交换、MPC/PX4不变。
- 统一原几何时间尺度，第一段时长初值为其1/.8/1.2/1.5倍；第二段初始时长和三维穿越速度初值相同。
- 四个初值的面内位置坐标都为零。自由版从迭代开始即可优化选点；中心版始终固定坐标为零。
- 每个时间初值独立求解，不能用上一条轨迹、历史飞行或中心优化结果替代下一条初值。
- 每条均按原收敛、节点约束和局部安全验收。四条全部尝试后，选T1+T2最短的合格轨迹。
- 候选是同一次请求内部的四次优化，不是重飞四次择优；实际每条件每方法只飞一次。
- 总求解/通信时间包含全部四个初值及其安全验收，飞前JIT构建单列。
- 当前沿用无墙钟上限；若显式传入有限上限，则四初值共享上限，日志注明是否全部尝试。
- 同样初值数量和每初值迭代/验收规则，不声称两方CPU耗时相同或全局最优，也不保留自由必优的名义保证。
