## 开发验证协议

1. 相同问题、相同已接受初值，无MPC并发/同进程MPC并发/独立进程MPC并发对比，
   记录迭代数、线程CPU、进程CPU、墙钟时间及约束残差。
2. 固定三个条件各飞一次：r1/t2/a1/120°（已定位停车）、r1/t1/a1/0°（原始），
   r10/t4/a1/120°（旧碰撞条件）。同一版本，不因单次结果调赛道参数。
3. 与已有同条件PVA和未隔离MPC比较圈时、过门、接触、真值净空、实际动力学、
   跟踪误差以及完整规划/MPC/发送耗时。正常算法失败不重试；仅既有判据证实的
   准备期基础设施故障允许一次同代码重试，全部保留。

这些是机制验证/开发试验，不是38条件总体成功率或连续安全认证。
隔离本身的v1结果已保存在`results/px4_v1_20261006/`：原始条件25.400 s、
困难条件31.740 s七窗返航，均零接触/采样净空/100 ms主验收通过；
r1/t2/a1/120°过4窗后13.152 s QP时间限制中止，失败保留。
三趟严格12/8/42动力学均未全部满足，不能称完全安全竞速已解决。

## 可选等价MPC消元

`--condensed`启用`fast/mpc.py`：将线性化动力学中的状态解析表示为输入序列的仿射函数，
QP从442个状态+100个控制变量缩减到100个控制变量，保留输入/倾角/信赖域约束。
目标、预测模型、1 s预测时域、2次SQP、求解容差、迭代/时间上限与非线性回溯不变。
CasADi累积映射替代逐步Python调用，仍使用同一RK4模型，不降阶、不缩短视域。
单测检验动力学消元、二次目标及倾角约束代数等价、滚动预测等价和控制近似一致。
数值求解结果不保证逐位相同；真实飞行必须独立重测，不以数学等价代替闭环验收。

消元版v2三个开发条件均主验收通过：r1/t2/a1/120° 25.412 s、原始25.504 s、
困难33.092 s；最小真值采样净空0.377181/0.358541/0.323226 m。未触发近似QP接收分支。
