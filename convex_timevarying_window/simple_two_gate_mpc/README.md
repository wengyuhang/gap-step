# 简化两窗规划：自由点与同结构中心配对

2026-10-08。按用户最新定义，竞速时间是从起点出发、按序穿完七窗、回到规定终点
并满足历史终态判据的完整时间。不能用第七窗退出时间代替，不删除返航时间代价。

## 算法

每次两窗穿越点/PVA/抵达J及三段时间联合优化，每段两个五次MINCO片段。
第三窗为真实轨迹终点P=c3(t_end)，世界V=A=0；这是沿用用户之前的终态约定。
剩最后两窗或一窗时，尾段为真实起点/终点、V=A=0，不虚构第三窗。
自由点版前两窗q可变；中心版仅q固定0，V/A/时间仍同样优化。两方仅free_points不同。

目标仅三类：J = sum(T) + dynamics_penalty + safety_penalty。
- 时间包含全部局部片段，末视界也包含返航。
- 动力学项是归一化速度、加速度、jerk、执行器需求、推力和倾角超限的三次hinge罚。
  jerk仅作为变化率限值，不再加独立的jerk平方平滑积分（jerk_weight=0）。
- 安全项包括开口/工作区/门框/正向离框条件的三次违反罚，以及偏好额外净空的软积分。
  延用同一1e5违反权重；偏好净空buffer=.25m、weight=10，两方相同。
  保留普通节点，并在两窗中心穿越的相邻片段前后各最多.5s加密、每侧26点、间隔≤20ms。
  每个节点按绝对时刻查询真实运动窗口，解析梯度包含时长和窗口运动依赖。
  违反罚是离散和，净空偏好为梯形积分；不能把整个目标说成精确连续积分。

优化器复用已审计MINCO/动态几何，通过配置精确删去独立jerk平滑项，且不构造期限代价。
无未来价值估计、全剩余赛程、候选包络、共同窗时限或分阶段控制。
只使用正常L-BFGS-B最终解，ftol/gtol=1e-6；缓冲求值不改变数学目标或停止条件。
初值统一规则：已有共同窗保留绝对时刻/PVA，新窗从中心、.45倍速度上限方向速度开始，
新段时长max(.8, distance/(.5*speed), sqrt(3*distance/acceleration))。两方规则完全相同。

正常调度只有首次规划与实际整机出窗事件。序号在整个外接球离开门框平面后推进，
不回退目标；不再0.2s正常定时或跟踪误差重规划。若事件求解失败，保留该待办、.2s后重试，
两方相同。最后一窗退出后执行已有返航尾段，不额外求解另一条轨迹。
执行层复用相同MPC/PX4，150ms未来参考PVA接续、过窗内不切换；MPC持续输出CTBR控制量。

## 软约束不等于安全保证

优化中用软惩罚，但执行前仍要求原采样残差<.003、正常停止、基本正向单次穿越和实时准入。
不做求解后的全轨迹几何/动力学扫描；原10ms局部轨迹事件检查仅检查顺序/反穿，需如实披露。
出窗触发本身不保证名义曲线不反穿，故不删除事件检查。没有CBF、MPPI或连续安全证书。

## 冻结配对协议

只原最难固定平面赛道1Hz/2m/全局初相0，各窗保留相对相位。真实Gazebo/x500/PX4，无GUI。
先自由点后中心，每种一次，不根据结果改源或调参重飞；只竞速前基础设施故障可重试一次。
两方世界字节、初始场景、MPC、PX4、优化权重/精度/初值/触发完全相同，仅free_points不同。
使用experiment容器，绝不操作replay。不运行并行仿真实验。

主指标full_race_time_s：仅完整顺序七窗＋无接触＋4ms真值球净空非负＋工作区＋终态＋
所有规划/MPC调用<100ms通过才记有效。否则仅列程序记录完成时间，不作为有效竞速成绩。
终态沿用历史容差：位置误差<.55m、速度<1m/s；不是数学上精确PVAJ归零。
准备期30s与飞前构图/编译单列，不计飞行时间；起赛后的首规划等待计入。
七窗退出时刻仅用于诊断，不参与获胜判定。不把旧历史中心当本轮匹配对照。
保存源码快照、全部失败/超时、日志/ULog/contact及单次条件限制，不推断随机成功率。
