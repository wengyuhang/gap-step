# 全局MINCO数值修复：姿态重建与时间目标尺度

本模块修复现有全局PVAJ求解器，原入口保留，不覆盖历史实验。显式依赖实验2的固定平面平移/摆动几何约束、global_gate_minco_probe的全局曲线及求解循环、原x500阻力/惯量/混控参数。

最终保留三项变化：

1. 以北图最短倾斜旋转+固定图内航向pi/2代替固定世界Y叉乘姿态，避免已复现的水平推力近奇异。hover姿态一致，但大倾角的航向定义不同，不能称完全相同姿态模型。
2. 直接优化总时间sum(T)，不再对数压缩为log(1+sum(T))。二者严格单调，最优解集合相同；新的目标梯度不再被1/(1+总时间)缩小。
3. SLSQP迭代上限400→2000。四时间初值、每初值180s、ftol、安全和节点动力学约束、物理边界与内缩不改。

保留原TOGT圆/多边形映射、完整内部PVAJ、八段七窗返航。没有中心回退、可行候选替代收敛结果、软化安全约束、增加倾角惩罚或改变赛道。
仅优化器报告成功、节点约束满足原1e-5阈值、原全部窗口/全部段几何复查通过才返回；北图极点与零推力域异常标为unresolved，不得算可行。
北图不是全姿态无奇异表示；b3=-世界Z仍需其他图，本模块不声称支持该极点。分母保护不是物理可行性证据，额外域检查会拒绝该区。

接口：`Planner(track, free_points=True, pose_function=scenario.pose, max_iterations=2000)`；`pose_function`由调用者显式提供，不能混用运动轴。
构建与求解暂时注入旧模块接口，finally恢复；应使用隔离进程，不支持同一Python进程多线程同时构建/求解不同版本。
当前只用于纯规划验证，未接入MPC/PX4新航向跟踪，不宣称实飞成功。节点动力学约束也不等同连续动力学证书。
