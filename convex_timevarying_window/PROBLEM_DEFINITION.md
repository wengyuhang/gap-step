# 凸时变窗口赛道

无人机从给定 PVAJ 初态出发，按指定顺序各穿越一个凸窗口，再返回相同 PVAJ 终态。七个开口依次为矩形、精确圆、正五边形、精确圆、正六边形、精确圆和矩形；中心按三轴正弦函数平移，姿态按 roll/pitch/yaw 三轴正弦函数旋转；窗口运动是时间的外生周期函数。

规划使用与 TOGT 发布配置对齐的 degree-7 MINCO、正时长映射、L-BFGS 数值设置和目标函数。目标只包含飞行时间、机体角速度与单旋翼推力的 `smoothedL1` 积分；安全碰撞不进入目标，只在求解后独立检查。

安全检查把无人机近似为半径 `0.3794227368 m` 的外接球，把窗口视为零厚度有限边框。对全轨迹每个窗口计算球心到当时三维边界曲线的距离，最大采样步长为 1 ms。动力学检查使用同一 TOGT 四旋翼模型并以最大 1 ms 网格复核。两项都是密集采样数值证据，不是连续域认证。
