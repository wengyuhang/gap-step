# 七动态窗口全局安全增强 DynaTOGT 原型结果

## 设置

- 赛道：`race_uzh_7g_dynamic_mixed_closed.yaml`，7 个异形凸窗口，起点等于终点。
- 窗口运动速度倍率：`2.5`。
- 优化：一次全局 `[K,D]` 动态 TOGT，纯 C++ MINCO/解析梯度/L-BFGS，无 CEM。
- 停止阈值：相对代价 `1e-5`，`past=8`。
- 安全场：外接球半径 `0.3794227368 m`，附加优化余量 `0.03 m`，每段 8 个积分区间，权重 `10000`。
- 输出时间延拓：所有段乘 `1.02`，并在新绝对时间重算动态穿越点与完整MINCO轨迹。
- 验收：最大 1 ms 独立网格；安全同时报告保守球体和真实姿态长方体，动力学调用发布版
  `QuadManifold`。

## 求解结果

| 指标 | 结果 |
|---|---:|
| L-BFGS停止码 | `1`（发布版相对代价停止） |
| 迭代/目标评价 | `286 / 393` |
| 单次规划时间 | `68.475 ms` |
| 输出飞行时间 | `10.864971 s` |
| 原优化点动力学软惩罚 | `0.004844583` |
| 原优化点安全软积分 | `1.3e-8` |

20次相同冷启动计时全部正常停止：均值 `64.804 ms`，中位数 `63.440 ms`，P95
`69.197 ms`，最大值 `73.865 ms`。重复计时覆盖原生目标、C++ L-BFGS、2%时间延拓和最终MINCO
构造，不包含CSV写盘及独立审计；上表单次 `68.475 ms` 是修改计时边界前保存的求解器内部时间。

## 结论边界

该单场景原型实现了小于100 ms的全局安全增强动态TOGT，并在最大1 ms网格上同时通过整机安全和
动力学验收。它尚不是连续时间安全证书：优化器内部是8区间平滑安全积分，最终证据是密集采样。
下一步若要在论文中声称“整段保证安全”，需要把当前安全场替换或补充为Bézier控制点凸走廊约束，
或对输出轨迹运行区间分支认证。
